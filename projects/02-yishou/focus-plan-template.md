# 专注流 · 计划模板

[返回一手](README.md)

把下面整段连同你的情况一起发给 ChatGPT / Gemini，它回的六行直接粘进一手的“专注流 → 粘贴计划”。

```
请根据我下面说的情况，按这个格式帮我排一个专注计划，只回这六行，不要别的：
【任务】这一段要做的一件事（例：刷行测言语题）
【目标】想做到的量（例：30 道；不确定可以空着）
【总时长】60 分钟
【每组】6 分钟
【休息】1 分钟
【允许的应用】ChatGPT、Gemini（用顿号隔开；系统界面、一手、微信短信电话不用写）

我的情况：……
```

## 怎么写“我的情况”

说清这三样就够了：

- 要做什么、做多少（“言语理解 30 道”“读完第三章”）；
- 你平时的速度和卡点（“一道题常要 3 分钟，容易分心刷手机”）；
- 这一段能用的时间（“晚上 8 点到 9 点”）。

## 规则（一手里写死的）

| 项 | 范围 |
|---|---|
| 总时长 | 10–240 分钟；开始后只能延长，不能缩短 |
| 每组 | 3–60 分钟 |
| 休息 | 0–15 分钟 |
| 中途换节奏 | 随时可以；从换的那一刻起重新排，总时长不变 |
| 每组结束 | 点一下“做完了 / 没做完”，可加一句；不验收内容 |
| 能用的应用 | 系统界面、一手、白名单、微信短信电话；别的全拦，休息时也拦，收费站放行不算数 |
| 提前结束 | 在一手里等 3 分钟，离开页面重新计时 |
