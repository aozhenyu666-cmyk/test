# 装完怎么验收

每一步都写了「看到什么算通过」。可以自己做，也可以把这份文件交给 DSH，让它照着查、把结果抄回来。

用到的几个文件（都在 `%USERPROFILE%\.dsh\` 下）：

| 文件 | 谁写的 | 看什么 |
|---|---|---|
| `fish-memory-diag.log` | 记忆插件 | 挂上了没、每轮注入了几条、自动提取记了什么 |
| `fish-memory\auto-extract.json` | 记忆插件（新） | 每个会话自动提取到哪了、最近 10 次的结果 |
| `feiyu-mood\diag.log` | 心情插件 | 挂上了没、每轮心情怎么变 |
| 主动搭话设置页底部的「记录」 | 主动搭话 | 每次掷骰、叫醒、送出的记录 |

---

## V1. 新版本加载上了

1. 重启 DSH，打开 **设置 → 主动搭话**。
2. 看最上面那条记录（「已装好 v…」）。

**通过**：写着 `v0.3.0-dafeiyu.1`，而且包含 `冷会话：会叫醒（叫醒后等 5 秒）`。

**不通过**：
- 版本号还是 0.2.x：没装上，回到 INSTALL.md 第 2 步。
- 写着 `想叫醒但这个 DSH 不支持`：这个 DSH 版本没有 `resolveAgent`。**停下，把那条记录原文发给我。**

记忆设置页的版本号应该显示 `1.6.0-dafeiyu.1`。

## V2. 冷会话叫醒（核心）

1. 让大肥鱼主会话变成「冷的」：重启 DSH，**不要点开**大肥鱼那个会话。
2. 在主动搭话设置页确认：目标会话只勾了大肥鱼，旁边显示「冷的，掷中会叫醒」。
3. 按 **「真发一次」**。手动按钮不受试运行和骰子影响。
4. 等 10 秒左右，看记录。

**通过**：最新一条记录里有 `已叫醒冷会话 ……；已送出一句，DSH 会照常开一轮`，并且一分钟内点开大肥鱼会话能看到她刚说的一句新话。

**不通过**，按记录里的字判断：
- `想叫醒冷会话「…」没成：session/not-found`：勾的会话 id 不对，重新勾一次。
- `没成：session/writer-held`：这个会话正被别的程序占着写（比如开了两个 DSH）。
- `等挂载的这几秒里它忙起来了`：不算失败，那一刻你正好在跟它聊。
- 记录里送出去了，但会话里没有新回复：去 DSH 主日志里找这个会话的报错，原文发给我。

## V3. 叫醒后的那一轮带着记忆和心情

紧接着 V2，打开两个日志，只看**刚才那几分钟**的内容：

`fish-memory-diag.log`，按时间顺序应该能找到：
```
✓ 挂上 session-429facb2…（N 条）
……
注入 K 条：……
```
**通过**：「挂上」出现在「注入」之前，而且「注入」这一行出现了。K 可以是 0（说明这句话没有相关记忆），但这一行必须有。

`feiyu-mood\diag.log`：
```
已挂心情到 session-429facb2…
```
然后这一轮结束后会有一行：`心情更新…`、`小波动…`、`这轮判定无变化` 或 `这轮没判出来`，四种之一。

**通过**：「已挂心情」出现，并且这一轮有上面四种结果之一。如果没有「已挂心情」，说明大肥鱼会话没绑在任何一份心情上，见 INSTALL.md 第 3 步。

## V4. 自动提取记忆

1. 打开大肥鱼会话，自己连着发 3 条带个人信息的话，比如：「我下周三要去面试」「我其实很怕坐飞机」「我妈妈生日是六月十二号」。
2. 等她回完第 3 条，再等半分钟。
3. 看 `fish-memory-diag.log` 的最后几行。

**通过**：有一行 `自动提取（一轮）：session-429facb2… 看了 3 句 → 新记 N 条…`，N ≥ 1，后面列出记了什么。打开记忆设置页，能看到这几条，来源是「自动提取」。

**还可以查**：`fish-memory\auto-extract.json` 里这个会话的 `最近` 最后一条，`ok` 是 `true`。

**不通过**：
- 只有 `问模型失败（…）`：模型调用出错，原文发给我。下一轮会自动重试，这几句不会丢。
- 一行都没有：确认大肥鱼会话的记忆开关是开的，`fish-memory-config.json` 里没有写 `"自动提取": { "开": false }`。
- 只说了 1～2 句：要等「闲置分钟」（默认 10 分钟）之后才会提，这是设计如此。

## V5. 你在聊的时候不插话

1. 正在和大肥鱼聊天时（她回复中），按「真发一次」。

**通过**：记录写 `勾的目标会话现在都不能说话（…(忙)）`，不会插一句进来。

## V6. 自动跑（放一晚上）

1. 主动搭话设置页：关掉「试运行」，「总开关」开着，保存。
2. 不打开大肥鱼会话，让 DSH 开着几个小时。

**通过**：记录里出现 `掷中 ✓ …｜…已叫醒冷会话 …；已送出一句`，而且会话里有对应的新消息。没掷中的那些轮会写 `没掷中 ✗`，这是正常的。安静时段（默认 1～8 点）不掷骰子。

## V7.（可选）主动说的话推到 QQ

前提是大肥鱼会话接了 QQ 桥。打开 QQ 桥设置：

- 「只回 QQ 唤醒」**关着**：所有回复都会推到 QQ，主动搭话也会推。
- 「只回 QQ 唤醒」**开着**：要同时打开「自动触发也发」，主动搭话才会推到 QQ。

**通过**：V2 或 V6 那句主动的话，QQ 上也收到了。

⚠ 已知没修：**QQ 发进来的消息不会叫醒冷会话**。QQ 桥只认活着的会话，冷的时候会先存着，等你打开会话再补投，超过 10 分钟就不补了。修法跟 speak-up 一样（改用 `resolveAgent`），排在下一步。
