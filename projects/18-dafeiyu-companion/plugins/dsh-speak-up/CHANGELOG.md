## 0.4.0-dafeiyu.1 — 2026-11-02（大肥鱼改造版）

**别再软绵无力：会提醒、会催、会弹通知、开口有内容**

起因：用户反馈大肥鱼主动说的话「太软绵无力，很多时候直接忽略」。读代码确认三个原因：
那句念头只有「好久没人跟我说话了」，她手里没有具体的事；话只躺在会话里，不开窗口看不见；没回就没回了，没有跟进。

- ✨ **提醒**（新文件 `lib/提醒.js` + host 接线，不依赖工具，PTC 模式下也能用）：
  - 每轮结束先用本地正则判断有没有提醒相关的话（「X 点提醒我」「叫我」「催我」「不用提醒了」「我九点叫你」），
    有才问一次模型，记下 / 完成 / 取消 / 推迟提醒；闲聊不花 token。
  - 支持「每天 / 工作日 / 每周」重复。存在 `~/.dsh/speak-up-reminders.json`（原子写）。
  - 每 30 秒查一次：到点 → 冷会话先叫醒 → 送一句「⏰ 提醒到点了」念头，要求第一句就说事、要用户回一句。
  - **跟进**：发出去 `提醒跟进分钟`（默认 15）内没回，再催一次，一次比一次直接，最多 `提醒最多跟进`（默认 2）次，
    最后一次会说「这是最后一次催」；用户一说话就停。回「等会」→ 模型判断后推迟（默认 10 分钟）。
  - 用户正在聊天时照样投递（排在这一轮后面），不吞掉提醒；跟进不在安静时段里催。
- ✨ **系统通知**：主动搭话 / 提醒那一轮说出的话，在 Windows 上弹系统通知（PowerShell + Windows.UI.Notifications，
  不装任何模块；提醒用 `scenario="reminder"`，一直留在屏幕上直到点掉）。正文只以 base64 进脚本，不会被当命令执行。
  弹不出来（非 Windows / 被拦）时由网页半边轮询 `/notify`，用浏览器通知弹（需要 DSH 窗口开着）。
- ✨ **话头**（「搭话要有内容」默认开）：主动搭话的念头后面附上 —— 记忆插件里她最近 14 天说过的一件重要的事、
  6 小时内要到点的提醒、「上次主动找你你没回」，再加一句风格要求（别只说「在吗」，结尾留一个容易接的问题）。
  风格可在设置页改。同一条记忆不会接连用。
- ✨ 设置页新增「提醒与通知」卡片：开关、跟进间隔、次数、通知开关、两个「试一下通知」按钮、提醒列表（现在就发 / 取消）、手动加提醒。
- ✨ 新路由：`/dsh-speak-up/reminders`、`/dsh-speak-up/notify`、`/dsh-speak-up/test-notify`。
- 🧪 新增 `tests/提醒.mjs`（62 条）；宿主测试 117 条、网页测试 65 条全部通过。

## 0.3.0-dafeiyu.1 — 2026-11-02（大肥鱼改造版，派生自 0.2.9）

**冷会话也能叫醒；叫醒后等记忆/心情挂上再开口；心情影响开口频率**

- ✨ **冷会话叫醒**：以前只认 `agents.get()`，勾的会话没在窗口里开着就直接跳过 ——
  用户不开聊天窗口，大肥鱼永远不会主动开口。现在掷中后用宿主自己的
  `sessionController.resolveAgent(id)` 把会话从磁盘恢复出一个 agent（跟用户点开会话是同一条路），
  再照常 `followup`。id 两种写法（带不带 `session-`）都试；只有 `session/not-found` 才换写法，
  `writer-held` 之类的错误直接停下并记账。新配置「唤醒冷会话」（默认开），关掉 = 回到 0.2.x 行为。
- ✨ **叫醒后先等几秒**（「叫醒后等几秒」，默认 5）：dsh-fish-memory / dsh-feiyu-mood 是定时扫描
  （0.5 秒 / 3 秒）挂到新 agent 上的，不等的话叫醒后的第一轮没有记忆注入、也没有心情。
  等完再查一次：要是这几秒里用户自己开始聊了（agent 不再 idle），这轮让给用户。
- ✨ **心情联动**（「心情联动」默认开，「心情联动强度」默认 0.5）：只读 `~/.dsh/feiyu-mood/`
  的 config/state，按 feiyu-mood 自己的衰减规则算出当前心情；担心/心疼/难过、心情低于基线、
  或开心/甜蜜时，命中线乘一个心情因子（最多 1 + 强度）。命中线算式里会写出这一项。
- 🧪 测试新增 19 条（叫醒成功 / 两种写法 / 叫醒后变忙 / 被占着 / 关掉开关 / 演练不叫醒 / 心情因子 / 读心情 / 衰减）。
- 演练（试运行）**绝不**真的叫醒会话，只在记录里写「真发时会先叫醒它」。

**冷却不再把「投递成功」当成「她开口了」；那句念头现在会带上「现在几点」**

  怕吵醒人把自己劝退。现在消息自带「现在这会儿是 11 月 1 日 周日 下午 3:08」，

## 0.2.8 — 2026-11-01

**「检查更新」以前会报错版本，而且只给一条命令让你自己手动复制、然后手动装**

- 🐞 **"最新版本"会骗人**：以前是「哪个地址先返回就用哪个」。GitHub 一超时就落到 jsDelivr ——
  那个地址**带 CDN 缓存、会滞后好几天**，于是同一分钟内能报出好几个不同的"最新"，
  甚至比你本机装的还旧，看着像"该降级"。
- ✅ 现在**三个源全查**（GitHub / jsDelivr / npm registry），**取版本号最大的那个**：
  版本只会往前走，哪个源报小了就是它滞后。三个都失败才说"查不到"，绝不把旧值当成"最新"。
- ✨ **检测到新版可以直接装**：那一块多了一个「一键更新到 vX」按钮，点它走 DSH 自己的插件管理装最新版，
  装完会提示你重启（或重载）一次。以前只有一个「复制命令」，得你自己去终端敲两行。
- 🧹 **界面上那些命令行全删了**：以前那两行 `dsh plugin --profile web remove/add` 和「复制命令」按钮不再显示 —— 很多人看不懂，还得跑来问。现在有新版就只有「一键更新到 vX」一个按钮。
- ⚠ **本地开发副本（link: 进来的那种）不给一键装** —— 那会把正在改的目录换成仓库里的版本；
  这种会明确写出来，让你手动更新。
