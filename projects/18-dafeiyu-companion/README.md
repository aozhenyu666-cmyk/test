# 大肥鱼 AI 伴侣 · DSH 插件改造

让电脑 DSH 上的「大肥鱼」做到这几件事：**不开聊天窗口也会主动开口**、**聊天时自己记住重要的事**、**主动开口带着记忆和心情**、**能提醒你、没回会催、弹系统通知**。

这里放的是改好的插件源码、能直接安装的包、安装脚本和验收清单。手机端（DSH-Go）的适配是下一阶段的事，见文末。

## 这一版解决了什么

| 原来的问题 | 原因（读源码确认的） | 这一版怎么改 |
|---|---|---|
| 不开聊天窗口，大肥鱼永远不主动说话 | `dsh-speak-up` 只用 `agents.get()` 找会话，会话冷了（没在窗口里开着）就放弃 | 改用宿主自带的 `sessionController.resolveAgent()` 把冷会话叫醒，再照常开一轮 |
| 叫醒后的第一句话没有记忆、没有心情 | 记忆和心情插件每 0.5 秒 / 3 秒扫描一次才挂到新会话上，叫醒后马上发话时它们还没挂上 | 叫醒后先等 5 秒（可调），再确认会话不忙才发 |
| 记忆几乎不增长（审计时只有 1 条） | 记忆**只**靠模型自己调 `remember` 工具；PTC 模式下模型根本看不到这个工具 | `dsh-fish-memory` 新增「自动提取」：每聊 3 句，插件自己问模型「哪些值得记」，再走 remember 同一条写入路 |
| 心情不影响主动开口 | 两个插件互不知道对方 | `dsh-speak-up` 只读心情插件的状态文件：担心、心疼、低落时更容易主动开口 |
| 主动说的话「软绵无力」，经常被忽略 | 念头只有一句「好久没人跟我说话了」，她手里没具体的事；话只躺在会话里没有通知；没回也没有跟进 | speak-up 0.4.0：① 认对话里的提醒，到点叫醒会话去提醒，没回就跟进（最多再催 2 次，一次比一次直接）；② 主动说的话弹 Windows 系统通知，提醒那种常驻屏幕；③ 主动搭话时附上记忆里她最近说过的事当话头 |
| 心情 30 小时不变 | 心情插件只在会话有新的一轮时才判断；主会话一直是冷的，所以一直不动 | 不用改心情插件：主会话被叫醒并开始对话后，它自己会判断心情 |

**没改的**：`dsh-feiyu-mood`（心情插件）、`dsh-qq-bridge`、SurfCore。心情插件本身逻辑是好的，问题出在主会话一直是冷的。

## 已知还没修

- **QQ 发进来的消息不会叫醒冷会话**（`dsh-qq-bridge` 只认活着的会话）。你现在不用 QQ，先不修。
- 提醒只认**勾为目标会话**的那几个会话里说的话（也就是大肥鱼主会话）。
- 系统通知要 DSH 在跑（最小化也行）；通知弹不出来时退回浏览器通知，那条路要 DSH 窗口开着。
- 记忆话头只在记忆插件用「按会话」模式时读得到；「按工作区」模式下读不到库，主动搭话就不带记忆话头（其余照常）。
- 自动提取和模型自己调 `remember` 共用「每天最多记几条」（默认 8）。聊得多的日子可能不够用，到记忆设置页调大即可。
- 自动提取的设置暂时只能改配置文件或调路由，记忆设置页里还没有对应的开关（默认就是开的）。
- 主动开口那句话里的心情、记忆，是靠「叫醒后等 5 秒」让另外两个插件先挂上。如果你的电脑很慢、5 秒不够（V3 里「注入」出现在「挂上」之前），把「叫醒后等几秒」调大。

## 下一阶段：手机 DSH-Go

交接包里的结论是：DSH-Go 的「本机引擎」是在手机上用 proot 跑真正的 DSH，插件可以原样装上去。所以这一版的两个插件**理论上不用改就能在手机上用**。要真机确认的是：

1. 手机上的 DSH 版本是否也有 `sessionController.resolveAgent`（speak-up 启动日志里会写「冷会话：会叫醒」还是「这个 DSH 不支持」）；
2. 息屏 / 后台时 DSH 进程会不会被系统杀掉（会被杀的话，定时器根本不跑，主动开口就不可能发生）；
3. 电脑上的记忆、心情、人格数据怎么搬到手机（目录是 `~/.dsh/fish-memory/`、`~/.dsh/feiyu-mood/`、`~/.dsh/*-config.json`，会话 id 要对上）。

这三件需要真机，等电脑上的链路跑通再做。
