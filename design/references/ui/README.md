# UI 设计参考

这里集中存放 UI 设计参考材料，供 Claude Code、Codex 等开发/设计工具在实现界面时查阅。

## 目录

- `Kit/`：可编辑的 UI Design Kit（Figma / Sketch / Adobe XD 等源文件及其配套资源）
- `Media/`：截图、图片、录屏、演示视频等视觉参考材料

原则：可编辑设计源文件与纯视觉参考素材分开存放，避免混在一起。

## 已收集的图片与动效

- [UI 参考素材包与使用说明](Media/UI参考素材/README.md)：13 个作品、105 张图片、1 个动态 GIF、5 段视频，附来源清单、图库和精选报告。
- 编程助手可先阅读这份说明，再按作品目录查看原图。该素材集为视觉参考，保存在 `Media/UI参考素材/`。
