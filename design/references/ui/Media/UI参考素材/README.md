# UI 与动效参考素材

这是给你和编程助手使用的设计参考库：13 个作品、105 张静态图片、1 个动态 GIF、5 段视频。文件按作品分目录保存，来源与选图建议也一并保留。

## 怎样让编程助手使用

在这个仓库开始任务时，可以直接说：

> 先阅读 `design/references/ui/Media/UI参考素材/README.md` 和 `design/references/ui/Media/UI参考素材/素材说明.md`，查看 ChatGPT、Claude、stoic 的参考图。给当前页面做黑白、简洁、留白舒适的设计，保持主要任务清楚。若加入进度动效，参考 Fliqlo、Mondaine 和 ClockClock-24，先做一个克制的小样。

助手需要能读取这个仓库，并且使用包含素材的分支。如果任务使用旧分支，先同步素材目录或切换到包含这次提交的分支。

## 参考文件与产品文件

`design/references/ui/Media/UI参考素材/` 存放研究和设计参考。真正用于应用的图片、图标或动画，等设计确定并核实使用权后，再按项目约定放进应用的资源目录。编程助手可以借鉴层级、留白、反馈与动效节奏，不应直接把整个参考包打进安装包。

部分图片来自应用商店宣传页，有外框和宣传文字；游戏图片主要提供氛围参考。来源清单区分官网、商店、Mobbin 与零售商演示。下载不等于获得商用授权。
