## 0. 第二版改了什么

第一版的思路是在总控里装一颗自己的大脑。你指出了两件事：

1. 你有 Gemini 和 GPT 会员，**Gemini Live 的额度很多**，聊天应该交给它，不该再花钱造一个更弱的聊天对象。
2. 问题不在总控功能少，而在**没有核心、信息不通、无障碍老掉、一手很乱**。再往总控里加“大谋划”没用。

所以第二版做减法，只抓四个问题：

| 问题 | 第二版的答案 |
|---|---|
| Gemini Live 聪明，但不认识你，像个陌生人 | 给它一个固定人格和规矩（墨灵），开口前先让它读你的局面 |
| 信息靠 GPT 和 Notion 传话，传不到就断 | 换成 **Google Tasks + 日历**：Gemini Live 能用语音直接读写，总控也能通过接口读写同一份清单 |
| 聊什么？一聊就口水，聊完没东西 | 总控每天从你的真实数据里出**话题卡**，每张卡只有一个问题，必须交收线 |
| 无障碍一掉全线失效 | 另做一个很小的 **哨兵 App**，专门盯总控：掉了就拉起、拉不起就冻结娱乐 App |

一手停止单独发展，总控收缩到三个页面。

## 1. 新的分工：三样东西

```text
          ┌──────────────────────────────┐

          │  深度思考备用：GPT              │
          └──────▲───────────────┬────────┘
       读局面、话题卡 │               │ 写收线、新任务、日程
          ┌──────┴───────────────▼────────┐
          │   信息总线：Google Tasks + 日历   │  两边都能读写，不用人传话
          └──────▲───────────────┬────────┘
       写局面、话题卡 │               │ 读收线
          ┌──────┴───────────────▼────────┐
          │  身体和记忆：总控                 │  眼睛、计时、记账、锁机、信用、决定什么时候推你去聊
          └──────▲────────────────────────┘
                 │ 盯着它活着
          ┌──────┴────────────┐
          │  哨兵（新，很小）    │  无障碍掉了就拉起；拉不起就冻结娱乐 App
          └───────────────────┘
```

| 谁 | 负责 | 不负责 |
|---|---|---|
| **Gemini Live（墨灵）** | 和你说话：晨会、拆事、复盘、陪学；读你的局面；把结论写回 Tasks | 记住长期状态、到点叫你、锁机 |
| **GPT** | 偶尔的深度长文思考（写方案、改简历、大判断） | 日常对话（语音额度少） |
| **Google Tasks + 日历** | 局面、话题、收件箱、今天的时间块 | 复杂数据 |
| **总控** | 看你在干什么、判断偏没偏、出话题卡、推你去聊、验收、锁机、记账、信用 | 自己陪你长聊 |
| **哨兵** | 让总控一直看得见 | 别的都不管 |

总控里仍保留一个很小的文字模型（DeepSeek），只做短判断：现在偏没偏、出哪张话题卡、收线有没有内容。这种短判断每天几毛钱。第一版第 7 节有估算：贵的是长聊天，而长聊天现在交给 Gemini。

## 2. 你什么都不做的时候，它怎么办

这是你问的核心问题：连你自己都说服不了自己，怎么指望 AI？

答案是：**它不需要读懂你的心，也不需要说服你。**它只需要三样东西：

1. **可靠的信号**：手机亮没亮、在用什么 App、用了多久、在哪、花了什么钱、今天排的事开始没有。这些不用你说，总控和哨兵自己能看到。
2. **默认剧本**：你清醒时定好的一天骨架，比如“上午一件主线、下午一个空档话题、晚上 10 分钟复盘”。你什么都不说，剧本照样跑。
3. **唯一通路**：偏离剧本、又不回应时，只开一条路：**去和墨灵聊**。娱乐 App 被冻结，直到你在 Gemini Live 里聊够时间、交了收线。

你说过自己的注意力像水，只往阻力最低的地方流。这个设计就是把其他口子堵上，只留“和墨灵说话”这一条路。到了 Gemini 那边，说服你、陪你想，是 Gemini 的事；它擅长这个，而且你已经付过钱了。

```text
你什么都没做
  → 总控看到：空档、抖音 15 分钟、主线没开始
  → 墨灵出话题卡：“下午这段时间，你打算怎么用？”（总控通知 + 朗读）
  → 不理：再提醒一次，带一个二选一
  → 还不理：娱乐 App 冻结，通知只有一个按钮“去和墨灵聊 10 分钟”
  → 打开 Gemini Live，墨灵先读局面：“抖音刷了 15 分钟，主线是申论大作文。我们先聊 5 分钟，你卡在哪？”
  → 聊完，墨灵把收线写进 Tasks 的“墨灵收件箱”
  → 总控读到收线 → 判定有内容 → 解冻，下一步变成行动
```

## 3. 信息总线：Google Tasks + 日历

Gemini Live 现在能用语音直接操作 Google 日历、Tasks、Keep 和地图：建日程、加任务、读清单（[来源](https://alternativeto.net/news/2025/8/gemini-live-adds-real-time-calendar-keep-tasks-and-maps-integration)、[9to5Google](https://9to5google.com/2025/06/25/gemini-live-google-keep/)）。Google Tasks 和日历都有公开接口，总控可以读写同一份数据。Keep 的接口只对企业版开放，所以不用 Keep。

总控维护三个 Tasks 清单和一个日历：

| 清单 | 谁写 | 内容 |
|---|---|---|
| **墨灵·局面** | 总控 | 5–8 条，每条标题就是一句话：今天的主线、主线的断点、今天娱乐 / 零食用了多少、信用和态度、昨晚的收线、明天第一步。每 15 分钟和每次有变化时刷新 |
| **墨灵·话题** | 总控 | 现在可以聊的 1–3 张话题卡（见第 4 节）。最上面一条就是“现在该聊的” |
| **墨灵·收件箱** | Gemini | 收线和新任务。格式：`收线｜结论｜下一步｜几点做`。总控读完标记完成 |
| **日历“墨灵”** | 总控为主，Gemini 也能加 | 今天的时间块（主线、空档话题、复盘）。Gemini 能回答“我今天下午排了什么” |

这样就不用 GPT 和 Notion 传话了：Gemini 开口前读“局面”和“话题”，聊完写“收件箱”，总控读回来。Notion 降为可选的归档。

**还没确认、必须先在你手机上测的**（任务 G0，20 分钟）：Gemini Live 能不能读出某个清单里的全部任务、能不能按指定格式往指定清单里加任务、Gem 的设定在 Live 里生不生效、国内网络环境下 Tasks 同步要多久。测不通的地方有备用路径：开场白用剪贴板粘贴；收线让 Gemini 用固定格式说一遍，你点一下复制，回到总控时它会检测剪贴板（总控已有这个功能）。

## 4. 聊什么：话题卡

你说的问题是真的：没有题目，聊几句口水话就停了。所以**题目永远由总控出，你不用想聊什么。**

一张话题卡 = 一个具体问题 + 规矩 + 收线要求。只有标题会被 Gemini 读到，所以标题要能单独看懂：

```text
【拆事·12分钟】申论大作文三天没动，卡在哪一步？聊完交：第一步做什么、几点做
```

话题从哪来（总控按优先级自动挑）：

| 类型 | 什么时候出 | 例子 |
|---|---|---|
| 晨会（5 分钟） | 早上第一次解锁 | 今天只做三件事，哪三件？第一件几点开始？ |
| 拆事（10–15 分钟） | 一件事过点没开始、或被推迟两次以上 | 这件事卡在哪？最小的第一步是什么？ |
| 接着昨天 | 有昨晚的收线 / 断点 | 昨天说要先把材料分成三类，分了吗？分出来什么？ |
| 判断 | 收件箱里有“待决” | 这个岗位投还是不投？给我两条理由和一条反对的 |
| 学习口述 | 主线是考试 / 求职时 | 申论：用 3 分钟口述这则材料的核心问题；或模拟一道结构化面试题 |
| 复盘（10 分钟） | 晚上 | 今天哪件事比计划差？差在哪？明天第一步是什么？ |
| 空档 | 没排事、在刷短视频 | 接下来 1 小时你打算怎么用？三选一 |

规矩写在墨灵的设定里，对每张卡都生效：一次只问一个问题；你先说，它再追问一处；不替你总结；你开始说口水话就把你拉回卡上的问题；到时间就要收线。

提醒一句：如果国考还在你的计划里，2027 年度笔试按往年规律估计在 11 月底，离现在大约 6 周。申论本身就是“把选择题变成简答题”的训练，结构化面试本身就是语音对话。在这种时候，学习口述类话题卡可以占话题的一大半。

## 5. 墨灵的设定（给 Gemini 的 Gem，也给 GPT 的项目）

Gemini Live 显得“没那么聪明”，主要原因是它不认识你、没有目标、太客气。修法是给它一个固定设定，任务 G2 会写成完整版本，核心是：

- **人格**：一个说话直接、温和但不迁就的同伴（声音在 Gemini 设置里选一个你喜欢的女声）。说“我们”，一次一两句，不夸，不说教，会把数字摆出来。
- **开口前**：先读“墨灵·局面”和“墨灵·话题”两个清单，以及今天的日历。
- **对话规矩**：见第 4 节。
- **收线**：到时间或你说结束时，问“一句话，今天聊出了什么？下一步几点做？”，然后在“墨灵·收件箱”加一条 `收线｜结论｜下一步｜时间`。
- **不能做**：不能答应放宽规则，不能替总控发娱乐时间。你求它放水，它只能说“这件事总控说了算”。

Google 正在把 Gem 改成“技能”（skills），具体形式可能会变，设定写成纯文字，迁到哪里都能用。

## 6. 哨兵：一个只管让总控活着的小 App

无障碍掉线是现在最大的单点故障。vivo 会把总控的进程冻住，这时总控自己的“自愈”也跑不起来。所以要一个**独立的、很小的、很难被杀的**进程来盯它。

**哨兵做四件事：**

1. **每 30–60 秒检查一次**：总控的无障碍是否开着；总控有没有在最近 2 分钟报过平安（总控每分钟给哨兵发一次心跳）。
2. **掉了就修**：用 `WRITE_SECURE_SETTINGS` 把总控的无障碍关掉再打开，再拉起总控的服务。这个权限只要在电脑上用 adb 授权一次，重启后也不会丢；总控现在的自愈也用这个方法。
3. **修不好就顶上**：
   - 弹全屏页“总控看不见了”，一键去权限页；
   - 用 Shizuku 把拦截名单里的娱乐 App 冻结（`pm suspend`，图标变灰、打不开）。冻结不依赖无障碍；
   - 用“使用情况访问”权限自己看前台应用（不依赖无障碍），作为第二双眼睛，把在线时长记给总控。
4. **互相盯**：总控也盯哨兵，哨兵被关掉时总控记一笔、扣信用、第二天问。

**为什么要单独做一个 App**：哨兵代码少、没有界面负担、只跑一个前台服务，被系统杀掉的可能比总控小得多；它和总控是两个进程，总控被冻住时它还活着。

**安全阀**：冻结都有到期时间（最长 12 小时），哨兵、总控、开机广播任何一个都会解开过期的冻结；电话、短信、微信、支付宝、地图永不冻结；哨兵里有“全部解开”按钮（会记录、扣信用）。

## 7. 减法

你说得对：总控和一手的功能很多，效果却不成比例。第二版的取舍：

| 东西 | 处理 |
|---|---|
| **一手** | 不再单独发展，也不用再打开。它最有用的一条“打开娱乐先答简答题”，总控 0.10 已经有了；断点进“墨灵·局面”；陪练和六骰子变成话题卡的规矩 |
| **一手的语音伙伴 T4–T7**（自建语音接口） | **暂停**。语音交给 Gemini Live。T1–T2 里“准备开场白、看你在不在 Gemini、回来收线”的部分搬进总控，成为“推你去聊”的工具 |
| **伴随**（独立语音 App） | 停止 |
| **SP 插件 AI 参谋** | 停止 |
| **总控** | 底栏从五个减到三个：**今天**（墨灵此刻的话、现在这一步、今天的票和钱）、**墨灵**（话题卡、收件箱、去聊按钮、和总控参谋的文字对话）、**我**（设置、权限）。四部页面、脉络、战役、预案、大统筹、多余的宠物形象和动效，收进“实验室”，默认隐藏，代码不删 |
| **总控时间（静收谋筹行封）** | 换成晚上 10 分钟的“复盘”话题卡，在 Gemini Live 里做。手机仍然“万籁俱寂”，只是陪你的变成会说话的墨灵 |
| **晨间部署向导** | 换成早上 5 分钟的“晨会”话题卡 |
| **谋划思考部、统筹规划部** | 不再是总控里的页面，而是和墨灵的对话类型（拆事、判断、晨会、复盘）。谋划思考部仓库保留，作为 GPT 端的长期档案 |
| **Notion** | 降为可选归档 |
| **保留不动** | 宪章、信用、挣来的娱乐、欠账严管、打开娱乐先答题、低屏模式、账本、电脑版 |

## 8. 一天的样子

| 时间 | 发生什么 | 你要做的 |
|---|---|---|
| 早上第一次解锁 | 总控朗读“晨会，5 分钟”，一键打开 Gemini Live | 和墨灵说今天的三件事。它写进收件箱，总控建成行动、排进日历 |
| 白天 | 总控照旧：计时、挣娱乐时间、欠账严管 | 做事 |
| 某件事过点没开始 | 话题卡“拆事”出现。不理 → 提醒 → 冻结娱乐 | 去聊 10 分钟，或直接开始做 |
| 空档刷短视频 | 话题卡“空档”出现，同样的阶梯 | 选怎么用这段时间 |
| 晚上 | “复盘”话题卡 + 手机静音模式 | 和墨灵聊 10 分钟，收线写明天第一步 |
| 无障碍半夜被杀 | 哨兵发现 → 重新打开 → 失败就冻结娱乐 App、记下来 | 早上墨灵会问 |

每天和墨灵说话的时间：晨会 5 + 复盘 10 + 一两次话题 20 ≈ 35 分钟，都在 Gemini Live 的额度里。

## 10. 做不到 / 不确定

- 总控**不能主动替你开启 Gemini Live 的语音**，只能打开 Gemini App 或 Live 入口；按下说话那一下要你自己来。
- 总控**听不到** Gemini Live 里聊了什么，只看得到你在 Gemini 里待了多久和最后的收线。所以验收看收线，不看过程。
- Gemini 的功能会变：Gem 在改成技能，Live 读清单的细节要实测。设计里每一处都留了剪贴板备用路径。
- 普通 App 拦不住你去系统设置里关掉哨兵或总控。能做的是：两边互相盯、留痕、扣信用、第二天追问。
