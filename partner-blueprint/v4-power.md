## 1. 权柄：从“每件都问”到“授权书”

现在的规矩是对的，但太累：每一件都要在墨灵点一次“好”、在总控再点一次“执行”。用户要的是**更高的权柄**。办法不是放松铁律，而是让他**事先**说清楚哪些事可以不问。

### 1.1 授权书（总控里的一页设置）

授权书是一张表：每一行是一类事 + 边界。例如：

| # | 墨灵可以直接让总控做 | 边界（他自己填） |
|---|---|---|
| 1 | 开专注锁 | 只在今天水道的主河道 / 支流时间里；每次 ≤ 45 分钟；每天 ≤ 3 次 |
| 2 | 把一个应用拦到今晚 23:00 | 只限总控娱乐类里的应用；每天 ≤ 2 个 |
| 3 | 今天的娱乐时间减少 | 每天累计 ≤ 30 分钟 |
| 4 | 进总控时间 | 只在“失联超过 3 小时”或“连续娱乐超过 60 分钟”时；每天 ≤ 1 次 |
| 5 | 排行动、定主线 | 只限今天；不改他已经开始的事 |
| 6 | 记约定 / 交谋划单 | 来自他在对话里亲口说的话 |

规矩：

1. **只能授权“收紧”和“排计划”**。放宽（移出拦截、加娱乐、推迟关卡）永远不能授权，永远是他自己申请、走 24 小时冷静期。
2. **授权立即生效（这是收紧），撤销授权走 24 小时冷静期（这是放宽）**——和总控别的规则一样，冲动时撤不掉，冷静下来还想撤就撤。紧急退出照旧随时可用。
3. **两道门**：总控的授权书允许 **且** 墨灵挣到的等级允许（规划者：第 5、6 行；管家：全部）。墨灵常常猜错时会被降成参谋，授权书自动失效（只剩提议）。
4. **60 秒反悔**：授权内的事，总控先发通知“墨灵 60 秒后开 30 分钟专注锁（授权书第 1 条）· 取消”，60 秒内他点“取消”就不做，也不算违约。墨灵把“被取消”记进成绩（接受率）。
5. **每一次都留痕**：总控日志 + 墨灵日志，写清是哪一条授权、为什么。

### 1.2 新的权柄表

| 一类事 | 参谋 | 规划者 | 管家 |
|---|---|---|---|
| 看、说、记、排水道草稿 | 自己做 | 自己做 | 自己做 |
| 召唤去聊（打开演员 + 开场白） | 问 | 自己做 | 自己做 |
| 排计划给总控（主线、行动、约定、谋划单） | 问 | 授权内：60 秒反悔；授权外：问 | 同左 |
| 收紧（专注锁、拦到今晚、减今天娱乐、总控时间、临时严管） | 问 | 问 | 授权内：60 秒反悔；授权外：问 |
| 墨灵自己的干涉（小窗、先答一问、勿扰、开口说话） | 只有小窗和通知 | 全部，按他的设置 | 全部 |
| 放宽 | 只能申请，冷静期 | 同左 | 同左 |
| 修复 / 冻结 | 不做（总控和哨兵的事） | 不做 | 不做 |

### 1.3 铁律（不变，写在代码里）

放宽只走冷静期；电话、短信、支付、地图、系统设置、总控、墨灵自己永不拦截；紧急退出永远在；不替他花钱、不以他的名义发消息；不读别的 App 里的私人聊天；新增监控必须他在系统里亲手授权；关于“他”的重要结论要他确认才算数。

## 3. 总结思考：她想得更深

1. **三层复盘**
   - 每晚（已有）：对账、日记、模式候选。
   - **每周日晚**：本周水道完成率、偏离最多的时段、预言成绩、提议接受率、哪条授权被取消最多 → 一页“周报”，并给出**一个**下周要试的改动（打法）。
   - **每月**：长期目标还对不对、哪件事拖了三周以上、要不要换方向。只提问题，不替他下结论。
2. **四个参谋**（大判断时）：改计划、换方向、判断他是不是在逃避之前，大脑让文字模型分别以教练 / 军师 / 对手 / 朋友各说一句，再合成一句给他。平时不用（省钱）。
3. **关于他的结论要确认**：模式候选（“下午容易卡住”）、画像（“晚上 10 点后效率低”）列在一个“她对你的了解”页，每条带证据和把握，他点“对 / 不对 / 不确定”。只有“对”的才进排水道和预言。
4. **打法本**：确认过的模式变成打法，真的改变大脑的行为。例：“下午容易卡住”→ 下午的主河道前自动插一个 10 分钟源头；“刷短视频多在 22 点后”→ 21:50 的提醒提前到 21:30。每条打法有试用期（一周），周报里看有没有用，没用就撤。
5. **体系图的复习**：没验证的假设、没回答的问题，按间隔（1 / 3 / 7 天）回到今天页的“下次该聊”，去演员那里聊之前自动成为开场白的第一问。

## 4. 对总控的干涉：她的手更长

1. **授权书**（第 1 节），总控里新增一页 + 一个 60 秒反悔通知。
2. **三个新开关**（总控内核）：
   - **只减今天的娱乐**：今天能玩的分钟数减少 N，明天恢复。
   - **临时严管 N 分钟**：到点自动解除。
   - **拦到今晚**：把一个应用临时加进拦截，到 23:00（或他设的时间）自动移出——自动移出不算放宽，因为是事先约好的到期。
3. **约定交给总控**：他在对话里说“我十点开始写申论”，墨灵提议“记一条约定：10:00 前开始「写申论」，检查：总控里这一步开始了”→ 进总控已有的约定账本，到点总控自己查、自己记“做到了 / 没做到”。墨灵读结果。
4. **谋划单交给总控**：墨灵和演员聊出来的计划（例如“这周把申论三篇写完，每篇怎样算完”）整理成总控已有的“外接谋划单”，由总控逐条盯落实。墨灵是谋划者，总控是监督者。
5. **总控时间的预约**：提议“今晚 21:00 进 30 分钟总控时间”，总控到点叫他（授权内直接排上）。

## 5. 墨灵自己的干涉：不经过总控也能出手

这些都不拦截、不冻结，只是**出现在他面前**；每一样都能在设置里单独关。

| 干涉 | 什么时候 | 怎么做 | 权限 |
|---|---|---|---|
| **小窗** | 去 Gemini / ChatGPT 聊的时候；水流偏了的时候 | 屏幕边上一个小圆点，点开是导演的卡片（一问、可以念给演员的话、按钮）；聊完一句话收线 | `SYSTEM_ALERT_WINDOW`，他手动开 |
| **先答一问** | 主河道时间里打开娱乐 App | 小窗弹出一张卡：“现在是「申论」的时间。A 先做 15 分钟 / B 我卡住了 / C 我就玩 10 分钟”。选完就收起，**不拦**；选 C 时墨灵记一条约定，10 分钟后来问 | 同上 |
| **开口说话** | 早上第一次亮屏、主河道开始前 5 分钟、约定到期 | 系统朗读：60 秒晨报（昨天停在哪、今天的主河道、第一问）；提醒用一句话 | 无 |
| **桌面小部件** | 一直 | 显示此刻该在的水道 + 接力棒的下一问；点一下进今天页 | 无 |
| **专注时开勿扰** | 总控专注锁开着时 | 打开系统勿扰，锁结束时恢复原样 | 勿扰访问权限，他手动开 |
| **全屏叫醒** | 授权书第 4 行触发总控时间时 | 总控已有全屏通知，墨灵不重复做 | — |

## 6. 监督：说过的话、做没做到

1. **约定账本**：所有约定（对话里说的、先答一问选 C 的、提议里定的）都进总控的约定账本，到点自动查证据。墨灵只读结果，周报里汇总“说到做到率”。
2. **升级阶梯**（同一次偏离，一步一步来，每一步之间至少 5 分钟）：
   1. 通知一句；
   2. 小窗出现，带三个选项；
   3. 提议开专注锁（他点“好”）；
   4. 授权内：总控 60 秒后开锁（他可以取消）。
   他回应了任何一步，阶梯就停。陪伴模式、休息时段、总控时间里不走阶梯。
3. **说法对证据**：演员说“完成了”、他说“我做了 40 分钟”——墨灵拿总控记录（做事分钟、行动状态）对照，对不上就温和地摆出数字：“总控记的是 15 分钟，差在哪？”不指责，记进事故簿。
4. **每周成绩单**：水道完成率、偏离次数、约定兑现率、预言 Brier、提议接受率、授权被取消次数。每项和上周比，只说变化最大的两项。
5. **撤支架**：成绩单里加一行“同样的推进，需要的打扰次数”。下降了，墨灵就主动少说话、把授权书里的上限建议往下调——成功的标准是他越来越不需要她。

## 7. 分析交流：她说话更像一个人

1. **模式**：对话页顶上一个模式条（工作 / 训练 / 启动 / 休息 / 陪伴），墨灵根据局面自己选并显示，他可以点改。不同模式提示词不同、成功标准不同（见 README 第 7 节）。
2. **连续语音对讲**：按一下开始，墨灵说完自动听下一句，“好了”结束。用系统语音识别 + 系统朗读，不接云端语音。
3. **训练模式**：一手式追问——“依据是哪一句？接下来会怎样？有没有反例？”他每答一轮，墨灵只指出一处漏洞，答完给一个分数进记忆。
4. **反驳我 / 疯想—冷判**：对话里两个按钮。“反驳我”让墨灵专挑他上一个判断的漏洞；“疯想”让墨灵（或演员）3 分钟里给最离谱的路线，再逐条标“事实 / 假设 / 可以试”，只留一个最便宜的小实验进今天的水道。
5. **和演员的交接一步到位**：点“去聊”→ 开场白自动复制 → 打开 Gemini / ChatGPT → 小窗挂在边上计时、给下一问 → 回到墨灵时自动读剪贴板接住收线（第 2 节）→ 结论进体系图、下一步进水道（提议）。
