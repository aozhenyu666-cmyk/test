## 1. 要的是什么

一个**会自己想事情的伙伴**。我什么都没说的时候，她也大概知道我现在在哪、卡在哪、下一步该聊什么；我去和 GPT 或 Gemini 说话时，她在旁边递问题；聊完，她把结论接回来，盯着它变成行动；系统哪里坏了，她会记下来，想办法修。

她可以是一个熟悉的女性角色，有固定的说话风格，会陪我、追问我、给我出新主意，也会在我们约好的范围里坚持。她不只是监工：我休息、打游戏、闲聊的时候，她也可以只是陪着。

**一个前提**：深度对话用的是 **Gemini 和 ChatGPT 的官方 App**（我有会员，比接 API 划算得多），尤其是 Gemini Live，额度很多。我们**不接它们的 API**，也不自己造语音模型。我们自己只用一个便宜的文字模型（DeepSeek API）做“导演”：分析、推演、准备问题、读回结果。

---

## 2. 现在卡在哪

1. **总控不了解我。** 它有规则、有眼睛，但没有一个持续在想“这个人现在怎么了”的脑子。我不汇报，它就只能按几条固定规则响；我一汇报，它又容易信我的话。
2. **聊不出东西。** 打开 Gemini Live 或 GPT，不知道说什么；说几句口水话就停了。Gemini Live 本身不笨，但它不认识我、没有议程，聊完也什么都没留下。
3. **系统坏了没人查。** 无障碍掉了、一手十天没打开、提醒被我划掉，这些事都没有人记录、分析、改进。每次都是我发现不对，再开一个新对话加功能，于是越加越乱。

## 3. 核心想法：导演、演员、接力棒、小窗

```text
          ┌───────────── 演员（官方 App，会员）────────────┐
          │  Gemini Live：长时间语音、看屏幕、看摄像头        │
          │  ChatGPT：深度文字思考、写长东西                 │
          └──────────────▲───────────────────┬──────────┘
            我把小窗上的问题说出口 │                   │ 我对小窗说一句结论 / 字幕被读到
          ┌──────────────┴───────────────────▼──────────┐
          │  小窗：浮在 GPT / Gemini 上面，导演和我之间的通道     │
          └──────────────▲───────────────────┬──────────┘
                         │ 现在这一问、追问、提示          │ 回应、结论
          ┌──────────────┴───────────────────▼──────────┐
          │  导演（总控里，DeepSeek 文字模型）                 │
          │  局面 · 接力棒 · 议程 · 推演 · 假设账本 · 事故簿 · 日记 │
          └──────────────▲──────────────────────────────┘
                         │ 事件、记录
                总控的眼睛和手（已有）＋ 健康监测 / 哨兵
```

- **演员**：Gemini Live 和 ChatGPT。它们能说会道，但不知道我是谁、今天怎么了。
- **导演**：总控里一个小文字模型。它不跟我长聊，只做三件事：**看懂局面、准备该说的话、读回结果**。一手语音伙伴 T3 早就设计过“导演卡”，这里把同一个想法用在官方 App 上：导演写卡，演员上台。
- **接力棒**：一个没想完的念头，包括正在回答什么问题、已经知道什么、卡在哪、下一问是什么。它其实就是一手的“断点”，现在升级成整个系统共用的东西。不管是手机换电脑、白天到晚上，还是 GPT 换 Gemini，接力棒都跟着走。
- **小窗**：浮在 GPT / Gemini 页面上的小窗口。演员接收不到导演的指令，但我能看到小窗，所以由我来传话。

**为什么这样能绕开“Gem 在 Live 里不能用”**：人格和上下文不需要预先装进 Gemini。每次开场时，我照着小窗念一段开场白（或者粘贴一次），Gemini 就进入角色；对话中途，小窗随时递给我下一问。导演这个角色，从头到尾都在我们自己手里。

## 4. 小窗（这一版的主角）

### 它长什么样

平时缩成一个小圆点（可以就是现在的墨灵），停在屏幕边上。我打开 Gemini、ChatGPT 或者导演认为该聊的时候，它展开成一张卡：

```text
┌───────────────────────────────┐
│ 墨灵 · 拆事 · 还剩 9 分钟          │
│                               │
│ 现在这一问：                     │
│ 申论第二题，你归纳的三个问题里，     │
│ 哪个是材料里没直接写、你推出来的？   │
│                               │
│ ▸ 可以接着问它：“这个推论哪里站不住？” │
│ ▸ 换个角度：“如果你是阅卷人，扣我哪分？”│
│                               │
│ [继续这一问] [卡住了] [有结论 🎤] [休息] │
└───────────────────────────────┘
```

- **一次只突出一个问题**，其他的折叠成“还有 2 个”。小窗不是题库，而是此刻的一句话。
- 问题下面给 1–2 句**可以直接念给 Gemini 的话**。我不用自己组织语言，照着念就行。
- 四个按钮就是全部操作：
  - **继续这一问**：没事，接着聊；
  - **卡住了**：导演换一个更小的问题，或者给一个起手提示；
  - **有结论 🎤**：我对着小窗说一句话（系统语音识别，免费），导演读回去，更新接力棒，推出下一问；
  - **休息**：小窗收起，切到陪伴模式。

### 它怎么跟上对话（三档，能做到哪档用哪档）

| 档 | 怎么做 | 前提 |
|---|---|---|
| **A 静态** | 开场时导演备好 3–5 个问题，按我点的按钮往下走 | 只要能显示悬浮窗 |
| **B 阶段确认** | 我每次点“有结论”说一句，导演据此出下一问 | A + 系统语音识别 |
| **C 字幕跟随** | 如果无障碍能读到 Gemini Live 屏幕上的字幕或 ChatGPT 的对话文字，导演每 30–60 秒看一眼最近几句，自动更新下一问；发现话题跑偏，提示我拉回 | 要实测（第 10 节）。读不到就停在 B，**不假装听见了** |

### 开场：怎么让 Gemini 进入角色

小窗第一屏是“开场白”：一段 100–200 字的话，内容是今天的人格设定、局面、接力棒和这一场的目标。可以用三种方式交给 Gemini，探针决定用哪种：

1. 粘贴进 Gemini 的文字对话，再从同一个对话进入 Live；
2. 通过系统分享，把开场白发给 Gemini App；
3. 进入 Live 后，照着小窗把开场白念一遍（最笨，但一定能用）。

### 收线

到时间或者我点“有结论”时，小窗问两句：“一句话，聊出了什么？”“下一步做什么，几点？”我用嘴回答，导演整理成结论、未解决的问题和下一步，写进接力棒。工作和训练会话需要收线；**陪伴和闲聊不需要交东西**。

## 5. 导演的脑子

导演跑在总控里，由事件叫醒（解锁、切换 App、计划到点、打开 GPT/Gemini、收到收线、夜里定时），平时安静。它维护下面这些东西，具体结构由你设计：

### 5.1 局面

“我现在大概在哪”。来源是总控已有的数据：今天的行动、前台应用时间线、娱乐和做事时长、账本、信用、最近的收线、一手的断点。

**导演要知道自己看见了多少。**没有收到产出，不等于没在做事；屏幕关着，不等于在睡觉；在购物 App 里待了一会儿，也可能只是在买菜。看不清的时候，先用最便宜的方式问一下：通知或小窗上一排按钮，比如“在做事 / 在休息 / 卡住了 / 在吃饭”，点一下就行，不用写字。

### 5.2 假设账本

导演每次做重要判断，都分开记几样东西：

- **看到了什么**（事实，带来源和时间）
- **猜是怎么回事**（假设，带把握）
- **还可能是什么**（别的解释）
- **怎么最便宜地分辨**（一个问题或动作）
- **之后什么时候回头看**

例如：“申论这件事两天没有新进展，今晚在闲鱼待了 12 分钟”只是看到的事实。“可能这件事阻力大”是假设。买东西、比价、休息也都可能。所以下一步是问一句，而不是加锁。

### 5.3 议程

导演想跟我说的所有事排成**一条队**，一次只拿出最重要的一件。总控现在的提醒、收集箱催促、强督导、一手叫我训练各自为政，以后都改成往这条队里投递，由导演决定先说哪一件、用什么方式说。

### 5.4 推演

每天早上，导演写一份很短的“今日预演”：今天最可能在哪卡住、为什么、提前备好什么（材料、第一问、B 方案）。晚上对照实际情况，看推演准不准。准了，它的话就更有分量；不准，就改推演方法。

### 5.5 事故簿：系统自己的失败

**导演不只看我的失败，也要看系统的失败。**以下情况都记成一条“事故”：

- 无障碍掉线（分清四层：权限关了 / 服务没连上 / 事件不来了 / 页面读不到）
- 提醒被划掉、连续没回应
- 一手 N 天没打开、总控时间被跳过
- 小窗被关掉、开场白交接失败
- 导演误判了（我点了“不对”）

每周导演做一次“事故复盘”，猜几种原因（入口太深？题太难？时机不对？太吵？设备问题？），选**一个**改动做一周试验，记下怎么回退。“一手为什么一直没用”就应该是这样一条有原因猜测、有试验的事故，而不是又一个新功能。

### 5.6 她的日记

导演每晚用伙伴的口吻写三五句日记：今天注意到了什么，对我好奇什么，明天想试试什么。

- 早上第一句话从日记里来（“昨天你说申论第二题卡在归纳，今天我们从这里开始？”）。
- 开场白里带上昨天的日记，Gemini 和 GPT 就能演同一个“她”。人格的连续性不靠 Gem，靠这几句日记。

### 5.7 情报

导演自己不上网，但它可以**派活**：

- 在开场白里让 Gemini 先做一件事：“先帮我查三条本周跟申论有关的时政，各用一句话说。”演员有搜索能力。
- 电脑开着的晚上，可以让电脑上的 Agent Bridge 调 Claude Code / Codex 整理一份“明日材料包”（这一项排在后面）。
- 我分享给总控的链接、截图、在 GPT 里聊出来的长文，进收集箱后由导演消化。

## 6. 天马行空清单（每条都有可以先做的第一步）

| # | 点子 | 为什么 | 第一步 |
|---|---|---|---|
| 1 | **疯想—冷判** | Gemini 爱瞎编，这一点刚好可以拿来发散思路。小窗上有个“让它疯一下”：让 Gemini 3 分钟里只管给出最离谱的路线，然后让导演逐条标“事实 / 假设 / 可以试”，最后只留一个最便宜的小实验 | 小窗加一张“疯想”卡，开场白模板里加两段指令 |
| 2 | **接力棒随身** | 思路断了，下次一句话接上：“刚才停在这里，现在只回答这一小问” | 解锁、打开 GPT/Gemini、回到总控时，第一眼看到的就是接力棒 |
| 3 | **今日预演 + 晚上对账** | 提前知道最可能卡在哪；准确率会让她的话有分量 | 早上写 2 条预演，晚上自动对照 |
| 4 | **事故簿** | 系统自己会修，不用我每次开新对话 | 先把无障碍四层健康、提醒被划掉、一手未使用三类记下来 |
| 5 | **她的日记** | GPT 和 Gemini 演的是同一个人 | 每晚 3–5 句，放进第二天的开场白 |
| 6 | **对手模式** | 我说完一个判断，让演员专门找漏洞；导演记下被戳中的地方，进复习 | 小窗按钮“让它反驳我” |
| 7 | **一分钟晨报** | 早上她用声音说 60 秒：昨天停在哪、今天预演、第一问 | 总控已有朗读，内容从日记和预演里拼 |
| 8 | **钱包镜子** | 打开购物 App 时，小圆点轻轻亮一下：本周零食几份、上次我们约定的是多少，再给一排按钮“买菜 / 零食 / 比价”。数字来自我们聊天时的约定，不预设 | 先做打开购物 App 时的一问和支付通知记账。支付页本身可能挡不住，不在那里做文章 |
| 9 | **陪玩模式** | 打三角洲时不催；如果想有人陪着说话，就开 Gemini Live 共享屏幕（Gemini 那边的功能），导演只管约好几局、到点轻声提醒 | 先做“陪伴模式”和约定结束时间 |
| 10 | **夜间情报员** | 晚上电脑空着，替明天准备材料 | 等前面跑稳，用 Agent Bridge 派一个任务试试 |
| 11 | **撤支架** | 启动和恢复变稳以后，她就少说话；成功的标准是我不太需要她，而不是她管了我多久 | 每周看一次：同样的推进，需要的打扰次数是否在下降 |

## 7. 模式

| 模式 | 她怎么做 | 什么算成功 |
|---|---|---|
| 工作 | 有议程，推一步，适时收束 | 产生一个判断、证据或开始了一个动作 |
| 训练 | 一手式追问：依据是哪一句、接下来会怎样、有没有反例 | 一个真实的推理步骤 |
| 启动困难 | 只要一个点选、一个词或一句话 | 连上了，知道卡在哪 |
| 休息 | 陪着，或者安静；约定什么时候回来 | 按时回来 |
| 陪伴 / 游戏 | 闲聊，不考核 | 我觉得愉快 |
| 降级 | 断网、模型不可用、无障碍掉线时，用缓存的问题和本地流程撑着，恢复后接上 | 不卡死，不乱加锁 |

## 8. 可靠性：健康监测和哨兵

无障碍健康要分四层看：**权限开没开、服务连没连上、事件来不来、目标页面读不读得到**。只看开关是开着，不能说明它在工作。另外要分清两种情况：系统意外掉线，要自动修；我自己在设置里关掉，要尊重，但会记下来。

我仍然希望有一个**独立的小哨兵 App**：vivo 冻结的是总控整个进程，总控自己的自愈也跟着停了。哨兵的做法第二版写过（[`v2-design.md`](v2-design.md) 第 6 节）：掉线就重新拉起；拉不起就冻结娱乐 App（Shizuku）；用“使用情况访问”当第二双眼睛。建议先在总控里把四层健康记录做出来，跑几天看掉线到底掉在哪一层，再做哨兵。

## 9. 守住的底线（必须遵守）

1. **规矩在代码里，模型说了不算。**模型可以选时机、出问题、提建议；不能自己放宽规则、发娱乐时间、扩大监控范围、改紧急退出。放宽仍然走现有的 24 小时冷静期。
2. **演员说“完成了”不算完成。**Gemini / GPT 的总结只是“说法”，要和总控的记录、我的确认对得上，才能改状态。
3. **猜测不写成事实。**没把握时先问；不编心理故事，不说“我识破你了”之类的话。
4. **电话、短信、支付、地图、紧急退出永远不当惩罚手段。**冻结都有到期时间。
5. **不接 Gemini / GPT 的 API，不自己做语音模型。**演员只用官方 App。
6. **读不到就说读不到。**小窗读不到字幕时降到 B 档，不假装知道对话内容。
7. **数字由我定。**零食份数、时长、预算等等，都由我和她聊出来写成约定，不要预设默认值强加给我。

## 10. 先验证的事（探针）

这些决定了哪些路能走。能写成小工具的就写，比如一个调试页里的“探针”按钮；需要我在手机上操作的，写成 5 步以内的说明。

| # | 要验证 | 通过算什么 | 不通过怎么办 |
|---|---|---|---|
| P1 | 小窗能不能浮在 Gemini Live 全屏界面和 ChatGPT 语音界面上 | 能看见、能点 | 改用通知栏卡片或耳机提示音 + 朗读 |
| P2 | 无障碍能不能读到 Gemini Live 的字幕 / ChatGPT 的对话文字 | 能连续读到最近几句 | 停在 B 档 |
| P3 | 开场白怎么交给 Gemini：粘贴后再进 Live 还记不记得；分享到 Gemini 是否预填 | 进 Live 后问“我们今天聊什么”，它能答对 | 照着小窗念 |
| P4 | 从总控能不能直接打开 Gemini Live（而不只是 Gemini 首页） | 一步进 Live | 打开 Gemini，小窗提示点哪里 |
| P5 | 系统语音识别在小窗里能不能用（vivo） | “有结论”能听写 | 打字，或者用总控已有的听写接口 |
| P6 | Gemini Live 能不能读写 Google Tasks 里指定的清单 | 能读出、能按格式写 | 不走这条，全靠小窗收线 |
| P7 | 无障碍掉线在 vivo 上实际掉在哪一层 | 一周日志 | 决定哨兵怎么做 |
| P8 | 导演每天实际花多少钱 | 调试页有真实的累计花费 | 加缓存、少叫模型，或者设每日上限 |

## 11. 建议的第一刀

一个场景从头跑到尾，比十个功能各做一半有用。建议先做这一个：

> **约定的做事时段里，主线没有新进展，我在刷短视频。**

1. 总控记下看到了什么，以及无障碍健康状况；
2. 导演写一条假设（带别的解释），从议程里拿出这件事；
3. 小圆点亮起，问一个点选题（在做事 / 休息 / 卡住了 / 在吃饭）；
4. 选“卡住了” → 小窗给出接力棒和一个小问题，并提议“去和 Gemini 聊 10 分钟”；
5. 打开 Gemini，小窗给开场白，开始一问一问往下走（先做到 A/B 档）；
6. 收线，用嘴说一句 → 接力棒更新 → 下一步变成行动；
7. 30–60 分钟后，导演看这个行动开始了没有；没开始，就分清是任务太大、问题问错了、提醒时机不对，还是设备出了问题，写进事故簿，调整下一次。

第一刀只需要支持一部手机、一条主线、Gemini 一个演员、小窗一个通道。电脑、GPT、消费、陪玩以后再接。

## 13. 成本

- **演员**：会员，不另外花钱。
- **导演**：DeepSeek API。只在事件过了门槛时才叫它，固定的设定放在提示词最前面以命中缓存，每次只带最近几轮和接力棒。花了多少，必须**在调试页显示真实累计值**，并且能设每日上限；超了上限就退到本地模板，不停摆。
- 我原来以为文字模型很贵，所以第一个月请把真实花费记下来，再决定要不要省。

## 15. 路线

| 阶段 | 内容 | 看什么 |
|---|---|---|
| 0 | 探针 P1–P8；四层健康记录 | 知道哪些路能走 |
| 1 | 第一刀（第 11 节）：导演最小版 + 小窗 A/B 档 + 接力棒 + 收线 | 一周里，导演主动发起、在 Gemini 里收线、之后真的开始做事的次数 |
| 2 | 事故簿 + 每周复盘；日记；今日预演 | 系统能说出自己哪里没起作用，并且改了一处 |
| 3 | 哨兵（看 P7 的结果）；小窗 C 档（看 P2 的结果）；GPT 作为第二个演员 | 掉线恢复时间；跟上对话的准确度 |
| 4 | 钱包镜子、陪玩模式、对手模式、疯想—冷判 | 按点子各自验证 |
| 5 | 电脑接入、夜间情报员、撤支架 | 同样的推进需要的打扰越来越少 |

不追求“聊满多少分钟、问了多少题、锁了多少次”。看的是：**她主动出现的时候有没有依据、我有没有接上、之后有没有真的做了什么、失败了她有没有学到东西。**
