# 总控

帮一个容易忘目标、思考中断、迟迟不启动的人，把讨论过的事情推进到实际结果。

- **0.6：三个部门各有一套体系、会说话的墨灵**：谋划思考部内置「脉络」（体系 → 层级 → 节点 → 关系，和脉络 App 同一种文件）；信息收集部的漏斗；统筹规划部的估时校准、精力地图、倒推规划；桌面墨灵和小部件、对讲、通知里直接回复、一天三次主动问候；一律北京时间；八种线条动效
- **总控者（0.5）**：AI 不再是陪聊的参谋，而是有宪章、有档案、有眼睛的总控。你说“我做了 5 小时饭”，它先查手机那 5 小时在干什么，对不上就直说；答应的事记成约定，到点自己回头查；信用掉了态度就变硬
- **总控时间（0.4）**：每天固定半小时，手机“万籁俱寂”——只剩总控、电话和你允许的几个应用。按 静 → 收 → 谋 → 筹 → 行 → 封 把四个部门修一遍，夜空和一棵随环节生长的树陪着
- **叫得醒你**：到点震动（像闹钟，不是一下就完）、全屏通知；几天不理它就一级级收紧，直到把你拉进总控时间
- **参谋会主动找你**：早上、中午、该开总控时间时它先开口；能看截图，能把回复念出来
- **打开就知道干什么**：首页只放此刻要看的一条（严管怎么解除、早上去部署、晚上去复盘）和现在这一步
- **一步一步带着走**：晨间部署、晚间复盘都是向导，一屏一个问题，点选为主
- **参谋（AI 对话）**：直接跟它说事，它能建事项、排行动、开专注锁、改节律、把事交给一手、替你打开页面、给首页加按钮
- **四个部门各有一页**：收集、谋划、统筹、行为管理，每页只放这个部门自己的事
- **和一手连着**：行为管理部直接读一手的训练组数验收；一步行动可以交给一手陪练；总控严管时一手不重复拦
- **断了能接上、结果有去处、没推进先问原因、约束还在**（同 0.2）

## 0.9.2：主动性（试验）

### 无回应强督导与一次缓行（2026-10-18）

- 首页 **强督导与补交**，或“我 → 强督导与一次缓行”进入。强督导首次安装/升级默认关闭，手动开启后才生效；缓行不依赖这个开关。
- 实际发出主动询问后，默认在 **30–60 分钟**内抽取一次接管时刻，重发/重启不重新抽取；到点前预告。一直不回应且无障碍真正在线时，进入随机 **15–30 分钟**总控时间，沿用电话、紧急呼叫等白名单。每天最多两轮，结束后冷却一小时；睡觉、休假和检查时段外不发起。无障碍故障时只能提醒，不宣称已接管。
- 每个逻辑日（北京时间凌晨 4 点换日）共 **一次 30 分钟缓行**，关卡、行动和总控时间共用。只延后选中的任务，其他关卡、娱乐额度、专注锁和低屏规则继续生效；不是整机放行。总控时间保留环节进度，到期恢复，也能点“现在继续”；提前恢复不会返还次数。
- 缓行不等于通过，也不消耗原有紧急放行次数。记录保存在本机，跨日保留；在补交页按原日期/原标准提交，不会通过今天的同名关卡。AI 没有发放缓行的工具。
- 每晚清单和 AI 的 `today_report` 现在包含所有当天关卡（包括日终总结）以及未补交的历史缓行，避免只列行动而漏掉总结任务。当前证据可用于迟交验收，会明确标记为迟交。
- 开启/收紧强督导立即生效，关闭/放宽沿用已有 24 小时生效规则。这次没有修复手机厂商的无障碍故障，也没有改动双向语音。

- **总控会主动来找你，但不是定时闹钟**：信息收集部按“欠账”来催——收集箱空着就少叫，压到 3 条就勤叫；被忽略会退避，下一轮会换语气、让参谋真的开口，连续三次没回应当天收手、次日恢复。硬下限 10 分钟、每天最多 6 次，配置提供总开关（本次未新增设置界面）。
- **该安静的时候一定安静**：睡觉时段、总控时间、专注计时且积压不足 3 条、刚和它说完话的 10 分钟内，都不打扰。
- **一手也会主动叫你走一手**：今天没走 → 一小时一次；在走但没达标 → 间隔翻倍，不打断节奏；达标 → 只留一次收尾。刚自己关掉窗口 45 分钟内不追，提醒里带上一手的断点。
- 规则和提醒状态流转在 `core/initiative`（总控）和 `initiative`（一手）里的纯函数，带 39 个单测；这些想法和没做完的记在 [`DEVLOG.md`](DEVLOG.md)。

## 0.9.1 / 0.9：外接谋划、多段对话、眼睛日志、低屏模式、动效打磨

- **外接谋划单**：Gemini / GPT / Notion 里聊出来的报告、计划、问题清单，整段贴进来；总控把它拆成“要做 / 风险 / 待决 / 事实”条目，挂到事项、行动、约定上，负责盯落实、要证据——它不替你重新谋划，只管理外面的谋划。
- **多段对话**：对话按段分开，旧的压成交接摘要带进下一段；每天默认最多新建 1 段，上下文不再无限堆。旧对话自动迁移，历史不丢。
- **眼睛日志（无障碍诊断）**：无障碍接上 / 掉线 / 被关 / 弹回 / 开着没跑都记下来，带今天的失联次数、时长和原因猜测，可分享导出；墨灵小部件在离线时闭眼显示“我看不见了”，点一下去权限页。
- **低屏模式**：闲鱼、Twitter/X 这类“全封太狠、放开太浪费时间”的应用，连续用 2 分钟就弹回做题页，冷却 10 秒再放行；题库可导入 TXT / MD 或粘贴。
- **0.9.1 动效打磨**：印章和标签颜色淡变、数字滚动、卡片错峰入场、页面推入带轻缩放、总控时间环节过渡、对话“回到底部”、完成盖章等；全部尊重系统“移除动画”。风格不变，只是层次更细。

## 0.8：今天的清单、预案、无障碍自愈、记一下、账本

- **今天的清单**（首页“今天”一栏，统筹规划部“今天的清单”）：照着记录列出今天排了什么、做了没有（✓ 做完 / ○ 没做 / ✗ 卡住 / → 改期）、另外做了什么、到期的约定、做事和娱乐时长、电脑、支出、明天第一步。没做的可以顺手点“做完了 / 明天再做”。
- **日终验收变简单**：交的就是这张清单（补一句明天第一步，可不写），不再由 AI 按标准逐条审、不再打回。老设置自动升级。问总控“今天哪些没完成”，它也照清单答，不另写报告。
- **预案（试验）**：把一天排成几段，每段写一个 B 方案（下雨、起晚、临时有事就换成什么做）。定稿后每段到点出声：开始前 5 分钟、开始、过半“速记一句做到哪了”、结束“交结果”；没法按 A 做就走 B 或写原因跳过，改预案要写为什么。也可以让总控起草。
- **无障碍自愈**：常驻服务每分钟看一眼。“开着但没在运行”时：在电脑上执行一次权限页里的 adb 命令授权后，总控自己关掉再打开；没授权就每 20 分钟大声提醒一次（通知 + 震动），点开就是权限页。
- **记一下 / 贴一段讨论**：桌面宠物的气泡里、信息收集部都有“记一下”，一句话直接进收集箱。在 Gemini、GPT 里聊过的，整段贴进来，总控开一场“消化讨论”：提炼结论、挂到事项上、定下一步。
- **立项**：新建的事很薄（比如“国考计划”下面只有“去查时间”），事项页会提议让总控展开：为什么做、做到什么算完、要弄清的关键事实（时间节点、要求）、里程碑、头两三步；晚上总控也会主动提一次。
- **它说为主**：行动到点、预案节点都会念出来（睡觉时段不念；在“语音”里可以关）。
- **账本（试验）**：我 → 账本。导入微信 / 支付宝导出的账单（CSV，只记支出、重复导入不会记两次），手记一笔，或者把付款截图发给总控让它记；看今天 / 本周花了多少、花在哪。
- **电脑版 0.2.0**：放宽规则要写理由，交给总控审——批了 24 小时后生效，驳回作废、6 小时内不能再申请，没接 AI 等 72 小时。
- 这些想法、做了什么、还没做的，都记在 [`DEVLOG.md`](DEVLOG.md)。

## 0.7：战友模式、大统筹 / 大谋划、三个部门自动跑

- **战友**：总控的设定从“上级 / 验收者”改成并肩作战的战友——目标一致、说“我们”、每次开口都带一个 25 分钟内能做完的下一步，主线上不让步。
- **强度跟着信用走**：主动程度多了一档“战友”（每半小时开口问一次、解锁手机就问、截图抽查 6–8 张 / 小时、每天抽查 8 次、连续娱乐 20 分钟就找你）。信用掉到 60 以下自动至少“黏人”，40 以下自动“战友”；首页“今天”里和档案页写着现在实际是哪一档、为什么。
- **爬回来的路**：它问你，15 分钟内回 +1（一天最多 4 次）；问了不回一天最多扣 4 次（问得勤也不至于一天扣光）。
- **截图不再白丢**：截图机会按时间一直攒，熄屏、锁屏时也攒；解锁后 20 秒到 3 分钟内补上，间隔随机。
- **战役**：统筹规划部“大统筹”（长期目标 → 里程碑 → 这周交出什么 → 排进时间 → 预演最危险的地方），谋划思考部“大谋划”（选题 → 拆开 → 假设 → 对立 → 结论和最便宜的验证，写进脉络），信息收集部“整理收集箱”。总控一段一段带着走，阶段说明一直带在它脑子里；也可以在对话里说“开一场大统筹”。
- **长期目标有了里程碑**：大统筹里从截止日倒推，过期没做的会被点名。
- **三个部门自动跑**（要接 AI）：早上主线没定，总控直接替你定一步；晚上收集箱积压 ≥ 3 条，先替你提炼最多 5 条；周六上午挑一个假设、排一个 30 分钟的验证；周日傍晚下周还没计划，提议开大统筹。
- **首页**：“现在这一步”放到最上面；“今天”一组放计划、总控时间、**电脑**、信用和强度；然后是接下来、等你处理、四个部门。
- **电脑**：首页多了电脑一栏（没连时提示去装电脑版、配对）；手机信用掉到严格，电脑问得更勤、放行按两边更严的态度。
- **修**：总控时间最后“封存”时间到了却点不了（在“封”这一步要待满一分钟，按钮却只显示总时间 0:00）——现在待满 20 秒就能封，按钮上写真正还要等多久；无障碍服务所有回调兜底、重活移出主线程，不容易再被系统标成“出现故障”。

## 0.6：三个部门的体系、会说话的总控

### 谋划思考部 · 脉络（内置）
「脉络」App 的核心搬进了总控（四部 → 谋划思考部 → 脉络卡；或者 我 → 脉络）。
- **结构**：体系 → 层级（最多 3 层）→ 节点 → 关系。节点 = 一句结论 + 3–5 个激活词 + 把握 + 验证方式；关系只有 7 种：属于、导致、支撑、反例、对立、前置、类似
- **录入**：贴一段材料，AI 拆成候选卡片；**你逐张确认才写入**（可能重复的会提示并进已有节点）。假设没写验证方式不让“全部接受”
- **提问 / 延展 / 设计验证**：只把相关子结构打包发给 AI（路径、节点、一跳邻居、激活词，超预算按规则砍），发送前能预览、逐项删减、看到“整库 X token → 本次 Y，省 Z%”；回答按结构先行的格式显示，“建议新增”一键进候选
- **溯源**：沿“导致”找根因、看后果，沿“前置”排学习路线；**体检**：把“好听的故事”冒充规则的地方挑出来打分；**温故**：间隔 1、3、7、15、30、60 天翻卡，假设优先
- **和脉络 App 互通**：菜单里“从脉络 App 的文件夹导入”（选手机上的 文档/脉络）、导入 / 导出 Obsidian 仓库 zip，文件格式和脉络 App 完全一样
- **总控会用它**：聊到想法时先 vein_search；新想法用 vein_propose 提议（进候选，你确认）；你说验证做了，它 vein_backfill 回填；问候时会问“这个假设这周验证了吗”

### 信息收集部 · 漏斗
收得进，更要消化得了。每条回答三问：**这是什么**（一句话收获）、**给谁用**（挂到哪件事，或送进脉络拆）、**什么时候过期**（念头 3 天、材料 7 天、问题 14 天）。
- 状态：新收 → 已提炼 → 已归位；过期没处理的提示“当初不该收”，一键丢掉
- **节食**：每天新收上限 10、待提炼上限 15，超了先消化再收（潮汐的水位就是积压）
- **来源账本**：B站、公众号、知乎、ChatGPT……各收了多少、用上多少，有用率低的来源该断

### 统筹规划部 · 校准、精力地图、倒推
- **估时系数**：计划时长 vs 实际（开始 → 暂停 / 做完）的中位数。“计划 60 分钟的事你实际要 90 分钟”——排时间时总控按这个放大
- **精力地图**：最近 14 天每个钟头真正在做事的分钟数，主线排在最好的那几格
- **倒推规划**：跟总控说“帮我倒推：某件事，截止哪天，大概哪几步”，它从截止日往回排，一天一步、留一天余量、时长按系数放大、放在精力最好的钟头，直接建行动
- **在制品上限**：同时进行中超过 3 步会提醒

### 会说话、会主动找你的总控
- **桌面墨灵**：一只线条画的小墨灵浮在所有应用上（借无障碍的悬浮层，不用另开权限）。点它看它最近说的话；**按住对它说话**，松手发出去，回答显示在气泡里并念出来；拖动挪位置；颜色跟着态度变，严格时旁边有一道小闪电，睡觉时段会睡着
- **桌面小部件**：长按桌面 → 小组件 → 总控 · 墨灵：信用、态度、最近一句，“说话”直接进对讲
- **对讲页**：按住大圆说话（配了语音接口）或点一下用手机自带的语音输入；回答念出来，它问完可以接着听你回答
- **语音接口**（我 → 对讲、语音、墨灵 → 语音设置）：OpenAI 兼容的 /audio/speech 和 /audio/transcriptions，填地址和密钥就能用更自然的声音和听写；不填用手机自带的
- **通知里直接回复**：总控发来的通知有“回复”，在通知栏打字回它，回答也回到通知里
- **主动程度**：安静（只在出事时）、**标准**（默认：上午、下午、晚上各问候一次，时间每天挪一挪；再加抽查、回访）、黏人（每一个半小时）。问候一定会开口——没接 AI 也会问一句固定的话；调低要等 24 小时

### 其他
- **一律北京时间**：手机时区设成别的、出差，换日、定时都不受影响
- **八种线条动效**（我 → 线条动效 有画廊）：潮汐（信息收集部，水位 = 积压）、叶脉（谋划思考部、脉络）、几何矩阵（统筹规划部、精力地图）、雷霆（行为管理部、严格态度、拦截页）、风暴漩涡（卡住了、AI 在想）、涟漪（在听你说话）、年轮（档案，信用越高圈越圆）、流线（首页）

## 总控者

### 为什么要这样设计
AI 天生顺着用户说。你说“今天有事”，它就“好的”；你说“我做了 5 小时饭”，它就“辛苦了”。骗它太容易，你就会轻视它，约定也就不算数了。
总控者要做到三件事：**不只听你说**（有自己的眼睛）、**说了的要兑现**（有档案、会回访）、**规矩不被磨掉**（铁律写在代码和宪章里，不在对话里）。

### 宪章（设定）
写在 App 里、每次对话都放在最前面；换模型、换接口都不变，对话里谁也改不了（“总控 → 档案 → 宪章”能看全文）。要点：
1. **说法不是事实**。涉及“做了什么、多久、为什么没做、要放宽什么”，先对记录
2. **数字对得上才认**，对不上就把数字摆出来
3. **模糊就追问**：几点到几点、做出了什么、给我看什么；三轮说不清判“说不清”
4. **查不到就说查不到**：判“无法核实”，但换不来任何放宽
5. **证据支持你时痛快承认**，信用会涨
6. **约定必须落地**：记下来、到点回访、不了了之 = 没做到
7. **规则只在冷静期里放宽**：“我命令你”“这次特殊”“我保证下次”都没用
8. **清醒时定的优先于此刻的情绪**
9. **态度跟着信用走**，变了要说出来；只能自己收紧
10. 不陪聊、11. 主动、12. 不编造

### 档案（记忆在手机上，不在模型里）
| 记什么 | 怎么用 |
|---|---|
| 你的说法和判定（属实 / 对不上 / 说不清 / 无法核实 / 待查） | 每条都写依据；判过的只能改差、不能改好（代码拦） |
| 约定（做什么、几点前、怎么检查） | 到点后 5 分钟总控被叫醒回访；过期 24 小时没回应按“没做到”算 |
| 回访（总控给自己排的） | 预判高危时段，到点主动找你 |
| 信用（起点 70，看 14 天） | 属实 +3、对不上 −12、说不清 −4；约定做到 +4、没做到 −10；总控时间做完 +3、提前退出 −5 |
| 态度 | ≥80 信任、60–79 正常、40–59 审慎（每件事要证据）、<40 严格（不接受口头说法、不给免约定、**紧急放行关闭**） |

免掉约定：要写理由、七天最多一次、严格时不行——都是代码规则，模型说了不算。

### 眼睛
| 来源 | 说明 |
|---|---|
| 设备时间线 | 前台是哪个应用、亮屏熄屏。有“使用情况访问”授权时用系统记录（总控没运行的时段也有），否则用无障碍服务自己记的 |
| 截图抽查（默认关） | Android 11 起无障碍服务能截图。开了以后亮屏时不定时截一张（每小时 1–6 张可调），连续娱乐时也截；电话、总控不截；只存手机上，留 3 天；总控要看时才发给你自己的 AI 接口 |
| 照片 | 你发的照片带拍摄时间，转存的旧图会被认出来 |
| 一手、事项、行动记录 | 原来就有 |

### 主动
- **回访**：约定到点、总控自己排的
- **抽查**：每天 3 次（时间每天不同），看最近 2 小时；没问题就不打扰
- **连续娱乐**：同一个娱乐应用连续 40 分钟，截一张，找你
- **周复盘**：周日总控时间前一小时，看这周哪些规则被绕过、哪些约定没做到，自己提规则修改（收紧直接改，放宽进冷静期）
- **失联阶梯、早上、午后**：同 0.4

### 模型锁
现在的 AI 接口能用时，换地址 / 密钥 / 模型要等 24 小时——免得不清醒时换一个听话的。接口坏了、第一次填、只加看图模型，立即生效。

### 0.5 修掉的“到点没进总控时间”
- **一次保存里既收紧又放宽，整份设置都要等 24 小时**：比如把时间提前、同时往白名单里加了应用 → 新时间也没生效，加的应用也“不见了”。现在收紧的部分马上生效，只有放宽的部分排队，设置页上标着“24 小时后可用”
- **下午点进去试过一次，晚上到点就不叫了**：现在只有到点前 3 小时内开始的那次才算“今天做过了”
- **无障碍服务被系统停掉时没有任何提示**：现在到点会全屏通知“总控被关掉了，锁不住手机”；首页最上面会提示缺了哪项权限；另加每半小时一次的看门狗闹钟
- **叫醒记录**：“我 → 权限与运行状态”最下面，记着每次提醒发没发、当时服务在不在

### 权限一览（“我 → 权限与运行状态”）
| 权限 | 必要性 | 手机里在哪（vivo） |
|---|---|---|
| 无障碍服务 | 必需 | 设置 → 快捷与辅助 → 无障碍 → 已安装的服务 → 总控（灰色点不开：应用管理 → 总控 → ⋮ → 允许受限制的设置） |
| 通知 | 必需 | 设置 → 通知与状态栏 → 应用通知管理 → 总控 |
| 准点闹钟 | 必需 | 应用管理 → 总控 → 权限 → 闹钟和提醒 |
| 全屏通知 | 必需（Android 14+） | 应用管理 → 总控 → 权限 → 全屏通知 |
| 不限制电池优化 | 强烈建议 | 设置 → 电池 → 更多电池设置 → 电池优化 → 总控 → 不优化 |
| 使用情况访问 | 强烈建议 | 设置 → 安全与隐私 → 更多安全设置 → 有权查看使用情况的应用 → 总控 |
| 后台弹出界面 | vivo 必开 | 应用管理 → 总控 → 权限 → 后台弹出界面 |
| 自启动 | vivo 必开 | i管家 → 应用管理 → 权限管理 → 自启动 |
| 后台高耗电 | vivo 必开 | 设置 → 电池 → 后台耗电管理 → 总控 |
| 锁定最近任务 | 建议 | 最近任务里按住总控 → 锁定 |

前 6 项总控能自己查到开没开；vivo 的 4 项系统不给查，页面上标“请确认”。**每次覆盖安装新版后，先看一眼无障碍还开着没有。**

## 总控时间

为“十天半个月不打开总控”准备的。它不等你想起来，到点就来找你，进来以后不聊完不放。

**进来以后**（首页“今晚 21:30 总控时间”那一条、我 → 进入总控时间、或到点的通知）：

| 环节 | 最短 | 做什么 | 算做完 |
|---|---|---|---|
| 静 | 1 分钟 | 跟着呼吸圈静下来 | 时间到 |
| 收 · 信息收集部 | 3 分钟 | 收集箱里没挂到事项的，一张张过：挂到哪件事 / 变成行动 / 转成问题交给“谋” / 先放着；脑子里还有的倒出来（可以说） | 收集箱清空 |
| 谋 · 谋划思考部 | 8 分钟 | 挑一件在等判断的事。接了 AI：参谋按今天的方法卡一次问一个问题，最后把判断记下来；没接：初判 → 最强的反驳 → 修正 → 24 小时内下一步。没东西可想就“随便憋一件” | 写下了一条判断 |
| 筹 · 统筹规划部 | 3 分钟 | 看今天的主线和本周计划，挑明天只推的一样，定时间 | 定好明天主线 |
| 行 · 行为管理部 | 2 分钟 | 对账：一手几组、娱乐几分钟、被弹回几次、今天被你忽略的提醒；给明天加一条约束（或不加） | 选了 |
| 封 | 1 分钟 | 自动汇总，改一改 | 整段时间到了才能封；没到就点印章回去再修一轮 |

- 进行中打开白名单以外的应用（包括桌面）都会回到总控时间；返回键不走；电话、闹钟、权限弹窗不受影响
- 封存后记一条“验收”记录（同步到 Notion），并交给当天的日终验收
- 真有急事：紧急退出，写清原因，会记下来，下次参谋会问
- 一手在总控时间里不弹自己的思考页（由总控统一弹回）

**叫醒**（我 → 总控时间与叫醒）：

| 时机 | 做什么 |
|---|---|
| 开始前 10 分钟 | 通知 + 短震 |
| 到点 | 全屏通知（锁屏也会亮）+ 连续震动最多 10 分钟，回到总控就停 |
| 到点 5 分钟还没进来 | 自动进入（可在设置里关）：再打开别的应用都会回到总控时间 |
| 一天没交流 | 参谋主动发一句话 + 重震（接了 AI 是它现想的，没接是固定的一句） |
| 两天 | 严管：娱乐应用打不开，直到跟参谋说几句或进一次总控时间 |
| 三天 | 下次打开白名单以外的应用，直接进总控时间 |
| 早上 / 中午 | 参谋问今天的主线、上午推进了没有 |

- 23:30–7:00 静音时段不震
- 关掉、推迟、缩短、放开应用都算放宽，24 小时后才生效；加长、提前、收紧立即生效

**参谋的新能力**：在对话里发截图（要么主模型能看图，要么在 AI 接口里填“看图模型”）；总控时间里可以把回复念出来（系统自带的语音）；它也可以自己决定“现在进总控时间”。

**要你在手机上开的**：通知权限、准点闹钟（我 → 权限）、全屏通知（Android 14 起要单独允许）；vivo 后台权限。

## 0.3 有什么

底部五个标签：

| 标签 | 放什么 |
|---|---|
| **今天** | 问候和严管状态 → 此刻要看的一条提示 → 现在这一步（开始 / 继续）→ 四个部门的进度环 → 随手按钮 → 等你处理 → 接下来的时间线 |
| **四部** | 四张大卡片，点进去是各部门的页面（见下） |
| **参谋** | 和 AI 对话。它能直接动手（见“参谋能做什么”） |
| **事项** | 所有事项，点进去看行动、记录、断点 |
| **我** | 运行状态、连接（AI 接口 / 一手 / Notion / ChatGPT）、规则 |

四个部门的页面：

| 部门 | 页面上有什么 |
|---|---|
| 信息收集部 | 收一条（说 / 粘贴 / 分享）、今天收进来的、还没挂到事项上的 |
| 谋划思考部 | 等你想清楚的事（带前情去 GPT / 问参谋）、最近的判断 |
| 统筹规划部 | 本周计划、晨间部署、晚间复盘、今天的时间线、有下一步还没排时间的 |
| 行为管理部 | 一手（今天几组、在练什么、陪练窗口、昨晚的规则；把当前一步交给一手）、总控管一手（现在收紧没有、上限几分钟、让一手开局）、专注锁、今天的娱乐时长和被弹回次数 |

每个部门页还有“这个部门的按钮”：参谋可以按你的要求给它加快捷按钮。

向导：
- **晨间部署**：今天最要紧的一件 → 第一步做什么 → 做多久、几点做 → 做到什么算完 → 盖章。排好的行动就是“今日部署”的证据，自动验收
- **晚间复盘**：今天每一步做完 / 做了一部分 / 没做 → 没做的卡在哪、明天再做还是取消 → 明天第一步 → 今天最大的偏差 → 交给日终验收
- **我卡住了**：先选卡在哪一步，再按原因（忘了 / 不会做 / 不清楚 / 时间冲突 / 去娱乐了 / 不想做）给办法

动效：卡片依次浮现、按下微缩、部门进度环走动、验收通过盖章、专注计时的呼吸圈和翻动数字、参谋思考时的三个点。系统里关了动画就全部静止。

## 计划模式

给抗拒做计划的人用：**计划是参照，不是排满的日程表。**

| 一份周计划里有什么 | 说明 |
|---|---|
| 方向 | 这周往哪走，最多 3 个（从手上的事项里点选，或写一个新的） |
| 交出什么 | 每个方向这周交出 1–2 样能检查的东西 |
| 节奏 | 每天给计划内的事多少分钟（预算，宁少勿多），哪天休息 |
| 预演 | 最可能在哪卡住 → 对策（如果晚上刷手机停不下来，就 20:00 开专注锁做主线） |

怎么定：
- **自己定**：统筹规划部 → 本周计划 → 进入计划模式。一屏一个问题，点选为主，上周没做完的会先带上，五分钟
- **让参谋起草**：跟参谋说“进入计划模式”，它看你手上的事、问一两个选择题，起草一份。**参谋只能起草，立项要你自己点**

立项后：
- 没有对应事项的方向建成事项，每样交出物在事项下建一步行动；记一条“计划”记录（同步到 Notion，GPT 也看得到）
- **今天的主线**：每天只推一样。晨间部署先从计划里挑；首页没有更急的事时就推主线
- 当前任务卡上标 **计划内 / 计划外**；开始一件计划外的事不拦，只问一句：加进计划，还是回到主线
- 交出物对应的那一步做完（达到），交出物自动打勾
- 想改就改：加 / 去掉一样都要写一句为什么，留痕不追责
- 周末“结束本周”：交出几样、每个方向花了多少分钟、计划外花了多少，一句话复盘，没做完的带到下一份

“本周计划”关卡（周日、周一）看的就是这里有没有一份立了项的计划，有就自动验收。

## 总控怎么管一手

一手是行为管理部的核心，但听总控的：

| 什么时候 | 一手怎么做 |
|---|---|
| 总控专注锁开着 | 一手照样问你一手，答对算数，但**不放行**，让你回去做事 |
| 总控严管中 | 总控会弹回的应用一手不重复拦；一手管的其他应用，每次最多放行 5 分钟，不能离线放行 |
| 落后于计划（主线过了时间 15 分钟还没开始；或者下午了，计划内的事一分钟没做） | 一手每次最多放行 5 分钟，不能离线放行；思考页上写着为什么、今天的主线是什么 |
| 按计划走着 / 休息日 | 一手照常 |

- 收紧时的上限（3 / 5 / 10 分钟）在行为管理部页面里改；关掉这项是放宽，24 小时后生效
- 总控还能让一手**马上开一局陪练窗口**：开始一步时打开“同时在一手开一局陪练”，或在行为管理部页面点“让一手现在开一局”，参谋也能做
- 一手只读总控的状态，不能改总控

## 参谋能做什么

参谋用你自己在“我 → AI 接口”填的模型（OpenAI 兼容接口，要支持工具调用；推荐 DeepSeek 的 deepseek-chat）。它每次都能看到此刻的总控（严管没有、关卡、当前一步、接下来、进行中的事）和它记住的你的习惯。

| 能做 | 说明 |
|---|---|
| 看 | 全局状态、事项列表和详情、关卡、一手的训练 |
| 事项和行动 | 新建 / 修改事项；加行动（中文时间：今晚 20:00-21:00）；改期；记结果（达到 / 部分达到 / 没达到）；取消；记念头、问题、材料、判断 |
| 开始做 | 开始一步并开专注锁，自动打开计时页 |
| 交给一手 | 把一步行动设为一手的当前任务，可以让一手马上开一局陪练 |
| 计划 | 起草周计划（你立项）、定今天的主线、标交出物、改计划（写为什么） |
| 节律和规则 | 新建 / 修改关卡、删关卡、改沉默检查和娱乐上限、拦截名单加减应用 |
| 界面 | 替你打开某个页面；在首页或部门页加快捷按钮（点了发一句话给参谋，或打开某页） |
| 记住 | 你的作息、习惯、偏好，以后每次都带上；“我 → 参谋 → ··· → 它记住的事”可以查看和清空 |

**它绕不过总控的规矩**：放宽的改动（推迟截止、删关卡、移出拦截名单、放宽额度）照样 24 小时后才生效；紧急放行、关无障碍没有对应的工具，只能你自己在界面上做。执行过的操作在对话里折叠成“已执行 N 个操作”，点开能看每一步。

## 和一手怎么连

两个 App 装在同一台手机上，直接在手机里互相问，不经过网络：

| 方向 | 做什么 |
|---|---|
| 总控 → 一手 | 读今天练了几组、目标几组、在练什么、断点、陪练窗口、昨晚总结的规则 |
| 总控 → 一手 | 把一步行动交给一手（同一步再交一次只更新，不重复新建） |
| 一手 → 总控 | 读总控是不是在严管、会弹回哪些应用、现在在做哪一步 |

- “一手训练”关卡（行为管理部）改成看一手的组数，够了自动打勾，不用写汇报
- 打开抖音这类应用时：总控在严管、会把它弹回去，一手就不再叠一层思考页；总控放行时，一手照常问你一手
- 一手的主控台多了“总控”一栏：严管没有、当前一步、今天的关卡
- 安全：两边都只认对方的包名和签名证书（写死在代码里），别的应用来问一律拒绝

已经装过 0.2 的：**我 → 关卡 → 「采用推荐节律」**，“训练打卡”会换成“一手训练”。

## 三个工具怎么分工

| | 负责 | 不负责 |
|---|---|---|
| **ChatGPT** | 复杂的思考：讨论、判断、拆解、定下一步 | 记住你的进度、提醒你 |
| **Notion** | 共享的工作记录：事项、行动、记录（材料、判断、结果） | 提醒、约束 |
| **总控** | 手机上的入口、提醒、续接、状态、约束；在 GPT 和 Notion 之间搬运和对账 | 替你思考 |

## 一件事怎么从讨论走到结果

所有东西都挂在**事项**上（编号 `ZK-XXXX`）：材料、问题、讨论出的判断、行动、结果、断点。三个部门是这条线上的三段，不需要你分类：

```
收集（材料、问题挂到事项上）→ 谋划（和 GPT 讨论出判断和下一步）→ 统筹（下一步排进时间、写完成依据）
        ↑                                                                              ↓
        └──────────── 结果、卡点回到事项里，GPT 下次接着判断 ←──── 行动（开始、做完、记结果）
```

一个完整的循环：

1. **在 ChatGPT 里讨论**。总控「去 GPT」会把这件事的前情（为什么、当前判断、停在哪、做过什么、结果）整理成一段话，复制并打开 ChatGPT。
2. **GPT 把结论交回来**。两种方式：
   - GPT 能写 Notion：它直接写进三个库，回一句【总控交接·已写入】
   - GPT 不能写 Notion：它输出【总控交接】块，你复制（或在 ChatGPT 里分享给总控），总控先给你看会改什么，确认后写入并同步到 Notion
3. **总控显示下一步**。首页任务卡：做什么、为什么、上次停在哪、做到什么算完。到点提醒；15 分钟没开始再追问一次。
4. **开始做**。可以开专注锁：做这一步时娱乐应用被弹回。中途离开就记断点（做到哪 / 卡在哪 / 回来第一件事）。
5. **做完记结果**。对照完成依据：达到 → 完成；部分达到 → 待确认；没达到 → 问卡在哪。结果写进行动、事项和一条“结果”记录。
6. **同步到 Notion，GPT 续接**。「带着结果去 GPT」或者 GPT 直接读 Notion，接着判断下一步。

## 收集

想到什么先收下，原文完整保留。类型（念头 / 问题 / 材料）、标题、链接的网页标题、可能相关的事项都自动猜好，点一下就挂上。可以说出来（系统语音识别），也可以在任何 App 里**分享**文字、链接、截图给总控。截图只存在手机里，Notion 里记文字和截图位置。

## 没推进时

| 原因 | 总控怎么帮 |
|---|---|
| 忘了 | 现在开始，或 30 分钟后再提醒 |
| 不会做 | 带着前情去 GPT 拆成小步；或者先做 5 分钟 |
| 不清楚 | 改写完成依据；或去 GPT 澄清 |
| 时间冲突 | 改期（同步到 Notion，GPT 能看到推迟过几次） |
| 去娱乐了 | 开专注锁做 25 分钟 |
| 不想做 | 只做 5 分钟、改时间，或写原因取消 |

「查看结果」里会慢慢显示：提醒后多快开始、哪个时段的提醒最管用、最常卡在哪。

## 节律和约束（保留，重新调整）

| 关卡 | 默认验收方式 | 说明 |
|---|---|---|
| 今日部署（10:00 前，不部署不准娱乐） | **看事项证据**：今天至少 1 个行动排进了时间、写了完成依据 | 以前要写一段计划给 AI 判，现在看真实的安排 |
| 收集并关联（20:00 前） | 今天至少 2 条材料 / 问题 / 念头挂到了事项上 | 只数条数证明不了什么；挂到事项上才用得上 |
| 推进一个判断（21:30 前） | 今天至少 1 条新的判断记录（GPT 交接导入、Notion 里写的、自己写的都算） | 结论可以是“还需要补充信息” |
| 一手训练（21:00 前） | **读一手的组数**：今天至少练够 2 组（一组几手按一手的设置） | 够了自动打勾，不用写汇报；一手没装或太旧时会如实说读不到 |
| 日终验收（23:00 前） | AI 验收，**会看到今天各行动的状态和结果**、娱乐时长、被弹回次数 | 复杂内容的质量判断留给 GPT；这里只对账 |

已经装过旧版的：我 → 关卡 → 「采用推荐节律」。放宽的部分照样等 24 小时生效。看证据的关卡（今日部署、收集并关联、推进一个判断、一手训练）证据够了会**自动验收**，首页盖个章告诉你。

其余约束不变：沉默检查、每日娱乐上限、紧急放行、放宽规则延迟 24 小时、失联记录。新增**专注锁**：做一步行动时，到计划结束（或默认 45 分钟）前娱乐应用被弹回；记断点或做完就解开。

| 参谋（AI 对话 + 工具调用） | 已实现并在模拟器上用模拟 AI 接口验证；**真实模型待你确认** | 填好 AI 接口后在参谋里说一句“帮我把今天排一下”试试。模型不支持工具调用时会明确提示换模型 |

## 哪些以哪一端为准

| 数据 | 以谁为准 | 说明 |
|---|---|---|
| 事项、行动、记录的内容和状态 | **Notion** | 手机上先改本机（立即生效、断网可用），再按字段写回 |
| 提醒时间的触发、专注锁、严管 / 放行、娱乐时长、紧急放行 | **手机** | 不依赖网络 |
| 节律关卡、规则 | 手机 | 不同步 |

- **断网**：改动进“待同步”，联网后补写；首页显示待同步条数和上次失败原因
- **重试不重复**：新建前先打标记，请求发出没收到回复的，下次先按“总控ID”查有没有建成
- **两边都改了同一处**：后改的为准，另一份保留在事项 / 行动页，你选“保留现在的”或“用另一份”
- **只写改过的字段**：不会把 GPT 刚写的别的字段覆盖掉
- **库里缺列**：跳过并提示，不会卡住
- **在 Notion 里删除页面**：不会自动从手机删除；要取消请把状态改成“取消”

## 已知限制

- **截图只存在手机上**：Notion 里只记文字和截图在手机上的位置（没有接 Notion 的文件上传）
- **Notion 里删掉的页面**不会自动从手机上消失；要取消请改状态
- **弹回偶尔慢**：极少数应用的第一个窗口会以别的包名上报（比如系统设置的搜索组件），这时要等总控下一次检查（最多 20 秒）才弹回
- **数据库不能有多个数据源**（Notion 2025 年的新功能）：总控用的 API 版本读不了这种库
- **ChatGPT 不会被自动唤醒**：总控能做的是把前情备好、打开 ChatGPT；对话要你自己发起
