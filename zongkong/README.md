# 总控

帮一个容易忘目标、思考中断、迟迟不启动的人，把讨论过的事情推进到实际结果。

- **随时知道**：现在最重要的一步是什么、为什么做、上次停在哪、怎么继续、做到什么算完
- **断了能接上**：做到一半离开，记三句话；回来从断点继续，去 GPT 时前情自动整理好
- **结果有去处**：做完的结果写回记录、同步到 Notion，GPT 下次直接接着判断
- **没推进时先问原因**：忘了、不会做、不清楚、时间冲突、去娱乐了、不想做——各有各的办法
- **约束还在**：关卡没交、太久不汇报、娱乐超额、专注锁期间，抖音 B 站这类应用打开就被弹回

## 三个工具怎么分工

| | 负责 | 不负责 |
|---|---|---|
| **ChatGPT** | 复杂的思考：讨论、判断、拆解、定下一步 | 记住你的进度、提醒你 |
| **Notion** | 共享的工作记录：事项、行动、记录（材料、判断、结果） | 提醒、约束 |
| **总控** | 手机上的入口、提醒、续接、状态、约束；在 GPT 和 Notion 之间搬运和对账 | 替你思考 |

## 一件事怎么从讨论走到结果

所有东西都挂在**事项**上（编号 `ZK-XXXX`）：材料、问题、讨论出的判断、行动、结果、断点。三个部门是这条线上的三段，不需要你分类：

```
收集（材料、问题挂到事项上）→ 谋划（和 GPT 讨论出判断和下一步）→ 统筹（下一步排进时间、写完成依据）
        ↑                                                                              ↓
        └──────────── 结果、卡点回到事项里，GPT 下次接着判断 ←──── 行动（开始、做完、记结果）
```

一个完整的循环：

1. **在 ChatGPT 里讨论**。总控「去 GPT」会把这件事的前情（为什么、当前判断、停在哪、做过什么、结果）整理成一段话，复制并打开 ChatGPT。
2. **GPT 把结论交回来**。两种方式：
   - GPT 能写 Notion：它直接写进三个库，回一句【总控交接·已写入】
   - GPT 不能写 Notion：它输出【总控交接】块，你复制（或在 ChatGPT 里分享给总控），总控先给你看会改什么，确认后写入并同步到 Notion
3. **总控显示下一步**。首页任务卡：做什么、为什么、上次停在哪、做到什么算完。到点提醒；15 分钟没开始再追问一次。
4. **开始做**。可以开专注锁：做这一步时娱乐应用被弹回。中途离开就记断点（做到哪 / 卡在哪 / 回来第一件事）。
5. **做完记结果**。对照完成依据：达到 → 完成；部分达到 → 待确认；没达到 → 问卡在哪。结果写进行动、事项和一条“结果”记录。
6. **同步到 Notion，GPT 续接**。「带着结果去 GPT」或者 GPT 直接读 Notion，接着判断下一步。

## 首页

- **当前任务卡**：正在做 / 现在该做 / 上次做到一半 / 过了时间还没做 / 今天接下来 / 还没排时间
- **四个入口**：继续上次、收集念头、我卡住了、查看结果
- **等你处理**：待确认的结果、卡住的行动、有“下一步”但没排进时间的事项
- **接下来**、**今天的节律**（关卡）、**同步状态**（如实显示：已同步 / 待同步 / 同步失败 / 有冲突）

## 收集

想到什么先收下，原文完整保留。类型（念头 / 问题 / 材料）、标题、链接的网页标题、可能相关的事项都自动猜好，点一下就挂上。可以说出来（系统语音识别），也可以在任何 App 里**分享**文字、链接、截图给总控。截图只存在手机里，Notion 里记文字和截图位置。

## 没推进时

| 原因 | 总控怎么帮 |
|---|---|
| 忘了 | 现在开始，或 30 分钟后再提醒 |
| 不会做 | 带着前情去 GPT 拆成小步；或者先做 5 分钟 |
| 不清楚 | 改写完成依据；或去 GPT 澄清 |
| 时间冲突 | 改期（同步到 Notion，GPT 能看到推迟过几次） |
| 去娱乐了 | 开专注锁做 25 分钟 |
| 不想做 | 只做 5 分钟、改时间，或写原因取消 |

「查看结果」里会慢慢显示：提醒后多快开始、哪个时段的提醒最管用、最常卡在哪。

## 节律和约束（保留，重新调整）

| 关卡 | 默认验收方式 | 说明 |
|---|---|---|
| 今日部署（10:00 前，不部署不准娱乐） | **看事项证据**：今天至少 1 个行动排进了时间、写了完成依据 | 以前要写一段计划给 AI 判，现在看真实的安排 |
| 收集并关联（20:00 前） | 今天至少 2 条材料 / 问题 / 念头挂到了事项上 | 只数条数证明不了什么；挂到事项上才用得上 |
| 推进一个判断（21:30 前） | 今天至少 1 条新的判断记录（GPT 交接导入、Notion 里写的、自己写的都算） | 结论可以是“还需要补充信息” |
| 训练打卡（21:00 前） | 字数 | 行为管理部 App 负责练，这里只记一下 |
| 日终验收（23:00 前） | AI 验收，**会看到今天各行动的状态和结果**、娱乐时长、被弹回次数 | 复杂内容的质量判断留给 GPT；这里只对账 |

已经装过 0.1 的：设置 → 关卡 → 「采用推荐节律」。放宽的部分照样等 24 小时生效。

其余约束不变：沉默检查、每日娱乐上限、紧急放行、放宽规则延迟 24 小时、失联记录。新增**专注锁**：做一步行动时，到计划结束（或默认 45 分钟）前娱乐应用被弹回；记断点或做完就解开。

## 连接现状

| 连接 | 状态 | 说明 |
|---|---|---|
| 总控 → Notion 写入（新建、按字段更新） | 已实现并在模拟 Notion 上验证；**真实 Notion 待你确认** | 「设置 → Notion → 连接自检」用你的 Notion 走一遍写 → 读 → 改 → 增量查询 → 关联 → 清理 |
| Notion → 总控 读取并识别状态变化 | 同上 | 按 last_edited_time 增量拉取；GPT 改了状态、判断、新建行动都能识别，显示在「查看结果」 |
| GPT → Notion 写入 | **需要你配置**，取决于你的 ChatGPT | ChatGPT 内置的 Notion 连接一般只能读；接上 Notion 的 MCP 才能写。写不了就用交接块 |
| GPT 读 Notion 里的结果 | 需要你在 ChatGPT 里连 Notion（只读即可） | 没连也行：「去 GPT」会把结果整理进前情 |
| 跳到 ChatGPT 时带上下文 | 已实现，**真机效果待你确认** | ChatGPT App 没有公开的“带一段话开新对话”接口。总控复制前情并打开 ChatGPT，你粘贴；另有“分享给 ChatGPT”（取决于版本是否接收分享）和网页版预填。都不会自动发送 |
| ChatGPT → 总控 交回结论 | 已实现并在模拟器上验证（分享 → 预览 → 导入 → 写入 Notion） | 也可以复制后回到总控，首页会检测剪贴板 |
| Notion 变化实时推送到手机 | **当前接入方式做不到** | Notion Webhook 需要一台公网服务器转发。现在用“打开 / 回到前台 / 每 15 分钟 / 改动后 2 秒”拉取。Notion 的变化也不能唤醒一个 ChatGPT 对话 |

## 哪些以哪一端为准

| 数据 | 以谁为准 | 说明 |
|---|---|---|
| 事项、行动、记录的内容和状态 | **Notion** | 手机上先改本机（立即生效、断网可用），再按字段写回 |
| 提醒时间的触发、专注锁、严管 / 放行、娱乐时长、紧急放行 | **手机** | 不依赖网络 |
| 节律关卡、规则 | 手机 | 不同步 |

- **断网**：改动进“待同步”，联网后补写；首页显示待同步条数和上次失败原因
- **重试不重复**：新建前先打标记，请求发出没收到回复的，下次先按“总控ID”查有没有建成
- **两边都改了同一处**：后改的为准，另一份保留在事项 / 行动页，你选“保留现在的”或“用另一份”
- **只写改过的字段**：不会把 GPT 刚写的别的字段覆盖掉
- **库里缺列**：跳过并提示，不会卡住
- **在 Notion 里删除页面**：不会自动从手机删除；要取消请把状态改成“取消”

## 第一次用

1. **权限**：设置 → 权限与运行状态，开无障碍；vivo 按页面里的步骤开后台权限；开“准点提醒”
2. **拦截名单**：常见娱乐应用已勾好
3. **Notion**：电脑打开 <https://www.notion.so/profile/integrations> 新建集成 → Notion 里建一个“总控”页面并连接集成 → 设置 → Notion 贴密钥和页面链接 → 一键建库 → **连接自检**
4. **ChatGPT**：设置 → ChatGPT 配合 → 复制说明，粘贴到 ChatGPT 一个“项目”的说明里
5. 首页 → 挑一件事 → 带着前情去 GPT

## 开发

```
zongkong/app/src/main/java/com/zongkong/
  core/            纯 Kotlin，单元测试覆盖
    work/Work.kt       事项、行动、记录；同步状态
    work/Sync.kt       双向同步：增量拉取、按字段写回、三方合并、防重复
    work/NotionMap.kt  字段 ↔ Notion 属性（按库的实际结构写）
    work/Handoff.kt    GPT 交接：前情整理、交接块解析、导入预览
    work/Focus.kt      当前任务、提醒、关卡证据、什么对你有效
    work/WorkOps.kt    开始、断点、完成、卡住、改期
    work/TimeParse.kt  “明天 20:00-21:00”“周六 10:00”
    Engine.kt / Policy.kt / Verifier.kt   节律、严管、规则、验收
  app/             Android：界面、无障碍服务、提醒、同步调度
app/src/sharedTest/  Notion 模拟服务（单元测试和模拟器测试共用）
app/src/androidTest/ 端到端闭环测试（模拟器上用真实界面）
```

CI（`.github/workflows/zongkong-android.yml`）：单元测试 → 打包 → 模拟器上跑端到端闭环和拦截测试 → 都通过才更新 `zongkong-latest` 发布，附截图。
