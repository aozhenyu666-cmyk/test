# 弯道助手：从「水坝」到「河道弯道」

2026-10-31 · 写给自己看的方案，不是已完成的功能。0.16.1 只做了第 0 步（死因日志）。

## 一句话

现在的总控是**水坝**：定规矩、到点拦、违规弹回。你要的是**弯道**：不拦住水，但在水流过的每一个转弯处施一点力，让思绪顺着你想要的方向流。

## 是不是伪需求

**不是伪需求，但「每小时 10 次 AI 主动发消息」这个形式是错的。**

- 0.10 的日志已经证明过：总控只会发提醒时，「不理它反而最舒服」。每 6 分钟一条 AI 消息，三天后就会被你划掉、静音，变成背景噪音。
- 高频互动其实**已经存在**：你清醒时间 9 成在玩手机，每一次切换应用、每一次解锁、每一次打开娱乐 App，都是一次天然的接触点——一天几百次。总控的无障碍服务本来就看得到这些时刻。
- 所以弯道的做法是：**在这些转弯处放一个一秒钟、一下点击的小动作**，而不是另外制造消息。频率来自你自己的手机使用，强度可以调，AI 只在少数关键处出场。

## 为什么「主动说话」以前一直是废的

和无障碍崩溃是**同一个根**：主动消息靠的是手机上的 App 进程活着。vivo 把进程一清，计时器、无障碍、主动消息一起死。

「大肥鱼」能主动找人，是因为它**根本不住在手机上**：大脑在电脑 / 云服务器上跑，通过 QQ 发消息——QQ 是手机系统永远不会杀的应用。

→ 结论：**主动说话的大脑应该放到电脑或云上**（总控已经有电脑版 `zongkong-pc/`），通过一个手机不会杀的通道（QQ / 微信机器人、或者推送服务）找你。手机上的总控只做两件事：眼睛（看你在干嘛）+ 手（拦、弹回、出题）。

## 两种模式：参谋（聊）和总控（干）

像 GPT 的 Chat 和 Work：同一份档案和记忆，平时各干各的。

| | 参谋（Chat） | 总控（Work） |
|---|---|---|
| 说话方式 | 能争论：先复述你的观点，再给最强的反方，最后才给建议 | 简短，只执行：排、查、拦、验收 |
| 思考流 | 显示模型的思考过程（推理模型会单独返回这一段，折叠显示） | 不显示 |
| 能做什么 | 只能「提交给总控」一条结论 / 约定 | 调工具、改计划、记约定 |
| 规则能不能改 | 能吵，但改规则只能走哨兵的解除闸门 | 照规则执行 |

**争论在哪发生**：你不服总控的一条规则时，点「去参谋那里吵」——参谋负责跟你辩，辩完如果你还是要改，就走解除闸门（冷静期 + 手写）。这样「能争论」和「不能一吵就松」两件事同时成立。

## 信息收集部：不让你收集，让收集嵌进转弯处

你不会主动去填表。所以收集也放进弯道：打开娱乐 App 时问一下「这次是 [累了休息] [无聊] [逃避某件事]」，一下点击，就是一条数据。一周后总控就知道你什么时候、因为什么在逃。

不用的部门、要素在界面上收起来，只留你真在用的。

## 以刷题为核心

已有的底子：低屏模式「打开就答题」（`guard/GateActivity`）、一手的题库和训练。弯道里最重的一档就是「打开娱乐 App → 先做一题」，题来自一手。刷题量就是你一天打开手机的次数。

## 参考过的项目

- **大肥鱼（dafeiyu-astrbot）**：主动联系放在服务器上 + QQ 送达；「主动联系协调」——主动消息共用额度、有间隔、记录你没回的，你正在聊天时让路。
- **dsh-speak-up**：定时掷骰子，掷中才调用模型。省钱，也让主动不那么机械。
- **dsh-feiyu-mood**：区分「你在说话 / 它主动找你 / 它在干活」三种轮次，各自判断。
- **dsh-fish-memory**：会淡忘的记忆，长期事实（约定、画像）每轮都带。
- **dsh-bili-whale**：默认保守——「最多 @ 你三次」。克制本身就是让主动消息有分量的办法。
