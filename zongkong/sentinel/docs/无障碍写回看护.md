# 思维驾驶员、总控、一手的无障碍写回看护

在哨兵已有独立 `:watch` 前台服务增加 30 秒检查，不新增客户端健康协议，也不让其他应用互相守护。首页为思维驾驶员、总控、一手各提供一个开关（默认关闭），文件落盘并在看护进程每次重新读取。沿用哨兵现有 `WRITE_SECURE_SETTINGS` 声明，首页可复制授权命令：

```sh
adb shell pm grant com.zongkong.sentinel android.permission.WRITE_SECURE_SETTINGS
```

仅给哨兵授权就能由它写回目标组件，不需要为了这一项功能给一手授权。开启某项会拉起原来的看护前台服务；哨兵紧急暂停期间跳过本项。要在系统里手动关闭无障碍，先关对应看护及目标应用自身的自动写回。

已按源码核对组件：

- 思维驾驶员：`com.dshdriver.app/com.dshdriver.app.WatchService`（`ccr-8329c7b5-gr96ko`）
- 总控：`com.zongkong.app/com.zongkong.app.guard.GuardService`（`deepseek/zk-client-v2`）
- 一手主线：`com.yishou.app/com.yishou.app.gate.GateService`（`ccr-a5172662-j1jcik`，不包含 `.chalu` 岔路版）

组件未安装时跳过；已启用时不反复重绑；缺失时重新读当前列表、只追加目标，兼容短组件写法，读取回验并记录最近结果。思维驾驶员只显示设置写回结果，不把它加入原有三客户端的 HEALTHY 判定；原有挑战协议、恢复预算与锁屏仲裁不变。写回不是服务已恢复运行的证据。

NOT_TESTED：真机 force-stop 后 Android/厂商能否根据写回重新绑定服务，以及设备休眠时实际检查间隔。哨兵自身被强制停止或看护进程被杀后不能保证继续检查，当前版本仍需用户允许后台运行；不承诺 30 秒恢复。

验证：新增纯逻辑列表保留/去重测试；完整单元测试、APK 和 CI 结果见 PR。验证分支只生成 artifact；原分支才可更新固定下载页。
