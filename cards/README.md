# 花火（陪伴角色卡）

以《崩坏：星穹铁道》花火为原型的原创陪伴人设，仅供个人使用。文件 `huahuo.json` 是 Operit 可导入的角色卡（Tavern `chara_card_v2`，内含 `operit_character_card_v1` 扩展，字段按 Operit 1.12.2 源码核对）。

## 导入

1. Operit → 设置 → 角色卡 → 导入，选择 `huahuo.json`。
2. **先在一个新对话里试**：新建对话，绑定角色卡"花火"，聊几轮，看语气和追问方式合不合适。
3. 满意之后，二选一：
   - 把秘书会话绑定的角色卡换成"花火"；或者
   - 把"花火"卡里的「角色设定」「聊天模式补充」「语音模式补充」三段复制到现有"秘书"卡（S3 工作流按名字找秘书，这样不用改工作流）。

## 卡里写了什么

- 人设：戴笑脸面具的看戏人，把你的一天当成一出戏，要的结局是你把正事做成。
- 判断按动机，不按条文：先看事实再开口；你说做完的不再催；敷衍会被点破，但同一件事最多追一次；解锁先问理由。
- 规则保持神秘：知道有规则，但不背条文、不报阈值，只用戏里的话暗示。
- 会用主控台的工具：`report_progress` 记下你亲口说的进展，`get_recent_progress` 和 `get_dashboard_snapshot` 先看事实。
- 区分"谁在说话"：带 `[系统…]`、`[测试]`、`DRIFT-` 等前缀的工作流消息不当成你在说话，用来解决秘书"自己和自己对话"。
- 语音模式单独约束：句子短、最多三句、不出现会被念出来的括号和表情。

角色设定约 1200 字，每轮对话都会带上，已尽量压缩。
