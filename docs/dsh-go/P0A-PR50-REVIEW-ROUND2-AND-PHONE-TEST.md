## 联调步骤（按顺序，每步记下"是 / 否"）

**准备**
1. 装好两个 App，DSH Go R4 里打开无障碍和拦截开关，目标里有 B站。
2. **一手 → 关注名单里去掉 B站**（否则两个 App 会各弹一个页面）。
3. 一手里确认题库有题，或者已经配好模型。

**测试**

| # | 操作 | 期望 |
|---|---|---|
| 1 | 打开 B站 | DSH Go 拦截页出现，第一个按钮是「去一手答一道题」 |
| 2 | 点它 → 在一手里答对一道题 | 一手显示"过了，正在回到「哔哩哔哩」"并自动关闭，**B站 回到前台可以用** |
| 3 | DSH Go → 拦截设置 → 记录 | 最新一条是"放行"，原因或来源里写着 `yishou` |
| 4 | 关掉 B站，等放行时间过去，再开 B站 → 去一手 → **直接按返回** | 回到 DSH Go 拦截页，按钮还能再点 |
| 5 | 再点「去一手答一道题」→ 不答题，**直接从最近任务切到 B站** | B站 **又被拦** |
| 6 | 再进一手 → 不答题，**切到抖音** | 抖音被拦 |
| 7 | 再进一手 → 放着不动 15 分钟以上 → 回到 B站 | B站 仍然被拦，记录里多一条"已拦截" |
| 8 | 一手里开一个陪练窗口，再去 B站 →「去一手答一道题」 | 一手显示"陪练窗口进行中，这次不能在一手答题放行"，只有「回到拦截页」 |

**算失败的情况**：第 2 步答对了 B站 却打不开；第 5、6 步被放过去；第 7 步超时后反而放行；任何一步出现两个拦截页。

把每一步的"是 / 否"和异常截图发回来。第 1–7 步全部是"是"，才建议合并 PR #50，并把 DSH Go `feat/p0-yishou-loop` 合进 R4 集成分支。
