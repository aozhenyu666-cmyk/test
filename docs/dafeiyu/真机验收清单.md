## 0. 准备

1. 安装本轮的 `fish-build-N`（独立包名 `.fish`，可与旧版并存）。
2. 打开：主动搭话、无障碍、悬浮窗、通知、精确闹钟、电池不限制；选好大肥鱼的会话。
3. 抓日志：`adb logcat -s DshProactive DshIntercept DshFocus DshLoop DshA11yWatchdog DshEngineExit`。
4. 出问题先导出诊断：设置 › 手机操控 › 主动搭话 › 诊断 › **导出诊断**（见 D1-1）。

## 记录格式

结果只填一种：**通过** / **不通过** / **现象：……**。
