# 验收体系设计（2026-11-20 · 供强模型评审）

> 背景：用户提出「调度者 = 验收者」「验收大于一切」，并要求假定他意志力如水、AI 天生迎合，体系必须有一个坚硬的点。
> 本文是 Claude 在 fish-build-197 基线上的设计；《大肥鱼 v4 全链路闭环架构方案》的取舍也写在这里。

## 一、核心原则

1. **验收点是唯一的一等公民。** 局、Gemini、看视频、刷题都只是手段；系统只认「到点交没交出可被检验的东西」。
2. **硬点在时间，不在 AI。** 冷静的自己（前一晚）立约，热的自己（第二天）只执行；热的自己没有改约通道（尤利西斯合约）。
3. **打分只靠代码。** 模型只做整理（口述 → 卡片）和出反问，不参与计分；纯口头永远不算过。
4. **知识类的验收 = 延迟回忆。** 今天的产出是卡片，验收发生在 1 / 3 / 7 天后的复习；奖励分两次兑现。
5. **超脱的验收者在体系外。** 每周冷数据包交给用户 + 订阅制强模型（无 API，走复制粘贴协议），产出 ≤3 条调整，用户确认才生效。

## 二、封印（Commitment Seal）

- 只在前一晚 21:30 晚间对账时做；截止 23:00（待用户确认）。
- 每条：交什么（证据类型）、拉伸目标、保底线（默认拉伸的 50%）、几点前交、挂哪个节点。
- 落盘只追加；原始拉伸 / 保底永不覆盖；只能加码。
- 当天现定（晨间 / 开局时）也可以，奖励 ×0.7（待用户确认）。
- 豁免：要写理由，占当天紧急解除 1 次；原始数字保留，周验收可见。
- 谈判通道关闭：姐妹 / Gemini / 任何工具对已封印条目的调低请求一律拒绝，并记账。

## 三、证据类型与判定（代码）

| 类型 | 怎么验 | 现有基础 |
|---|---|---|
| 题（DSH 题库内） | 做了几题、对了几题 | bank_unlock |
| 题（外部 App，如粉笔） | 开工后的截图 + 该 App 当日分钟 | wall_auditor（screenshot / app） |
| 笔记 / 文件 | 开工后指定文件的字节增量；夜里须能提炼出 ≥1 张卡，否则周验收标异常 | wall_auditor（file） |
| 学习（视频 / 阅读） | 交出 ≥N 张卡（口述即可，夜里整理）；复习答对兑现另一半 | 新：卡片 + FSRS |
| 投递 / 外部动作 | 开工后的截图 | wall_auditor（screenshot） |

判定档位：拉伸（≥100%）/ 保底（≥50%）/ 未达（<50%）。没有封印的普通局保持现状（兼容）。

## 四、到点后果与奖励

- 到点未达保底：沿用契约逾期机制（1 分钟缓冲 → 严格锁），交上保底线即解，最长 60 分钟（待用户确认）；紧急解除始终保留。
- 奖励（挣来制）：拉伸 ×1.25、保底 ×1.0、未达 ×0；当天现定 ×0.7；学习类交卡给一半、首次复习答对给另一半。奖励累计、跨天结转（现有）。

## 五、作弊面（假定意志力如水）

见 Claude 回复表格：改口 / 口头冒充 / 旧截图 / 灌水 / 简单卡 / 低目标 / 紧急解除 / 卸载。
诚实边界：挡不住铁了心的作弊者；目标是让作弊比做更累，且必在周验收留下痕迹。

## 六、与现有部件的关系

- 计划编译器：封印从节点挑；验收结果写回节点 executionLog；节点进度 = 验过的产出。
- 局 / 主动点火：局是手段；点火对准下一个到期验收点。
- Gemini：常驻；回执口吻对准验收点；回执入卡片池；改不了封印。
- 墙：验收点的判官；墙页显示今日封印与进度。
- 锁：只用现有契约逾期路径，不新增判锁路径。
- 锁屏刷题：优先出到期复习卡。
- 晚间对账：验今天、封明天。

## 七、超脱验收者：复制粘贴协议

1. 周六周报时一键复制冷数据包（只有数字与事实：封印 vs 实绩、留存率、时间投向、豁免 / 紧急次数、节点进度），末尾附固定提问模板，要求输出【周验收】块（≤3 条调整，固定字段）。
2. 用户粘贴给订阅模型（Claude / GPT / …）。
3. 粘贴回 DSH，解析【周验收】，逐条确认后生效（拉伸系数、节点日期、砍范围）。与 Gemini【复盘】回执同一种模式。

## 八、对 v4 方案的取舍

- 保留：事前封印、两入口零成本捕获、夜间蒸馏（≤8 张 / 晚）、纯 JS FSRS、锁屏出到期卡、冷数据导出。
- 改动：奖励按档位 + 分两次兑现；无封印的局 1.0× 兼容。
- 延后：服药 / 睡眠 / Keep 底盘与熔断（原则认同：连续失效时不越锁越严）；外部验收写回 HTTP 接口（用复制粘贴替代）；周报建议自动生效（一律需确认）。
- 事实校正：Gemini 聊天现在不挣任何额度（只有通过验收的局按时长 1/3 挣）；锁屏刷题已支持无选项自判题（计分应打折），不必强制 4 选 1；Keep 分钟数时间账已能读到，无需新权限。

## 九、分批

1. 硬核：晚间封印 + 验收点统一（基于契约验收点）+ 代码判定 + 到点后果 + 按档奖励 + 谈判通道关闭 + 墙页显示。
2. 记忆：两入口捕获 + 夜间成卡 + FSRS + 锁屏 / 姐妹出卡 + 延迟兑现。
3. 超脱：周冷数据包复制 + 【周验收】粘贴回收 + 确认生效 + 拉伸系数自适应。
