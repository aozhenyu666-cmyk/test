# 大肥鱼整理方案（2026-11-19）

> 起因：192 修的「锁不住」不是偶然。手机端有 5 套能弹锁页的执行者、4 份放行名单、7 种解锁出口、一堆互相牵连的开关，
> 其中一个「主动陪伴」开关默认关，就让整条锁链静默失效——连写代码的 AI 都看不出来。
> 原则：**不削弱能力，只把同一件事收成一处**；每个功能只有一个入口、一份数据、一个执行者。

## 一、现状盘点

| 维度 | 现在 | 问题 |
|---|---|---|
| 页面 | 19 个大肥鱼页面，约 1.27 万行 | 中枢页几乎每个入口出现 **2–3 次**（上面分组宫格一遍，下面长列表又一遍）；统计页有 6 个入口 |
| 计划类 | 6 处：今日主线、鱼发的任务卡、今日计划（时间块）、计划模态 / 契约台、三层战略、每日四部门 | 同一件「今天要做什么」分在 6 个地方，彼此只部分连通 |
| 能弹锁页的 | 5 套：①原生专注监督 ②娱乐锁机（自己的黑名单、冷却、每日上限、开关默认关）③伴侣锁（强制 / 拒绝模式 / 局 / 封禁 / 规则快照）④统一裁决器（默认关，只记分歧）⑤设置页自卫 | 各自判、各自记账；①和插件的「局」是两套计时 |
| 放行名单 | 4 份：局的放行、娱乐锁机白名单、原生专注的 allowed、插件 defaultAllow；永不锁名单 Kotlin / 插件各一份；白名单预设在局页和锁机页各写一遍 | 改一处其他处不知道 |
| 解锁出口 | 7 种：紧急解除、破窗（计步）、紧急通行证、鲸澜通行证、刷题解锁、申诉、放风 / 宽限、长按回 DSH | 各有各的额度，没有一处说清「出不去怎么办」 |
| 影响锁的开关 | 测试模式、裁决器执法、主动陪伴（192 已解耦）、娱乐拦截、触发测试、专注监督、强度档 | 这次的事故就出在这里 |
| 接口 | 插件 49 条路由，App 侧 65 个调用 | 不是问题本身，但入口散导致很多调用只有一个页面在用 |

## 二、目标结构

底部三个标签不变：**局 / 墙 / 对话**。中枢改成「设置」，只放配置和诊断，不再放日常功能。

### 局（今天的一切）
1. 锁机体检（192 已加）
2. 此刻焦距 → 局详情
3. 今日使用情况 → 完整统计页（统计、24h、App 排行、晚报、Gemini 都在这一个页里）
4. **计划**（三合一，见下）
5. 工具：摇一骰、语音、题库

### 墙（审和出口）
1. 锁状态 + 审查记录 + 申诉（已做）
2. **每日四部门交付**（从中枢挪过来：它本来就是给墙验的）
3. **出不去怎么办**：一张卡列全部解锁出口和今天剩几次

### 中枢 → 设置（每项只出现一次，四组）
- **鱼**：姐妹与记忆、会话换班、声线、桌宠、主动搭话（只管她们开不开口，不再管锁）
- **锁**：App 分类表、强度档、测试模式、解锁出口额度
- **数据**：Obsidian 挂载、导入记忆、复制交接
- **诊断**：重启引擎、日志导出、哨兵配对

## 三、合并清单（不删能力）

| # | 合并 | 做法 |
|---|---|---|
| M1 | 计划三页合一 | 「今日计划（时间块）」「计划模态 / 契约台」「三层战略」→ 一个「计划」页，三个分段：**今天 / 契约 / 长期**。局页的主线卡就是它的摘要 |
| M2 | 放行名单合一 | 一张 **App 分类表**：永不锁 / 学习工具 / 娱乐 / 游戏 / 其他。局的放行、默认放行、娱乐锁机黑名单都从这张表来；白名单预设只留一份 |
| M3 | 娱乐锁机并入 | 它的黑名单 = 分类表里的「娱乐 / 游戏」；锁不锁交给插件按额度和局判（和 B 站超额封禁同一条路）。去掉它自己的开关、冷却、每日上限（这些和插件的额度是两套规则，会互相矛盾） |
| M4 | 原生专注监督并入局 | 不再是独立入口；变成「局」在引擎断开时的本地兜底（同一个局、同一张放行表、同一个计时） |
| M5 | 解锁出口合一 | 紧急解除 / 破窗 / 紧急通行证 / 长按回 DSH 共用**一个**每日额度（默认 3 次）；刷题解锁、申诉、鲸澜通行证保留，全部列在墙页「出不去怎么办」 |
| M6 | 语音合一 | 局官语音 + 声线设置 → 一页 |
| M7 | 永不锁只留一份 | 插件那份为准，手机启动时同步（手机本地保留桌面 / DSH / 系统的硬兜底） |

## 四、建议删除（要你点头）

| # | 功能 | 为什么 |
|---|---|---|
| D1 | 触发测试页 | 第一轮调试用的，现在触发器是 Gemini Live；它的开关还会影响读前台 |
| D2 | 工作记忆挂载卡页 | 代码里**没有任何入口**能打开它（死页面） |
| D3 | 中枢里的重复入口长列表 | 和分组宫格完全重复 |
| D4 | 娱乐锁机的训练模式 / 冷却 / 每日上限 | 见 M3，和插件额度是两套规则 |
| D5 | 统一裁决器「执法开关」 | 192 真机跑稳后，裁决器直接转正成唯一判锁路径，旧路径删掉，开关也就不要了 |
| D6 | 摇一摇自动弹六骰 | 局页和中枢都有「摇一骰」按钮；摇一摇常年开着、误触多。**你常用就留** |

## 五、不连通处（会一起修）

1. ~~主动陪伴开关牵连锁~~（192 已修）
2. ~~读前台依赖旧开关~~（192 已修）

7. 白名单预设两份 → M2

## 六、分批

- **第一批（只整理，不删能力，一个包）**：中枢改四组且每项一次、计划三合一（M1）、语音合一（M6）、四部门挪到墙 + 出不去怎么办卡、删 D2 / D3。
- **第二批（锁统一）**：App 分类表（M2）、娱乐锁机并入（M3）、原生专注变兜底（M4）、解锁出口合一（M5）、永不锁一份（M7）。这一批动锁，**先在测试模式下跑**。
- **第三批**：你真机用 192/第二批一两天没问题后，裁决器转正、删旧路径（D5），删 D1 / D4 / D6 中你同意的。

每批都带：本地测试全过、真机测试单、改了什么一句话一条。
