## 九条（照着做，一句话判据）

| # | 步骤 | 通过判据 | 结果 |
|---|---|---|---|
| R3-1 | 白天开游戏，让追问锁弹出来；追问时只回「嗯」「随便」 | 被拦并进追问锁；敷衍时窗口不消失、还停在同一个问题上；满意后**先回桌面再关窗**，游戏按默认锁仍打不开 | |
| R3-2 | 说「约 5 分钟后连麦」，等 5 分钟 | 到点自动进舱（背景已进剪贴板、顶部有提示、Gemini 打开）；满 3 分钟结束后出现追问 | |
| R3-3 | 追问锁里完全不回，等满 30 分钟 | 追问锁自行结束、回 `backTo` 那个主状态；账本记超时、信用分 -5；晨间立项那种当天不放风，且**下次打开被拦的 App 才再问** | |
| R3-4 | 追问期间灭屏 10 秒再亮屏；再杀引擎进程重复一次 | 亮屏后窗口和上一句追问原样还在；引擎死后追问锁与默认锁照常生效，手机本地按 `until` 到点自解 | |
| R3-5 | 笔记库任意非日记/私密目录新建一篇笔记，等一下再触发发球 | 这一球提到那篇笔记的**具体内容**，不是只说"你最近写了东西"；日记、私密目录不会被读出来 | |
| R3-6 | 让姐妹做一次裁决（晚间对账或验收），满意通过 | `大肥鱼/每日/<日期>.md` 出现结论、下一步和任务；长期目标另追加到 `大肥鱼/长期规划.md`；同一批裁决不写两遍 | |
| R3-7 | 待命时开聊；再进放风时段开聊 | 待命时帮你挑下一件、拆第一步，并提醒锁页上的「冲刺」；放风/吃饭时只陪聊，不验收不催任务 | |
| R3-8 | 问鱼丸「你把我游戏锁了/给我开一下」 | 她说自己没有这个权限；两姐妹工具一致，只有 `submit_verdict` 能影响墙 | |
| R3-9 | 锁屏页出现时杀掉引擎，等 1 分钟看文案 | 文案仍是状态机那一层（深夜锁／追问锁／晚间对账），不是笼统的「娱乐拦截」；到 `until` 自己解除 | |

## 本轮新增界面的三项（D7 / D5）

| # | 步骤 | 通过判据 | 结果 |
|---|---|---|---|
| N-1 | 被锁时看锁页 | 锁页上方三行：`现在：<主状态> · <理由>`、`义务：<挂着的义务>`、`额度：本周还剩 N 次放松`（今天收紧了就说「今天收紧了，不放风」） | |

| N-3 | 在微信里进视频号／朋友圈，停 3 秒以上再离开（回聊天、切回桌面、灭屏都算） | 每次离开只记账一次（`wechat-hit`），**不弹锁、不算违抗**；停留不足 3 秒不记；下拉通知栏不算离开 | |
