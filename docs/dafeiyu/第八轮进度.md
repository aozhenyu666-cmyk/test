### 做了什么

1. **三个角色共用一张嘴**（`app/lib/companion/voice_roles.dart`）

   - `VoiceRole { official, strategist, companion }`——局官、大鱼、小鱼，用的是施工书里的词。
   - **服务、密钥、风格只有一份；只有音色按角色分开存**（`shared_preferences` 键
     `companion_voice_roles`）。密钥不在这里，仍然只走 `flutter_secure_storage`（上游
     `CompanionVoiceSettingsController` 就是这么存的，`plain()` 里没有 key 和 headers）。
   - `speak(role, text, {style, id, flush})` / `stop()` / `events`，对应施工书要的
     `speak(text, voice, style)` / `stop()` / 进度事件。`voice` 由 role 决定，`style` 一句一给。
   - **兜底就是「换一份设置」**：没配置（设置没读出来 / 开关关着 / 没填密钥 / 选了手机自带）时
     `settingsFor()` 返回一份 `source = system` 的设置，交给同一个播放器——走的就是第七轮 B5 那条
     系统 TTS 的路，不报错、不静默、也不假装配好了。外接服务取不到音频时，
     `companion_voice.dart` 自己再退回一次手机语音（`fallback` 事件）。

2. **设置页加「声音输出」区块**（`app/lib/ui/settings/voice_settings_page.dart`）

   开关 / 服务（四家预置）/ 密钥 / 三个角色各自的音色 / 每行一个试听按钮。
   换服务时把在新服务里不存在的音色清掉、回到「跟随服务默认」——否则下一句会拿别家的
   音色 id 去请求，失败再退回手机语音，白等一次还听不出为什么。

   新增 15 个 l10n 键（`voiceOut*`，zh 与 en 成对，`l10n_merge.py` 校验通过）。

3. **`MainActivity.kt` 注册插件**（+1 行，第 66 行）。
