# 主动性与记忆（2026-11-16）

> 基线：fish-build-147（`e4cb9af5`）。用户反馈：两姐妹只催不动手、没有记忆、局页面没用、鲸澜啰嗦、墙不接 AI。

## 根因（代码里找到的）

| 现象 | 原因 |
|---|---|
| 只催不动手 | 待命状态每个状态最多挂 8 个工具，开局、连麦、封 App 都不在待命里；人设却说她们有。提示词到处写「他点头再用」。没有任何工具能让她们开局。 |
| 局页面没用 | 早上的局计划草案只有时段、没有工作包，也没有工具能填，局官只能问「第一步是什么」，过关标准是字数。 |
| 没有记忆 | 召回只按他最后一句的字面重合，「嗯」「好烦」对不上就一条不带；主动发球的提示被当成检索线索；没有对话留底；「小事」这个 kind 不认。 |
| 鲸澜啰嗦 | 人设是五步流程卡，每句都套；长卡还把妹妹的递话挤出了上下文预算（`dual.test` 第 7 条在基线上就挂着）。 |
| 墙不读内容 | 只看文件变长 300 字节，凑字数也过。 |

## 改了什么

**记忆**（`dsh-go-memory`）：常驻档案、对不上时补位、原话留底（`lib/dialog.js`）、每 20 分钟随手想起一条旧事、kind 认中文。见插件 README。

**笔记库**：`notes.js` 的 `vaultPick`，每 30 分钟两姐妹各翻一篇（新旧各半，系统产出和太短的不翻），进每轮的内容层。

**主动性**（`dsh-go-companion`）：
- 新工具 `open_bout`（现在就开一局，带工作包和 App）、`plan_bouts`（一次排好今天的局，十分钟后自动生效）。
- 工具子集上限 8 → 14；待命里有开局、排局、连麦、封 App、递话、收紧。
- 「可逆的直接做，做完一句话告诉他；不可逆的才问」替换掉所有「他点头再用」。
- 计划草案没内容时，鲸澜自己来填（`plan-draft`，一小时最多一次，让位给深夜锁、连麦、忙时和没接的球）。
- 早上立项：鲸澜先从记忆、笔记库、昨天的账里替他排好，他只说行或换。
- 巡逻从每天 3 次（10/15/20 点）改成 5 次（9/11/14/16/19 点），巡逻时直接开局 / 立任务。
- 工作包第一步：「打开 / 登录 + 名字」认作应用（以前连报错里举的「打开 Boss 直聘」都过不了）。

**鲸澜**：人设卡重写：结论先行、默认一到三句、能做的直接做；五步推演只留给选方向、做取舍的大事。

**墙的眼睛**（`lib/wall_eye.js`）：交验收、文件证据在代码层已经过了时，读立项后新写的那段，问模型「是不是真在做这件事」。只能把过改成不过；判不过必须引得出原文；模型连不上就按代码结论并说明。截图不读（DeepSeek 没有识图）。
