# DSH Go 魔改说明（给后来的修改者）

> 2026-11-08。分支 `ccr-553d9e36-lw8d16`。这份只讲**我们在 DSH Go 上加了什么、放在哪、怎么串起来**，读完不用再去啃 DSH Go 原版代码。细节设计见文末的文档索引。

## 0. 一句话

在 DSH Go（手机上跑本地 AI Agent 的 App）里，我们做出了"大肥鱼"：两个人格——妹妹**鱼丸**（陪伴、嘴欠、黏人）和姐姐**鲸澜**（谋士、冷静、有管控权）。她们会高频主动找他、看他手机在干嘛、该锁就锁娱乐 App、给他立任务并验收、接 Gemini Live 连麦，还有记忆和信用分。

## 1. DSH Go 原版是什么（只需知道这些）

DSH Go 有三层：

| 层 | 技术 | 我们怎么用 |
|---|---|---|
| 界面 | Flutter（`app/lib/`） | 加了设置页、拦截页几个入口，改动很少 |
| 原生 | Kotlin（`app/android/.../dsh_app/`） | 新增 `loop/` 整个目录：主动搭话、拦截、专注、锁机；`phone/a11y/` 加了前台监测和看门狗 |
| 引擎 | Node 写的 DSH 引擎（`@deepseek-ai/dsh`），跑在 proot 里的 Linux 中 | 大部分"脑子"写成**内置插件**，放在 `app/assets/engine/plugins/` |

几个关键事实：
- **插件部署**：内置插件由 `runtime/BuiltinPluginGuest.kt` 在每次引擎启动时拷进去。**插件里新增一个 lib 文件，必须加进这个文件的清单**，否则手机上找不到（插件测试 `manifest.test.mjs` 会查）。
- **引擎接口**：手机和引擎之间是 HTTP，Dart 带 cookie 转发。插件自己的路由挂在 `/dsh-go-companion/v1/*` 下。
- **会话和工具**：插件能给指定会话注入人设（`systemPrompt.context`，每轮都带），也能注册工具（`agent.ctx.tools.register`）。
- **原生面板**：插件可以声明原生面板（`package.json` 的 `dshGo.contributes.panels`），面板内容是一棵 JSON 组件树，App 负责画出来。

## 2. 总体怎么串起来

```
手机（Kotlin）                                   引擎里的插件（dsh-go-companion）
─────────────                                   ──────────────────────────────
无障碍：前台 App、停留、切屏次数、亮屏 ──┐
使用情况：今天每个 App 打开几次 ──────────┤  POST /plan（每次切 App 都问，15 秒节流；
                                         ├─▶   连续乱切时 5 秒）
                                         │   插件决定：说不说、谁说、几点再问、
                                         │   力度（锁 / 赶）、拒绝到几点、
                                         │   通知防波堤、封禁名单
手机执行：发起一球 / 锁 App / 回桌面 ◀────┘
          / 拦通知
POST /request ──▶ 插件把一段"发球提示"送进鱼丸或鲸澜的会话，模型生成一句话
GET  /result  ◀── 那句话（带〔鱼丸〕/〔鲸澜〕前缀），浮层显示
POST /say     ──▶ 他在浮层里打的字，原样作为他本人的话进会话
POST /event   ──▶ 关窗、违抗（关窗 30 秒后还在玩）、拦下的通知、破窗、动设置
POST /session ──▶ Gemini 互动舱开始 / 结束（应用规则页或 gemini_live 开的场次）
```

**铁律：插件决定，手机执行。** 手机端不自己掷骰子、不自己判断该不该锁。**补一句（P0）：已下发的规则，引擎死了也要执行**——`/plan` 带一份规则快照（`rules`），手机存在 `files/loop/proactive/rules.json`，引擎不可达时按它执法，到期按本地时间解除。

## 3. 引擎插件（`app/assets/engine/plugins/`）

| 插件 | 做什么 |
|---|---|
| **dsh-go-companion** | 核心。主动搭话的决策和生成、双人格、管控、档位、Gemini 搭桥、信用分、面板。下面单列 |
| dsh-go-memory | 手机本地记忆，SQLite 是权威。有作用域（记事加 `share:true` 两人共享）、纠正和删除、未完成话题、原生记忆面板 |
| dsh-go-relationship | 关系内核：人物卡（价值观 / 底线 / 边界）、双向约定、截止日期。鲸澜的底子来自这里 |
| dsh-feiyu-mood | 心情值：每轮自动判断涨跌，界面上有挂饰 |
| dsh-fish-strict | 严格沟通的状态机（较早的方案）。**P0 起不再部署**，源码留作参考 |
| dsh-speak-up | 主动搭话的早期版本（掷骰子起话头），已被 companion 取代，不部署 |

另有 `runtime/proactive/dsh-go-proactive/`：宿主侧的小插件，把手机的主动事件交给会话，并如实回报状态。

### dsh-go-companion 的模块（`lib/`）

| 文件 | 管什么 |
|---|---|
| `index.js` | 入口：配置、路由（`/plan` `/request` `/result` `/say` `/event` `/config` `/status` `/outcome` `/cancel`）、两个会话的人设挂载、所有工具、面板注册 |
| `core.js` | Desk 状态机：一次请求的 accepted → claimed → generated / failed / cancelled |
| `roles.js` | 两人的默认人设、生活设定、各种场合的开场提示（报到、对账、违抗、巡逻、连麦复盘……）、能力说明 |
| `prompt.js` | 拼出发给模型的那段"发球提示" |
| `plan.js` / `silence.js` / `rally.js` | 开不开口（安静时段、额度、间隔、骰子）；没人接时的阶梯；回合计数 |
| `phone.js` / `tide.js` / `temper.js` / `brain.js` / `force.js` | 手机现状清洗；水位（陷得多深）；脾气；Thompson 抽样挑脸；力度 0–4（说 / 追 / 屏 / 锁 / 赶），以及拒绝模式 |
| `gear.js` | 档位：闲时（高频）/ 忙时（报到、拒绝）/ 她们立的任务模式 |
| `gemini.js` | Gemini Live 搭桥：生成给 Gemini 的背景、判断他在不在 Gemini 里、连麦复盘的格式 |
| `trust.js` | 两人共用的信用分（0–100，从账本算） |
| `panel.js` | 「鱼丸 · 鲸澜」原生面板：评分、家庭群、记忆 |
| `notes.js` | 知识库：`大肥鱼/我.md`（他写）、`大肥鱼/判断.md`（鲸澜写）、扫描没写完的笔记 |
| `rhythm.js` | 作息：早上对线、深夜管控、晚上对账 |
| `judge.js` / `classify.js` / `stock.js` | 判他的回复（认真 / 糊弄 / 反驳）；套话守卫 |
| `topics.js` / `garden.js` / `context.js` / `persona.js` / `drills.js` / `serve.js` / `ledger.js` / `tz.js` | 话题池、上下文、人格卡与温和 / 严格模式、思维题（默认关）、发球类型、账本读写、时区 |

**状态都是文件**，放在 `$DSH_HOME/companion/` 下：

| 文件 | 内容 |
|---|---|
| `config.json` | 所有开关和当前模式（档位、拒绝到几点、放风、封禁名单……） |
| `ledger.jsonl` | 账本：每一球、他每句话、违抗、任务、连麦等一切事件。**信用分、评分、阶梯都从这里算**，不另存 |
| `gemini.json`、`gear.json`、`rhythm.json`、`notifs.json`、`notes.json`、`brain.json`、`temper.json` | 各模块的小状态 |

| 工具 | 作用 |

## 4. 手机原生层（Kotlin，`app/android/app/src/main/kotlin/io/github/ccch1mneyyy/dsh_app/`）

| 位置 | 做什么 |
|---|---|
| `loop/core/` | 纯逻辑，可以在 JVM 上测：`Coordinator`（一次主动事件从排队到展示到回执）、`ProactiveScheduler`（兜底定时）、`SurfaceSlot` / `VisibleSurface`（同一时间只许一个 DSH 页面占屏）、`Intercept`（拦截守卫，`force()` 是大肥鱼下令的锁） |
| `loop/proactive/ProactiveRuntime.kt` | 手机侧总控：问 `/plan`、执行力度（回桌面 + 锁）、拒绝模式本地缓存、违抗 30 秒复查、切屏计数、使用情况统计、通知防波堤开关、封禁名单、永不锁名单 |
| `loop/proactive/ProactiveOverlay.kt` | 悬浮窗：跨 App 显示，能直接打字聊天，显示是谁在说话。**没回过一句关不掉**；有"在忙，晚点回"快捷回复；聊天中来了新球就接在同一个窗口里 |
| `loop/proactive/NotificationShield.kt` | 通知防波堤：忙时、任务期间拦下非白名单通知（需要用户授权"通知使用权"） |
| `loop/intercept/` | 拦截页（锁屏页），DeepSeek 负责：设置页自卫的入口；计步破窗（150 步 + 100 字违约说明，换 10 分钟放风，报 `/event breakglass`）；急事直达（电话 / 短信 / 地图 / 支付）。互动舱期间，主按钮变成"回 Gemini 继续" |
| `loop/proactive/TamperGuard.kt` | 设置页自卫（DeepSeek 写）：管控期间，设置类 App 的同一页上同时出现 App 名和"强行停止 / 卸载 / 无障碍"，就全局返回、回桌面，并报 `/event tamper` |
| `loop/focus/` | 原生专注监督（不依赖引擎，离开任务 App 5 秒就拉回） |
| `phone/a11y/NowFeed.kt`、`A11yWatchdog*` | 前台 App、停留时长、今日用量；独立进程里的无障碍看门狗 |
| `runtime/RuntimeController.kt` + `SafeMode.kt` | **引擎被杀自动重启，不放弃**（5 秒 → 15 秒 → 45 秒 → 2 分钟 → 之后每 5 分钟） |
| `runtime/DshService.kt` | 前台服务，运行中改成 `START_STICKY`（整个 App 被杀，系统会把服务拉回来） |
| `runtime/EngineExitLog.kt` | 每次引擎退出都写 `files/runtime/logs/engine-exits.jsonl`，含 Android 给出的进程死因 |
| `runtime/BuiltinPluginGuest.kt` | 内置插件部署清单（见第 1 节） |
| `runtime/FishMcpGuest.kt` | 连接电脑端的 fish 桥（MCP） |

**Flutter 改动**（`app/lib/`）：
- `ui/phone/proactive_page.dart`：大肥鱼设置页（模式、间隔、谋士会话）；
- `ui/phone/intercept_page.dart`；
- `ui/phone/app_rules_page.dart`：应用规则页里的"Gemini 互动"，可以看状态、选时长和模式、开关互动舱（DeepSeek 写）；
- `proactive/` 下的通道；
- 若干 l10n 文案。

## 5. 主要功能一览

- **双人格**：两个会话各挂各的人设，共享记忆；每句话带〔名字〕前缀；姐妹之间能递话。
- **高频主动**（闲时）：最短 18 分钟一次、每天最多 40 次。
  - 没人接：两次后鲸澜接手，此后每 10 分钟来一次，直到他回话。
  - 信用分低时更勤。
- **看得见他**：前台 App、停留时长、今日用量和打开次数、切屏频率。
  - 90 秒内切 5 次以上：鱼丸截胡；15 分钟内切 8 次以上，或娱乐超过 90 分钟：鲸澜巡逻、自己决定要不要立任务。
- **管得住他**：
  - 力度会随水位升级；拒绝模式；忙时；她们立的任务模式（验收才结束）。
  - 违抗闭环：关掉提醒 30 秒后还在玩，当场开拒绝模式，鲸澜来收尾。
  - 通知防波堤；封禁名单。
  - 电话、短信、地图、支付永远不锁。
- **作息**：
  - 早上：10 点前第一次亮屏，先说出今天 3 件事才解锁。
  - 深夜：23:30 起频繁催睡，0:30–7:00 锁娱乐。
  - 晚上：21:30 对账，对完才解锁。
- **知识闭环**：他写 `我.md`，她们以它为准；鲸澜每晚写 `判断.md`，他来纠正。
- **Gemini 互动舱**（DeepSeek 写）：开着的时候**只许用 Gemini**；切到别的 App 当场锁，锁屏页一键回 Gemini；重启后仍有效，到点自动失效。
- **Gemini Live 搭桥**：
  - 去：生成背景写进剪贴板，打开 Gemini。
  - 中：连麦时不插嘴，跑去玩照样锁。
  - 回：在后台屏读回对话，写进笔记库 `Gemini/日期.md`。
- **信用分与评分**：0–100，决定松紧（是否放风、讲理由松不松、主动频率）；面板上有今日四项评分和总评。
- **面板「鱼丸 · 鲸澜」**：信用分、评分、家庭群（可以同时发给两个人，鱼丸先回、鲸澜接着说）、她们记得的你。面板只能收紧管控，不能放松。
- **引擎稳定性**：被杀自动重启，退出原因写日志。

## 6. 改的时候别踩的坑

- **新增插件 lib 文件** → 加进 `BuiltinPluginGuest.kt` 的清单。
- **插件决定、手机执行**：不要在 Kotlin 里另起一套"该不该说 / 该不该锁"的逻辑。
- **账本是唯一事实来源**：信用分、评分、阶梯、互动时间线都从 `ledger.jsonl` 算，别另存一份会对不上的计数。新事件要 `record({ state: '...' })`，需要的话在 `trust.js` / `panel.js` 里接上。
- **他亲口的话**：通过 `/say` 进会话的消息要带 `source: { kind: 'user', rpcId, clientTimeZone }`，否则引擎不开轮次，时间也会按 GMT 算。插件自己注入的消息标成 `dsh-go-companion`，不算他说的话。
- **底线不能破**：
  - 永不锁名单：插件端的 `NEVER_BLOCK` 和手机端的 `NEVER_LOCK`；
  - 面板不能有"放松管控"的按钮；
  - 她们的写权限只有 `大肥鱼/` 和 `Gemini/` 两个目录；
  - 读屏和相册看到的东西不落盘。
- **测试**：
  - 插件：`cd app/assets/engine/plugins/dsh-go-companion && node --test test/*.test.mjs`；
  - 端到端：`bash tooling/companion-e2e/run.sh`（真引擎 + 假模型）；
  - 真模型试跑：`tooling/companion-e2e/*-real.sh`。
- **打包**：推送到分支，CI（`.github/workflows/build-dafeiyu-apk.yml`）会跑插件测试和端到端测试，打 arm64 包并发布 `fish-build-N`。包名是 `.fish`，可以和原版并存。提交信息里带 `[skip ci]` 就不打包。
