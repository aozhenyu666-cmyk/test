# 大肥鱼 · 水道（主动引导体系）

> 2026-11-06。接在《现状评估与下一步》后面读。这一份讲方向和这一轮落地的"大脑"，不重复底稿。

## 1. 他现在是什么状态（设计的出发点）

- 意志像水：往阻力最低处流，主观能动性弱，被外部因素锁定。
- 沉进去时的症状：**精准度掉**、开始凭感觉说话、降低大脑输出和记忆、**用沉默应对一切**；看完视频只剩似是而非的结论。
- 过去的工具（定时任务、总控、拦截）都是**水泵**：抽一下停一下，抽完水照样往低处流。拦截模块只在打开 App 那一刻拦一次，点完数字就放行十分钟。
- 最怕的失败：打一天游戏，它充耳不闻。

由此得出五条原则：

1. **水道，不是水泵**：一个连续的量（水位）一直在算，陷得越深，开口越勤、语气越硬、手越重；回到清醒就退。
2. **沉默是信号，不是缺席**：不回 = 水位上涨；没答的思维题下一球要被点名。
3. **考精准，不考参与**：判球按"合格线"判，似是而非、只有感受词都算没接住。
4. **脾气阴晴难测**：固定节奏和固定语气会被他提前"消音"。间隔、脸色都带随机。
5. **底线说到做到**：力度不掷骰子。温和模式也会锁，只是更晚。

## 2. 结构

```
手机现状（NowFeed：前台 App、停留、今日累计、亮屏）──┐
账本（没接几球、糊弄几次、上一题答没答）────────────┤
                                                    ▼
                      水位 tide.js  0–100：清醒 / 在滑 / 在沉 / 陷住了
                         │            │             │
                 节奏（间隔×水位×随机）  脾气 temper.js  力度 force.js
                         │            │ 底色(温和/严格)+水位+随机游走+偶尔翻脸
                         │            ▼
                         │       大脑 brain.js：Thompson 抽样在相邻几张脸里挑最可能拉回来的
                         │            │        思维题按"答不上来"加权（弱项多练）
                         ▼            ▼
                      /plan：说不说、何时再看、force（锁/赶）  ──▶ 手机执行（锁 App / 回桌面）
                      /request：这一球的 prompt（脸色 + 思维题 / 说他 + 判断 + 宣布）
                                      │
                      回球 → 判球（按合格线）→ 大脑记分 → 判断重算，翻了就记下来
                      10 分钟内离开娱乐 App → 这张脸 +1（近端结果，借自 HeartSteps 的 JITAI 做法）
```

## 3. 各模块

| 模块 | 做什么 | 关键规则 |
|---|---|---|
| `tide.js` 水位 | 连续停留、今日累计、没接、糊弄、深夜 → 0–100 | 不在娱乐 App 里封顶 40；间隔 = minGap × (1 / 0.5 / 0.25 / 0.12) × 随机 0.6–1.4；在沉/陷住不掷骰子 |
| `temper.js` 脾气 | 五张脸：哄 / 逗 / 冷 / 怼 / 训 | 温和底色 0.25、严格 0.7；水位最多再推 0.45；均值回归随机游走；13% 翻脸，只翻这一球 |
| `brain.js` 大脑 | Thompson 抽样挑脸；思维题弱项加权；从证据推判断 | 拉回来 = 发球后 30 秒–10 分钟内离开那个 App，或认真回球；每格 ≥4 次才下判断；判断翻了就让它说"我之前看错了" |
| `drills.js` 思维题 | 一句话论点 / 给个数字 / 找反例 / 挖前提 / 下注 / 讲给小孩听 / 反过来想 / 机会成本 / 二阶后果 | 模型现编、只属于他；每题有合格线和"答不上来怎么说他"；最近三次不重复 |
| `force.js` 力度 | 说 / 追 / 屏 / 锁 / 赶 | 严格：连续 30 分钟锁、60 分钟赶；温和：60 / 120；今天累计也算；陷住且连着两球不接直接锁；没给控机权限最多到浮层 |

其他：一早第一球（今天还没开过口、屏幕亮着）不等骰子，先问"今天最重要的一件事、几点前做完"；说"严格点 / 温柔点 / 切到严格模式"一句话切换。

## 4. 手机侧（这一轮）

- `/plan` 带上手机现状；**每次切前台 App 都问一次**（15 秒节流）——滑进游戏那一刻就是决策点。
- `/plan` 回 `force ≥ 3`：锁住那个 App（`InterceptGuard.force`：不看拦截自己的开关、暂停、冷却、每日上限、目标清单；守住白名单、已挣到的放行、一次锁一个、灭屏/DSH 在操作时不锁）。`force = 4` 先退回桌面再锁。3 分钟内切回那个 App 照样锁。
- 放行仍是锁屏页自己的训练题（点数字 + 停留）。答过放行 10 分钟，到点插件还说锁就再锁——这是"水道"，不是一次性的门。

## 5. 调整（同日）：真聊天为主

- 浮层加了输入框：打字直接进大肥鱼的会话，回复显示在浮层里，可以来回聊，不用切回 App（`/say`）。
- 大肥鱼回话那一轮：不出题、不打分；他解释理由时先复述再表态。讲通了（判成真反驳）就松 20 分钟不锁。
- 做题默认关，一句话打开；关着时锁之前是"问他为什么"，不是丢题。

## 6. 没做 / 下一步

1. **锁屏页也能直接聊**：现在锁屏页还是点数字放行。下一步：锁屏页加同样的输入框，跟大肥鱼讲通了（真反驳）就放行。
2. **力度 2（屏）在手机侧强制**：现在无障碍连着时默认就是浮层，但没有强制"不许退回通知"。
3. **下注对账**：思维题"下注"要求之后回来对账，现在只是说了，没有把预测存下来、到点核对。
4. **每晚沉淀**：把大脑的判断、几点容易滑写进 fish-memory，让会话本身也"记得"。
5. P4 合并 + 真机验证（全部未上真机）。
