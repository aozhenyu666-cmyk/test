## 3. 当前实现约定

### D3 知识库
- 只读检索：`vault_search(query)`、`vault_recent_notes(limit)`；跳过日记/私密/.obsidian/.trash。
- 发球前注入：最近 3 篇笔记摘要 + `大肥鱼/长期规划.md` + 当天 `daily.json` 的任务/完成物。
- 裁决同步：扫账本 `state:'verdict'`，按 `at` 增量写 `大肥鱼/每日/日期.md`；`longTerm:true`（或任务带 `longTerm`）追加 `大肥鱼/长期规划.md`。
- 记忆导出：`facts` 里 `pinned=1` 或 `importance>=4`，单向覆盖写 `大肥鱼/记忆.md`（每 6 小时最多一次）。
- 写权限：只写 `大肥鱼/`、`Gemini/`；检索不读日记/私密目录。

### D4 定时 Gemini Live（插件部分）
- `schedule_gemini_live({ delayMinutes | at, topic, minutes?, mode? })` 存 `companion/gemini-schedule.json`。
- 到点由 `POST /gemini/due` 产出 launch：背景简报（人设 + 笔记库相关 + 当天任务）、`topic/minutes/mode`，并把 `gemini.json` 置为一场进行中的 session。
- `gemini_end` 记录 `minutes`；`gemini_log` 继续写 `Gemini/日期.md`。
- 手机端剪贴板/顶部提示/打开 Gemini/进共舱等 C1；白名单沿用 `config.geminiPackages`，真机数据出来后改配置。
