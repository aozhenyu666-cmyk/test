# 大肥鱼：乒乓式高频互动 —— 产品方案与任务书

给实现方（DeepSeek / GPT）。代码在 `aozhenyu666-cmyk/dsh-Go`，分支 `feat/relationship-core-p0`（当前 HEAD `b771490`）。
先读本文，再读 `app/assets/engine/plugins/dsh-go-companion/`（话题花园、分类、账本、出题）和 Android 端 `ProactiveRuntime` / `ProactivePageActivity`。

---

## 1. 用户是谁、要解决什么

- 他的思考强烈依赖外界刺激；没人推，就不会主动开始。
- 空下来时（比如坐在车上），会自然滑向最省力的娱乐；不是不知道该做什么，而是没人来"发球"。
- 他最常见的两种反应：**不回复**、**漠视**（看到了但不理）。现在的系统对这两种反应没有任何办法，只会重复同一句话。
- 他要的不是"提醒工具"，而是**一个活的对手**：主动发球，接住他的回球，再有力地打回去。像打乒乓球一样一来一回，高频、短促、有来有往。
- 大肥鱼本身就是有人格、有记忆、能自己判断的智能体。这套东西要建在它身上，而不是再造一个规则机器人。

**一句话目标**：让大肥鱼每天和他打出足够多的"有效回合"，并且在他不接球时，换着法子把他拉回来，而不是重复唠叨。

## 2. 核心概念：回合（rally）

```
发球   大肥鱼主动开口：一个具体的观点 / 观察 / 挑战（不是空泛的问题）
回球   用户回应
判球   大肥鱼自己判断这一球：接住了 / 敷衍 / 回避 / 套话 / 拒绝 / 真正的反驳
回击   接住了 → 往深一步或换角度；敷衍、套话 → 点破并追一次；拒绝 → 停，换话题或换时间
收拍   自然结束（聊透了、他要去做事了），写下这一回合的要点
没接   见第 5 节"不回复与漠视"
```

衡量好坏只看回合，不看消息条数：
- 每天有效回合数（至少两拍、且有一拍是"接住了"）；
- 平均回合长度；
- 发球后 5 分钟内的接球率；
- 被漠视后的重新接上率。

## 3. 发球：每次说什么

### 3.1 先亮观点，再提问

每次发球都必须包含大肥鱼**自己的判断**，再抛给他：
- ✗ "你现在在干嘛？"
- ✓ "你在 B站已经 20 分钟了，我猜你是在躲下午那份申论。说错了你来反驳我。"

### 3.2 发球类型（掷骰子，最近 3 次不重复）

| 类型 | 素材来源 | 例子 |
|---|---|---|
| 观察 | 手机现状：前台是哪个 App、用了多久，时间，是否在充电 | "十一点了还在刷短视频，昨天这个点你说要早睡。" |
| 记忆回调 | fish-memory、话题花园、过去的回合要点 | "上周你说想换工作，后来怎么样了？我觉得你没动。" |
| 观点挑衅 | 他最近说过的结论 | "你昨天说行测靠刷题量，我不同意，量不解决审题。" |
| 小挑战 | 30 秒能做完的一件具体事 | "现在说出今天最该做的一件事，就一件。" |
| 闲聊 | 人格卡里的兴趣、近期话题 | 按人设自由发挥，但要接得上他的生活 |
| 复盘 | 今天 / 昨天的回合记录 | "今天你三次说'等会儿'，等到现在了。" |

### 3.3 套话守卫

生成的句子如果和下面这类模板字面相似度 ≥ 0.6，就重写一次，还像就换类型：
"你在做什么""下一步是什么""依据是什么""加油""你可以的"。

## 4. 判球：由大肥鱼自己判断，不再按字数

现在 `classify.js` 主要按字数判："≥ 16 字就算实质回答"，一句够长的套话就能过。改成：

1. 把**发球原文 + 他的回球 + 最近 3 拍**交给大肥鱼（就在它自己的会话里判，用它的人格和记忆），只输出 JSON：
   ```json
   {"verdict":"engaged|brief|evasive|stock|refuse|pushback","why":"一句话","next":"deeper|angle|callout|stop"}
   ```
   - `stock`：套话、复述、正确的废话；
   - `pushback`：真正的反驳。这是最好的球，要正面接住；
   - `evasive`：转移话题、"以后再说"。
2. 规则分类器只在大肥鱼连不上或超时（例如 6 秒）时兜底。
3. 判球结果写进账本（已有 `replied` / `replyClass`，扩展取值即可），话题花园按它走。

## 5. 不回复与漠视（这是核心）

### 5.1 先区分是哪一种

| 状态 | 怎么知道 |
|---|---|
| 没看到 | 没有 `displayed`（锁屏、通知被系统收起） |
| 看到不理 | 有 `displayed`，之后没有回球；或点了「Later / Seen it」 |
| 敷衍 | 回了，但判球为 `brief` / `stock` |
| 回避 | 判球为 `evasive` |

### 5.2 换法子，不重复

同一个发球**不允许原样再发**。没接球时按阶梯换打法，每一级都换内容、换角度：

1. **5 分钟**：换一个更轻、更具体的球（从"观点挑衅"降为"小挑战"或"闲聊"）；
2. **15 分钟**：换渠道。通知 → 浮层；如果他开了语音，用人设的口吻念出来；
3. **连续 2 次没接**：本轮停下，不再追。把"什么时间、在用什么 App、哪一类球被漠视了"写进记忆；
4. **下一个合适时机**（下一次打开手机、第二天早上）：把这次漠视本身当成素材发球："昨晚 11 点我叫了你两次，你在刷什么？"

规则：
- 每小时、每天的发球次数有上限；安静时段不发（按手机时区算，见第 8 节第 1 条）；
- 被漠视的类型自动降低权重，接住的类型提高权重。大肥鱼会慢慢学会"什么时候、用什么球你才接"；
- 他随时能说"安静一小时""今天别找我"。大肥鱼照做，并把这句话本身记下来。

## 6. 人格卡与两种模式

- **人格卡**：名字、口吻、口头禅、兴趣、和他的关系、能说多狠、哪些话题不碰。存在 DSH 会话的人设里（DSH 本来就支持），首页提供可视化编辑。
- **两种模式**：
  - **伙伴**：自然闲聊，发球偏"闲聊 / 记忆回调"，频率低。
  - **教练**：发球偏"观察 / 观点挑衅 / 小挑战"，频率高，判球严。
  - 切换方式：用户说一句"进入教练模式 2 小时"，或按日程（例如工作日 9–12、14–18）；大肥鱼也可以建议切换，由用户确认。

## 7. 手机上的感知与能力（全部由用户在设置里逐项打开，随时可关）

| 能力 | 用途 | 现状 |
|---|---|---|
| 前台 App 与时长（无障碍，只读包名） | "观察"类发球；判断是不是在娱乐 | R4 的 `LoopRuntime` 已有，只读包名 |
| 通知、浮层 | 发球、显示判球结果 | `ProactivePageActivity` 已有 |
| 语音朗读（系统 TTS 或人设语音） | 换渠道 | 待接；可评估交接包里 `dsh-voice-mode` / `dsh-talk` |
| 桌宠 / App 外显示 | 有"活人在旁边"的存在感 | DSH Go 已有 Deepy、鲸娘 |
| 日程、充电、亮灭屏 | 选发球时机 | 部分已有 |

原则：用户主动打开的能力越多，大肥鱼越了解他、发球越准；每一项都能在设置里单独关掉，首页有一键"安静"。

## 8. 任务清单（按顺序，每步都能单独用）

### P0 先修已知问题
1. **时区**：引擎跑在 `TZ=GMT`，`plan.js` 用 `getHours()` 算安静时段，真机上会偏 8 小时。改为按手机时区（APP 在请求里带上，默认 `Asia/Shanghai`），测试要在 `TZ=UTC` 下也全过。
2. **拒绝误判**：`classifyReply` 里"别管 / 别问"在长句中误判（例："别管这道题了，我先做第三题"会被判成拒绝）。只有短句（≤ 20 字）命中才算 `refuse`；第 4 节上线后，规则只作兜底。
3. **冷会话唤醒**（验收 B 项）：大肥鱼会话不活跃时能不能叫醒。之前在电脑上就没成功过，先真机验证。
4. **只保留一个主动调度器**：`dsh-speak-up` 与 companion 会各自开口。主动开口统一由 companion 负责，speak-up 的总开关默认关。

### P1 回合引擎 + 大肥鱼判球
- 账本加 `rallyId`、拍数；第 2 节的回合状态。
- 第 3 节：先亮观点的发球 prompt、发球类型骰子、套话守卫。
- 第 4 节：大肥鱼判球，规则兜底。
- 测试：沿用 `test/routes.test.mjs` 的假宿主；加一组"假用户"脚本（一直敷衍 / 一直套话 / 真反驳），断言判球和回击类型。

### P2 不回复与漠视
- 第 5 节的状态区分、换法子阶梯、上限、"安静"指令、把漠视记进记忆、下次拿来当素材。
- 测试：时间注入，断言同一发球不重发、阶梯按时触发、上限生效。

### P3 感知 + 人格卡 + 模式
- 前台 App 与时长进发球上下文（复用 `LoopRuntime`，只读包名）。
- 人格卡编辑页、伙伴 / 教练两种模式、日程切换。

### P4 语音渠道
- 先用系统 TTS；再评估现成的语音插件。

### P5 评测
- 用 promptfoo 的"模拟用户"（敷衍型、沉默型、反驳型人设）跑 20 个回合，统计判球准确率和平均回合长度；每次改 prompt 前后都跑一遍对比。

## 9. 界面（DSH Go 里的主动交流页）

功能太多堆在一起时，按"现在 → 回顾 → 设置"分三层：
1. **首页只放"现在"**：大肥鱼刚发的球、你的回球框、「安静一小时」。
2. **回顾**：今天的回合、被漠视的球、大肥鱼记下的习惯。
3. **设置**：人格卡、模式与日程、各项感知开关、上限与安静时段、诊断（默认收起）。

## 10. 硬约束

- 每条结论都标明是否真机验证；没跑就写"未运行"。
- 不复制 GPL 代码进来，除非整体按 GPL 发布。
- 不改总控 / 一手 / 哨兵；那边是另一组（防御）。两组的联动以后单独设计。
- 用户随时能让它安静，所有感知都能单独关掉。
