# 大肥鱼体系总图（一页纸）

> 2026-11-14 · 给用户和执行 AI 共用。任何新设计先在这张图上找位置；找不到位置的，先别做。
> 本文同时是《第九轮补充三》：§3 的三个缺口是新增工单，排在补充二 §8 第 1 批里。

---

## 1. 体系要做的只有一件事

**每天把他的时间变成一串「局」，每一局都做完一件说得清的事。**

三个器、两条鱼、墙、法典、大脑，全部是为这一句服务的。

## 2. 一天的流水线

```
 前一晚                早上                 白天（每一局）                       晚上
┌──────────┐      ┌──────────┐      ┌───────────────────────────┐      ┌──────────┐
│ 鲸澜备课  │ ───→ │ 计划模态  │ ───→ │ 开局 → 第一步 → 触发 → 交付 │ ───→ │ 对账      │
│ (调度)    │      │ (调度)    │      │      ↑ 偏离 → 预案 / 墙     │      │ (验收汇总)│
└──────────┘      └──────────┘      │      ↓ 交付 → 验收器        │      └────┬─────┘
      ↑                              └───────────────────────────┘           │
      └──────────────────── 行为大脑：模式、法规、权柄 ←───────────────────────┘
```

| 环节 | 谁做 | 产出（必须是数据，不是聊天） |
|---|---|---|
| 前一晚：备课 | 鲸澜 + 代码 | 明天的**工作包**队列（§3.1） |
| 早上：计划模态 | 鲸澜说，他确认（≤ 10 分钟） | 生效的计划 |
| 白天：开局 | 代码到点开 | 局官念出**第一步** |
| 白天：触发 | 局官（局内）、鱼丸（局外、休息时） | 一句话指令，对着工作包问 |
| 白天：偏离 | 预案 → 严格模式 / 锁 / 升级 | 执法记录 |
| 白天：交付 | 他 | 产出物（文件、截图、照片、语音、外部提交） |
| 白天：验收 | 验收器（§3.2） | 过 / 一半 / 不过，带依据 |
| 晚上：对账 | 墙 + 四部 | 当天的账 |
| 晚上：大脑 | 代码 + 鲸澜 | 模式卡、法规、权柄、明天的工作包 |

**三个器各在哪：**
- **调度器** = 备课 + 计划模态 + 开局 + 预案 / 墙（管资源：时间、App、注意力）
- **触发器** = 局官 + 鱼丸 + Gemini Live（在某一刻给一个具体动作；陪伴本身也是触发）
- **验收器** = 交付 + 验收 + 对账（管证据）

## 3. 现在缺的三样（这就是「好像还差些什么」）

### 3.1 缺「内容」：工作包

**问题**：现在的计划只写「10:00–12:00 求职局」。到了 10:00，局开了、App 锁好了、局官问「第一步是什么」——他答不出来，因为没人替他想过。触发器问的是「推到哪了」，可是根本没有「哪」。这就是你说的「它们无法给出当下的内容」。

**补法**：计划里的每一局都是一个**工作包**，前一晚由鲸澜备好，早上他确认：

| 字段 | 例（求职局） |
|---|---|
| 目标（一句话） | 投出 3 份简历 |
| 第一步（具体到动作） | 打开 Boss 直聘，筛选「上海 · 后端 · 1–3 年」，看前 10 个 |
| 后续步骤（≤ 5 步） | 选 3 个 → 改简历第二段 → 投 → 截图 |
| 必需应用 / 允许应用 | Boss 直聘、WPS / 浏览器、微信（只读） |
| 交付物 | 3 张投递成功截图 |
| 验收方式 | 截图时间在开局之后、识图能读到「已投递」、3 张 |
| 卡住时 | 第一步做不下去 → 局官切到「卡在哪」小局；20 分钟无进展 → 鲸澜介入 |

- 鲸澜备课时可以用的材料：长期目标、上周未完成的、笔记库、模式卡、他昨天说过的话。
- **第一步必须是一个 2 分钟内能开始的物理动作**，代码检查：含一个动词、含一个应用或物件、不超过 40 字。
- 局官的触发全部对着工作包问：「第一步做了吗」「现在在第几步」「交付物有几张了」，而不是空问「在干嘛」。
- 鱼丸在局间休息时可以提起刚完成的那一步（「你刚投了那家？我觉得他们 logo 好丑」）——陪伴也对着内容。

### 3.2 缺「验收标准在开局前定好」

**问题**：「给 AI 一些命令就能验收」——不成立。原因有三个：
1. 模型天生宽容，你给它一段像样的话，它就会说「不错」；
2. 模型看不见现实：你说投了 3 份，它没法知道你投没投；
3. 验收标准如果是事后定的，就一定会被他（和她）临场放宽。

**补法**：验收器早就有零件（墙的物理证据审查、思维局的判错依据、外部提交、判官），缺的是一条规矩：

> **每个工作包在生效时就写好交付物和验收方式。没有验收方式的工作包不能进计划。**

验收方式只有三类，按可信度排：

| 类 | 怎么判 | 例 | 谁判 |
|---|---|---|---|
| 证据 | 文件变化、截图（时间 + 识图）、使用时长、外部提交 | 3 张投递截图；文件长了 2000 字 | 代码 |
| 依据 | 和标准答案、原文、他之前的记录比对 | 行测答案；「刚才讲了什么」对原文 | 代码 |
| 判断 | 按事先写好的评分标准，引用原文打分 | 一篇分析写得清不清楚 | 判官模型，只在前两类用不上时才用 |

鲸澜备课时选验收方式，优先选「证据」；只有「判断」可用的工作包，一天最多 2 个。

### 3.3 缺「自律模态」：权力要能流回他手里

**问题**：到现在为止，所有设计都是把权力交给 AI：她能立法、能锁、能升级、权柄会涨。没有任何东西在他做得好的时候把权力还给他。这样的系统只能越来越紧，最后只剩两条路：他被管一辈子，或者他受不了把它卸了（fish-build-27 就是这么没的）。

自律的意思不是「管得更狠」，是**外面的管束随着他自己做得到而逐步撤掉**。

**补法**：和鲸澜的权柄对称，他也有一个**自律等级**，同样由代码按战绩算：

| 等级 | 条件（连续 14 天） | 系统怎么对他 |
|---|---|---|
| 0 托管 | 初始；或主动开局比 < 20% | 全套：计划自动生效、局自动开、预案全开 |
| 1 半托管 | 主动开局比 ≥ 30%，交付率 ≥ 70% | 计划要他确认才生效（超时仍自动生效）；切出预案的阈值放宽一档 |
| 2 自主 | 主动开局比 ≥ 50%，交付率 ≥ 80%，无「有害」升级 | 他自己排计划，鲸澜只审；严格模式只在他自己开或连续偏离时触发 |
| 3 自律 | 主动开局比 ≥ 70%，交付率 ≥ 85%，连续 28 天 | 预案默认影子（只记录）；鲸澜只出周报和建议；墙只管宪法和深夜锁 |

- 降级比升级快：任何一周交付率 < 50%，或单周触发 E3，直接降一级。
- **自律等级和鲸澜的权柄是两回事**：她的权柄管「她能做多大的事」，他的等级管「需要她做多少事」。他升到 3 级时，她的权柄还在，只是用不上。
- 「主动开局比」（他自己开的局 ÷ 系统开的局）一直是周报第一行，也是整个体系的北极星。

## 4. 「说话要明确」放在哪

思维要明确有力，这条规则只在**两个地方强制**，其余地方不管：

| 地方 | 怎么管 |
|---|---|
| 局里（局官） | 第八轮的沟通上限：单条字数、话题数、混乱只给压缩指令、连续混乱切写模式 |
| 计划模态（鲸澜） | 他只能「接受 / 换一局 / 删一局 / 加一局」，不能用一段长话把计划聊散 |

和鱼丸闲聊、和鲸澜聊心事**不管**：那是陪伴，也是他喘气的地方。全天候的「说话必须精炼」会把陪伴变成审讯。

## 5. 现在最大的风险不是设计

过去几轮，设计一直在加，真机证据几乎是 0。一个体系对不对，**只能靠用来判断**，再多的文档也回答不了「是否正确」。

建议：
1. **设计冻结两周。** 不再开新的方向，只做 §3 这三个缺口和补充二 §8 第 1 批。
2. **装 fish-build-122 用起来**，哪怕很多东西还没做。
3. **只看四个数**（每天自动记，周报给出）：

| 数 | 回答什么 |
|---|---|
| 主动开局比 | 他有没有在变得更自主 |
| 交付率（通过验收的局 ÷ 开了的局） | 局有没有真的做成事 |
| 空局率 | 哪种局最容易逃 |
| 局内偏离分钟数 | 管束有没有用 |

两周后看这四个数再决定下一步。数没动，说明设计有问题；数在动，说明方向对，继续。

## 6. 补充三的工单（并入补充二 §8 第 1 批）

| 工单 | 最小交付 |
|---|---|
| **W-1 工作包** | 计划项扩成工作包（§3.1 七个字段）；鲸澜备课生成；第一步代码检查；局官触发对着工作包问；测试 ≥ 25 条 |
| **W-2 验收前置** | 工作包没有交付物和验收方式就进不了计划；三类验收方式接到已有的验收零件；「判断」类每天 ≤ 2；测试 ≥ 20 条 |
| **W-3 自律等级** | 四级、升降规则、每级对应的系统行为（计划确认、预案阈值、影子化）；周报第一行；测试 ≥ 25 条 |
| **W-4 四个数** | 每天自动算，进周报和「计划」页顶部 |

W-1、W-2 排在计划页（B1）里一起做：计划页本来就要每局写明 App，顺便写全工作包。
