# 如何往两姐妹记忆库导入你的个人资料

把任何你想让「鱼丸」和「鲸澜」长期记住的笔记（Markdown `.md` 文件）放到当前目录 `大肥鱼/导入/` 里：

1. 每条要记住的事实写成 `- ` 开头的列表项（每条建议 10~120 字，说清一件事）。
2. 在前面加上 `📌 ` 的条目会作为**高优常驻核心记忆**直接进入每次对话上下文。
3. 你可以按主题拆成多个文件（例如 `我的项目.md`、`个人习惯与弱点.md`、`学习进度.md`、`常用软件分工.md`）。
4. 放好后，打开 App 的「大肥鱼中枢 → 生成记忆模板并导入 Obsidian 数据库」，或重启伴侣引擎，就会自动去重写入 `fish-memory.sqlite`（隐私目录如 `日记/`、`Diary/`、`私密/` 会自动跳过）。
