BUILT TO CONNECT

接入指南

先连通本地工具，再逐步扩展你的 Agent 团队。

01

启动与登录

在 Windows 解压项目，运行 install.ps1，然后双击 start.cmd。先在普通终端确认 Codex、Claude Code 或 Harness 能正常启动并已登录。

服务在你的 Windows 电脑上运行；工作目录也填写这台电脑上的路径。

02

配置自动任务

Codex 与 Claude Code 提供常用命令模板，请以本机版本的 --help 为准。DeepSeek Harness 需填入实际的非交互启动命令。

自动任务把完整提示词写入 stdin。命令必须读取 stdin、输出结果并退出。只有交互界面的程序请使用“交互终端”。

03

让 Agent 使用 MCP

将项目中的 mcp_server.py 配置为工具的 stdio MCP 服务。提供列出 Agent、发消息、读信箱、派发协作和查询结果等工具。

python C:\AgentBridge\mcp_server.py

具体配置见 README。MCP 客户端须与服务运行在同一台电脑，或能访问它的连接文件和本地地址。

04

协作边界

轮次间自动传递文本结果；每轮启动独立 CLI 进程，暂不恢复工具原有会话。文件通过各自的工作目录访问。

建议不同 Agent 使用独立 Git worktree，避免互相覆盖。当前版本只连接本机；云端连接器尚未实现。
