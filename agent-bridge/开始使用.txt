Agent Bridge 0.2.0 · Windows 桌面版

安装版：运行 AgentBridge-Setup-0.2.0-x64.exe，按提示安装。
便携版：完整解压 ZIP，然后双击 AgentBridge.exe；不要只复制一个 EXE。

不需要安装 Python。需要 Windows 10 1809+ / Windows 11 x64，以及 Microsoft Edge WebView2 Runtime。
Codex、Claude Code 和你的 Harness 本身仍需安装并登录。

第一次使用：
1. 到“接入指南”添加两个演示伙伴，先跑通流程。
2. 到“Agent 管理”检测本机工具，选择项目目录，再检查命令。
3. 回到工作台选择伙伴或主管模式，提交任务。
4. 从任务详情继续对话、续跑未完成轮次或导出结果。
5. 在“设置与备份”复制 MCP 配置，并备份 Agent 配置。

数据位于 %APPDATA%\AgentBridge。关闭窗口会停止当前任务；重启后可手动续跑。
DeepSeek Harness 需填写实际启动命令。真实模型能力取决于各工具的登录和权限。

当前支持本机 Agent；云端连接和接管已有窗口尚未实现。
详细说明见 README.md，测试记录见 VALIDATION.md。
