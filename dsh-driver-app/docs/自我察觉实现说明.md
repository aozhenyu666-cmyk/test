## 使用

首页默认伙伴模式，保持原陪练行为。开启监督并选 30/60/120/240 分钟后，复用 Engine 每秒 ticker 和 LockService：5 分钟小问、10 分钟四问复盘；10 分钟不叠加小问。可以暂停监督、跳过、只答部分、用输入法语音；不新增录音权限。小问复用 Overlay，复盘使用同一 Ui 的独立页面。后台页面若被系统限制，退到可点击通知，首页可接着回答。

观察先落盘再呈现，带实际窗口起止时间、固定/DSH 来源、应用时长、未知区间、回答、跳过原因与同步状态。监督截止时间/节拍和草稿持久化；进程重启后仍在有效期内的监督可恢复。进程死亡期间不冒充仍在观察，已过期监督不追补一堆弹窗。整包强制停止依然不能保证自行恢复。

无障碍记录根窗口确认过的包名（含本 APP）。锁屏、断连、进程空档记未知，不算给上一个 App。时间线保留 2 小时并留边界事件；是无障碍窗口估算，不是系统 UsageStats 精确统计。超过39种应用时，余量合并为“其他应用”。观察原始记录保留14天；支持查看最近30条与主动导出JSON。

截图开关和语音开关在首页可关。监督的察觉点才尝试一帧无障碍截图（Android 11+），宽不超过720、JPEG质量60、私有目录 `files/driver/shots`，7天清理。硬件 buffer 及时关闭；仅对瞬时内部错误/频率限制重试一次，安全窗口不绕过，系统可报错或返回黑色脱敏图，不能把“生成了图片文件”等同于截到了受保护内容；超时不拖住察觉卡。失败保存状态码，仍可回答。没有新增 `/app/shot`，网络只发送“有截图/失败原因”，不发送图片或私有路径。

## 大肥鱼闭环

- `/app/observe` 沿用本机 Host / Origin / 配对令牌校验。每批至多20条、单批至多256KB，按id去重，重复也确认；只有返回的准确id才移出APP队列。其他旧接口保持16KB限制。APP按实际字节数缩小批次，后台重试与提问使用不同的可用工作线程，补发不会阻塞4秒提问兜底。
- `/app/compose` 增加 `checkin_micro` / `checkin_deep`，返回1/4句问题；普通 compose 的 `card` 契约保留。注入最近6条观察、教练计划与最多12条相关记忆；监督问题要求引用实际素材，引用不符/超时/忙/格式错误则用固定问题。伙伴与监督口吻区分。
- 新的深度记录触发消化；批量积压可合并，同一时间仅一个消化。繁忙/失败的待消化标记持久化，冷却30秒后再试；重复投递不重复排队。消化提示要求同类偏离有至少3次证据才考虑记忆，代码也要求至少3条非跳过且有偏离回答的样本，语义是否反复仍由模型判断。
- 工具钩子按实际 SDK `ToolExecutionInput.name` 检查。普通出题全部禁止；消化仅精确名称 `remember` 最多2次。`run_code`、文件/网络/手机操作都禁止。超时的旧回合在真实 turn/end 前继续受限，不能借重入解除工具限制。
- **PTC兼容边界**：仅 `run_code` 的会话无法在此限制下调用记忆工具，不会放开 run_code 来绕过；请使用可直接调用原生 remember 的会话。fish-memory 自己管理配额/记忆库，插件不直接写它。计划存 `plan.json`，原始观察存 `observations.jsonl`，不建立新长期记忆系统。
- 部署需要同时更新 APK 与插件、重载 DSH 内核。旧插件不认识 observe 时，APP继续独立记录并保留待同步数据。实际 DSH 会话/模型/remember 运行效果须现场验证。

## 验证边界

纯核心测试覆盖 5/10 优先级、末次复盘、延迟合并、时钟倒退、时间线边界/未知区间。插件测试覆盖鉴权、批量限制、重试去重、持久计划、繁忙重试、精确工具权限/两次上限/超时后保护、引用素材及旧契约。

NOT_TESTED：国产系统后台弹窗/保活、真机TTS与Gemini的音频焦点、锁屏/重启/强制停止后的实际恢复、真实DSH工具装配与记忆写入。语音不是“确定Gemini已停下”的证据；观察也不代表能知道用户在想什么。
