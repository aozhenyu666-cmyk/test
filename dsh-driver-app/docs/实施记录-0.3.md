# 思维驾驶员 0.3 实施与验证

许可选择：内置拦截为独立重写，未复制 Curbox 实现。保留原有 Curbox API v3 兼容入口。Curbox 参考版本见任务书。

第一块：拦截名单、持久化限时放行、HOME 后延迟 100ms 答题、根窗口复核、1 秒去重、到期重查；首页选应用/开关/时长；内置与 Curbox 共用出题判卷界面。
第二块：显式开启的无障碍写回、30 秒前台看护、15 分钟持久任务、启动/回首页/开机/更新检查。只追加自身组件并读取回验，保留其他服务。设置写入不是服务运行证据。关闭自动修复后再在系统里停用服务；若哨兵也在看护，需要一并关闭哨兵的对应开关。

未将无障碍移至独立 :watch 进程：当前 Engine 与界面共用会话与诊断状态，直接改进程会丢失状态，需要额外 IPC；本轮采用独立于无障碍绑定的前台看护服务。整包强制停止后，自身服务/任务/广播不能保证恢复。

NOT_TESTED：国产系统后台弹页限制、HOME 后弹页、清后台、到期重拦、真机强制停止后哨兵写回能否重新绑定。排除最近任务仅减少划掉答题任务的机会，不保证免杀，也不妨碍到设置强制停止。

本地核心测试：29 项通过（含 BlockRules 新增 2 项）。本地 Android `:core:test :app:assembleDebug` 已通过（JDK 17 / SDK 34）。CI 结果在 PR 记录。答题通过沿用本地启发式判卷，不代表模型核实答案正确。

未添加固定 Release 发布：任务书将此列为单独授权项；本轮仍提供 Actions artifact。
