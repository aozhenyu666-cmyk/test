# 思维驾驶员 0.3 实施与验证

许可选择：内置拦截为独立重写，未复制 Curbox 实现。保留原有 Curbox API v3 兼容入口。Curbox 参考版本见任务书。

第一块：拦截名单、持久化限时放行、HOME 后延迟 100ms 答题、根窗口复核、1 秒去重、到期重查；首页选应用/开关/时长；内置与 Curbox 共用出题判卷界面。
第二块：显式开启的无障碍写回、30 秒前台看护、15 分钟持久任务、启动/回首页/开机/更新检查。只追加自身组件并读取回验，保留其他服务。设置写入不是服务运行证据。关闭自动修复后再在系统里停用服务；若哨兵也在看护，需要一并关闭哨兵的对应开关。

未将无障碍移至独立 :watch 进程：当前 Engine 与界面共用会话与诊断状态，直接改进程会丢失状态，需要额外 IPC；本轮采用独立于无障碍绑定的前台看护服务。整包强制停止后，自身服务/任务/广播不能保证恢复。

NOT_TESTED：国产系统后台弹页限制、HOME 后弹页、清后台、到期重拦、真机强制停止后哨兵写回能否重新绑定。排除最近任务仅减少划掉答题任务的机会，不保证免杀，也不妨碍到设置强制停止。

本地核心测试：33 项通过（含 BlockRules 新增 2 项、Interaction 新增 4 项）。插件 31 项 Node 测试通过（假宿主/纯逻辑，含新增 5 项互动测试）。本地 Android `:core:test :app:assembleDebug` 已通过（JDK 17 / SDK 34）。CI 结果在 PR 记录。答题通过沿用本地启发式判卷，不代表模型核实答案正确。

未添加固定 Release 发布：任务书将此列为单独授权项；本轮仍提供 Actions artifact。


第三块：可选 ComposeRequest.kind 与五种随机互动（跨会话保存最近 3 种）；先素材再问题；插件取最多 12 条记忆和最近 5 份报告结论；字面模板相似度达到 0.6 或缺引用则在 8 秒总预算内再出一次；失败保持旧 card:null 契约，APP 换互动类型后本地兜底。低带宽仍用小动作，收尾仍收结论。只扩展可选请求字段，不改路由、认证、版本或旧请求返回契约。识图只调研，见 Gemini-Live识图调研.md。

首块 CI：[41684823409](https://github.com/aozhenyu666-cmyk/test/actions/runs/41684823409) 已通过并上传 APK。最终 CI 见 PR #51。总控 PR #52、哨兵 PR #53 分别针对原项目分支；不迁移/混合项目代码。一手源码只读核对组件，没有改动。

验证后须由用户授予权限并在首页开启自动写回；真机重点测试：只勾 B站（先关闭 Curbox 同 App 拦截）；HOME→答题；通过后限时放行及到期重拦；未勾选的 Gemini/相机/文件选择器不受拦截；关闭无障碍后写回；force-stop 后由哨兵尝试写回；系统里保留另一个已启用无障碍服务，确认它始终保留。逐项仍为 NOT_TESTED。
