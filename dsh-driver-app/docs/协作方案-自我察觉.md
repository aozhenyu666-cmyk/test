# 整合方案：大肥鱼（DSH Go）× 思维驾驶员 —— 自我察觉闭环

目标：「读取记忆 → 生成指令 → 主动干预 → 用户反馈 → 更新记忆」跑起来。尽量复用已有的，只加缺的那几块。
本文给接手实现的编码助手看；和 `GPT-任务书.md`（0.3：内置拦截、无障碍自愈）互不冲突，可以先做那份，也可以并行。

## 1. 分工：谁做什么

| | 大肥鱼（DSH Go，大脑） | 思维驾驶员（APP，终端） |
|---|---|---|
| 已经有的 | 人格（它自己的会话）、长期记忆（fish-memory，模型调 `remember` 才写入）、dsh-driver-core 插件：`/app/pair` `/app/ping` `/app/compose` `/app/report`、`reports.jsonl` | 配对与本机通信（`DshLink`）、前台服务 + 每秒节拍（`Engine` / `LockService`）、顶部悬浮小卡与展开页（`Overlay` / `CardActivity`）、前台应用记录（`WatchService` → `Engine.recentForeground`）、本地存储（`Store`）、模板兜底出题 |
| 这次要加的 | ① 收观察记录 `/app/observe`；② 出题时带上最近的观察和"教练计划"；③ 定期"消化"：在大肥鱼自己的会话里跑一轮，让它自己写记忆、更新计划 | ① 定时察觉（5 分钟小问、10 分钟复盘）；② 本地观察记录 + 待同步队列；③ 应用使用时间线；④（第二步）截图 |

原则：**APP 只存原始观察，判断和长期记忆都归大肥鱼**。不接 Notion / IMA，不建新知识库。

## 2. 闭环怎么转

```
每 5 分钟  APP 弹小卡：「刚才 5 分钟你在做什么？」+ 附上这 5 分钟的应用时间线（如 Gemini 3 分、B站 2 分）
           你回一句（打字或输入法语音）→ 存本地 → 能连上就发给大肥鱼
每 10 分钟 APP 弹复盘页：做了什么 / 偏离目标没有 / 为什么 / 接下来做什么（问题由大肥鱼出）
           → 存本地 → 发给大肥鱼
大肥鱼     每次复盘后跑一轮"消化"：读最近观察 + 自己的记忆 → 自己决定要不要 remember（记住反复出现的习惯）
           → 写一份"教练计划"（下次问什么、语气、要不要加强监督）
下一次出题 /app/compose 带着这份计划和最近观察 → 问题越来越针对你
大肥鱼没响应 APP 用固定问题照样弹、照样记；恢复后把积压的一次性补发
```

## 3. 思维驾驶员要做的

### 3.1 两种模式

- **伙伴模式**（默认）：不定时弹，只保留现在的陪练小卡。
- **监督模式**：首页一个开关 + 时长（例 60 分钟）。打开期间才有 5 / 10 分钟察觉。复用现有的前台服务和每秒节拍，不新开调度器。

### 3.2 定时察觉

- 在 `Engine` 现有的每秒 `ticker` 里判断：距上次小问 ≥ 5 分钟 → 小问；距上次复盘 ≥ 10 分钟 → 复盘（复盘那一次不再同时弹小问）。
- 小问用 `Overlay` 小卡：一句问题 + 输入框（展开）+「跳过」。**跳过也记一条**（跳过本身就是观察）。
- 复盘用 `CardActivity` 展开页：4 个问题依次显示，每个一个输入框；可以只答一部分。
- 回答方式：打字，或用手机输入法自带的语音输入。**不另接麦克风**，免得和 Gemini Live 抢话筒。
- 问题来源：先请大肥鱼出（`/app/compose`，`intent` 传 `checkin_micro` / `checkin_deep`，4 秒内没回就用固定问题）。固定问题就是需求里那 1 + 4 句。

### 3.3 行为观察：应用时间线（先做这个，比截图可靠）

- `WatchService` 已经在记前台变化。改成持续记 `(时间, 包名)`，存最近 2 小时。
- 每次察觉时算出这一段每个应用用了多久（按切换时间相减），显示在卡片上，也一起发给大肥鱼。这是客观数据，能和你的回答对照（"你说在做题，但 B站 4 分钟"）。
- 需要无障碍开着；没开就只发回答，不发时间线。

### 3.4 截图（第二步再做）

- 用无障碍服务自带的截图（`AccessibilityService.takeScreenshot`，Android 11 起；`accessibility_service` 配置里加 `android:canTakeScreenshot="true"`）。**不用弹系统的录屏授权**，比 MediaProjection 简单。
- 只在察觉那一刻截一张，缩到宽 720、JPEG 质量 60，存 APP 私有目录，7 天自动删。
- 默认**不上传**，只把"有截图"记在观察里。要让大肥鱼看图，等确认它那边的模型能收图后，再加上传（见 4.4）。
- 银行、密码类页面系统会返回黑图，属正常。

### 3.5 本地记录与补发

- 新建 `files/driver/observations.jsonl`，一行一条：
  ```json
  {"id":"uuid","at":1762...,"kind":"micro|deep","mode":"supervise","question":"…","questionSource":"dsh|fixed",
   "answers":{"did":"…","drift":"…","why":"…","next":"…"},"skipped":false,
   "apps":[{"pkg":"com.google.android.apps.bard","label":"Gemini","sec":180}],"screenshot":"shots/….jpg|null","synced":false}
  ```
- 待同步：`synced=false` 的就是队列。每次 `/app/ping` 成功后，按 20 条一批 `POST /app/observe`，成功的标 `synced=true`。`id` 用来去重，重复发不怕。
- 只保留最近 14 天的原始记录。

## 4. 大肥鱼插件（dsh-driver-core/plugin）要做的

### 4.1 新接口 `POST /app/observe`（配对令牌鉴权，和现有 `/app/*` 一样）

- 收一批观察，按 `id` 去重，追加到 `$DSH_HOME/storages/dsh-driver-core/observations.jsonl`。
- 收到 `kind=deep` 的记录后，安排一次"消化"（4.3），同一时间只排一个。

### 4.2 `/app/compose` 扩展（向下兼容）

- 认识新的 `intent`：`checkin_micro`（返回 1 句问题）、`checkin_deep`（返回 4 句问题的 JSON 数组）。
- 提示词里加两块：最近 6 条观察的要点（回答 + 应用时间线），和 `plan.json` 里的教练计划。
- 伙伴 / 监督两种语气：请求里带 `mode`，提示词按模式换要求——伙伴模式自然聊天；监督模式就是教练，必须引用一条具体观察来问（"你 10 分钟前说要做第 3 题，后面 4 分钟在 B站，怎么回事？"）。

### 4.3 "消化"：让大肥鱼自己更新记忆（关键，复用 fish-memory）

- 在已认领的出题会话（「驾驶员就用这个会话」）里，用现有 `AgentBrain.ask` 发一条消息：附上最近一段的观察，请它：
  1. 判断有没有**反复出现**的行为或想法（同一类偏离出现 ≥ 3 次才算）；
  2. 值得长期记住的，**自己调用 `remember` 记下来**（一次最多 1–2 条，fish-memory 默认每天只给 8 条写入额度）；
  3. 只输出一个 JSON 教练计划：`{"focus":"接下来最该盯的一件事","pattern":"看到的习惯","style":"partner|coach","nextQuestions":["…","…"]}`，插件存成 `plan.json`。
- **注意**：现在插件会在驾驶员发起的回合里禁止调用任何工具（`AgentBrain.guardTool`）。消化回合要改成**只放行 `remember`**，其余工具照样禁止。
- 频率：每次复盘后最多一次；大肥鱼正忙就跳过，下次再说。

### 4.4 （第二步）看截图

确认大肥鱼会话的模型能收图之后：加 `POST /app/shot`（单张 JPEG，≤ 300 KB），消化回合附最近 1–2 张。确认之前不要做。

## 5. 实施顺序（每步都能单独用）

1. **APP 独立闭环**：监督模式开关 + 5/10 分钟察觉 + 固定问题 + 应用时间线 + `observations.jsonl`。不连大肥鱼也能完整用。core 里写纯 Kotlin 的节拍判断和时间线汇总，加 JVM 测试。
2. **接上大肥鱼**：`/app/observe` + 补发队列；`/app/compose` 支持 `checkin_*` 和最近观察。插件加测试（沿用 `test/app.test.mjs` 的假宿主写法）。
3. **记忆闭环**：消化回合（只放行 `remember`）+ `plan.json` 进出题提示词。
4. **截图**：无障碍截图本地存；之后视情况上传给大肥鱼。

## 6. 风险与取舍

- **弹得太勤会被你习惯性划掉**：小问一定要能一句话答完、能跳过；跳过次数本身交给大肥鱼分析。先按 5 / 10 分钟上线，之后再看要不要让大肥鱼在 5–20 分钟内调节奏。
- **fish-memory 写入额度**：默认每天 8 条，只让它记"反复出现"的东西；原始观察留在 `observations.jsonl`，提示词里用最近几条，不全塞。
- **截图隐私**：默认只存本机、7 天删除、不上传。
- **都还没在真机验证**：无障碍截图在部分国产系统可能受限；大肥鱼会话正忙时出题会退回固定问题。
