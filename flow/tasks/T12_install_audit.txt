====================
一、是什么
====================
新 ToolPkg "系统体检"（local.operit_audit 0.1.0），源码 github aozhenyu666-cmyk/test 的 flow/operit_audit。
- audit：检查工作流开关与调度新鲜度、关键状态文件、判断链（save_log）、锁队列，输出每项 PASS/WARN/FAIL 和总评。
- self_test：用人造的正常/异常场景验证体检的判断逻辑本身是否还准（模拟异常）。
全程只读，它唯一会调用的工具是 workflow:get_all_workflows。
