# 第十一批：只听电台、活体表现与常态对弈

> 配套 [总执行计划](DEEPSEEK-ALL.md)，依赖第十批的来源池/事件/预算。覆盖 B4/B5/B6、H4。
> 出口：她能拿着真实材料陪你讲一小段，你不回也不追问；想接招时一点击就能过招。不要只增加一种通知样式。

## 0. 施工边界

分支 `deepseek/moling-radio-play`，纳入已核对的前置。允许 core/live、core/spar、core/predict、core/review 的指定扩展，以及 app/live、app/voice、Speaker、Chat/Bench/Settings/Debug 的接线；必要修改 Brain/BrainHost/CognitiveCycle。
不改总控、授权阈值和硬限制；保留 TalkMode.FOG、Chess/Chesses、Habits，不能新造第二套引擎。RADIO用呈现会话表示，不必往 TalkMode 里再塞同义状态。

## R1：电台内核与内容队列（C）

实现 RadioSession/RadioSegment、PREPARING/PLAYING/PAUSED/FINISHED/STOPPED，状态带sessionId/focusId/segmentId/deadline。只播来源池/案板已有内容，或为明确焦点准备一次有预算的推演；不能一边播一边无限联网。引用事实和猜想分别措辞，不假装在看不存在的视频。

一段30–90秒，一次默认最多5分钟；按“接上上次→一个有意思的点→可选留个悬念”组织。不要求用户回答、不播“你怎么不说话/还没开工”。支持继续/暂停/跳过/停止；停止立即清空待播并取消该会话未开始作业，迟到模型/TTS回调不能再次开播。

保留内容产物ID和来源以便回看，音频临时文件会话后清理。模型失败显示可读摘要，不能进入“等会再试”无限循环。

## R2：先做可点击体验，再做自发陪伴（I+C）

在对话、案板和桌宠轮盘接“陪我听一会”。面板显示当前题目、来源、进度和醒目停止。用户随时只听不回，不扣分、不记成拒绝。

默认只有明确开始才播放。另设“应用内沉默时可续播”和“耳机伴随”开关，说明生效场景和上限；前者只在墨灵可见且会话有效时，后者需耳机/音频可用且遵守安静期。没有开启时不能由一次无回应偷偷开启电台。

拟新增接口，先写实现与测试再固定：
```kotlin
suspend fun radioStart(focusId: String?, sourceIds: List<String>): PortResult<RadioSession>
suspend fun radioPause(sessionId: String): PortResult<Unit>
suspend fun radioResume(sessionId: String): PortResult<Unit>
suspend fun radioSkip(sessionId: String): PortResult<Unit>
suspend fun radioStop(sessionId: String): PortResult<Unit>
```
状态由 StateFlow 统一渲染，不靠 Composable重组重复start。

## R3：反免疫从“换皮肤”变成情境学习（C+I）

复用 HabitBook/marks/cooling，映射到第十批CognitiveProfile，保留旧记录。曝光必须区分：真正显示/有机会看到/未观察、回复、有用、跳过、明确停止。未连耳机、被系统拦浮层不计“他不理我”。

两次同形态低回应可冷却该形态48小时；然后在可用形态中按新鲜度/效用选另一种，或把材料留在案板。总预算和安静期优先，不因 ignored 增长无限加压。

“先不聊了/别管我”直接进入可查看的安静期；用户可恢复。把“因为冷落减少所有自发好奇”改为“后台可在预算内准备，前台不强迫出声”：保留她的闲心，也保留休息。调试页写出为什么选这种表现/为什么没有出现，低样本时不宣称某方法特别有效。

## R4：一手统一使用材料与已有棋局（C+I）

FOG/TOLL/Chess接来源材料：优先当前焦点和用户刚分享的内容；仅在有真实快照时说“刚才屏幕上那句”。只有包名/时长时用“我想到一个小问题”，不能编视频标题。

FOG固定2–3短选项、一个退出；模型遗漏本地兜底；一点击即回应。TOLL每天和出声间隔有预算，不每次页面切换出题；材料不足不启动内容题。三手棋保留既有回合/评分，题干、解释、来源与练习标志可回看；正式草稿不混入故意的错。

把“听完这一段→可选捉一个漏洞”连起来。做完一轮可点“继续听/再来一局/先停”，不自动进入总控放行。题目主观/答案有争议时允许“这题有问题”，留给参谋复核，不惩罚用户。

## R5：思维选择赌局（C+I）

新增 ChoiceBet，关联具体session/题目/选项ID/截止时间/观测证据。支持“猜你选A”“猜你愿意接这一轮”；观测到结果才settle，无法观测就UNOBSERVABLE，取消不算输。

玩笑“我赌你…”不显示伪概率；可评分预测只有明确概率/结果定义时纳入自己的Brier集合，与旧娱乐分钟预测分开。不能因输赢提升Powers、改授权或剥夺退出。激将风格单独开关，默认用温和邀请；不羞辱、不诊断“你脑子断电”。

在卡片/电台/弹幕复用同一赌局ID，不能展示三次就生成三笔赌。用户可关闭赌局，旧记录保留结果而不再推送。

## R6：HUD轮盘、耳语、语音与微停顿（I）

- 点桌宠展开轻轮盘：破雾点选/当场捉虫/只听电台/先安静；关闭不抢焦点，不强制切回墨灵。
- AudioSessionController独占会话、管理音频焦点与duck；正常/出错/取消都释放，不硬改系统媒体音量。来电/导航播报/拔耳机时暂停或退回文字，不外放未获允许内容。
- Speaker保留原生TTS通路，可选云TTS；按segment回调，旧session回调丢弃，停止后不续播。
- 显式开启VoiceSession后才启动SpeechRecognizer，TTS结束可在有效会话内听5秒；按钮/通知显示正在听和停止。后台弹窗不自动打开麦克风。现有RECORD_AUDIO许可未开时由用户在界面开启，拒绝可继续点选。
- 可选“微停顿”：墨灵自己的局部浮层最多1–3秒，限定选择的娱乐应用，可关闭，不挡导航和急事，不点击其他应用。W12未提供有效坐标前只做已有浮层区域版；坐标过期、旋转、换窗口立即取消。与租约坐标的最终接线在 W12 A4 验收。

不做“倒计时结束替你执行最差方案”。想保留这个创意，作为案板练习中的沙盘分支，到点只显示模拟后果。

## R7：检验与交付

核心测试：状态机所有停止路径、晚到回调、重复start/skip、预算和安静期优先级、形态冷却、低样本、赌局过期/无法观测/重复结算、练习材料分离。App验证：真实Speaker/Recognizer适配可mock生命周期，Android测试/打包。

真机：
1. 同一材料点“陪我听”→播放一段→暂停/继续/跳过/停止。
2. 不回答也不会追问；停止后等待一会不自动恢复。
3. 音乐+耳机耳语结束，音频恢复；拔耳机/来电/锁屏按策略暂停。
4. 轮盘接一轮破雾/三手棋，退出始终可用。
5. 明确“先不聊”后不换弹幕或语音继续骚扰。
6. 显式对讲能续听，停止/撤权限后不监听。
7. 同一赌局换呈现不重复记账；无结果标未知。
