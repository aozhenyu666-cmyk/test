# 墨灵真机测试流程

> 第一轮大约 30 分钟（第 3 节需要你正常用手机一段时间，可以分几次做）。
> 每一步：**做什么 → 应该看到什么**。不对就截图，记下时间，按第 6 节发过来。

---

## 0. 准备（5 分钟）

1. 装最新的 **moling-latest**（总控也装最新的 **zongkong-latest**）。
2. 打开墨灵 → 点右上角的**小圆环** → 进「她准备好了吗」清单，把“必须的”一项项点开：
   - AI 接口（没填就去填 DeepSeek 的密钥）
   - 总控连上了（打开一次总控）
   - 看前台应用、显示在其他应用上层、通知、后台陪着
   - 不被省电杀掉（vivo 还要：i 管家 → 应用管理 → 权限 → 后台高耗电 → 允许墨灵）
   - ✅ 应该看到：圆环变满，“都好了”。
3. 设置 → **活的墨灵**：「她会主动找你」开、「她多主动」选 **多**（测试时方便触发）、「她可以拦住你」开。
4. 体系图里先放点东西（三手棋要用）：**体系**标签 → 粘贴一段你自己的笔记（几句话就行，比如申论怎么写）→ 收进体系图。
   - ✅ 应该看到：出现 3 条以上论断。

---

## 1. 对话页（5 分钟）

| 做什么 | 应该看到 |
|---|---|
| 随便说一句话 | 她回复，像纸条；顶上的小墨滴表情会变 |
| 点台子上的「让她想想」 | 过几秒提示“她想了想”；台子上出现「她的推断」，可能还有“她想跟你说：…” |
| 展开「她的推断」，点一条「对」或「不对」 | 那条消失（记下了） |
| 点「来一局」 | 她给一句带漏洞的话，下面 3–4 个选项，顶上“三手棋 · 第 1 手” |
| 点一个选项 → 再点一个 | 第二手问“下一步会怎样”；第三下后显示**分数**和“新结论挂进体系图了” |
| 去**体系**页 | 那条新结论前面有个**小棋子**记号 |
| 模式条选「破雾」，说一句“有点懵” | 她不问“卡在哪”，回复下面出现**选项按钮**，点一下她接着说 |
| 点「对讲」，说一句话 | 说完自动发出；她念完后自动再听；说两轮后点「停对讲」 |

## 2. 今天页（2 分钟）

| 看什么 | 应该看到 |
|---|---|
| 顶部 | 月亮（按时间变圆缺）+ 大字时间 + 流动的水纹 |
| 精力行 | 小火苗 + 今天做事 / 娱乐分钟（总控连上才有） |
| 思维转速 | 一个圆环和分数；刚才下过棋、点过选项，分数应该 > 0 |
| 今天的手机 | 用了一会儿手机后：24 小时的墨线图 + 用得最多的应用 |
| 一周的手机 | 用满 3 天后才出现 |

---

## 3. 她主动出现（正常用手机时顺便测，可分几次）

> 她**不是每次都会出来**：同一类事有一半时候“懒得说”，两次之间至少隔 12 分钟（“多”档）。没出来不一定是坏了——看第 6 节的调试页日志。

| 做什么 | 应该看到 |
|---|---|
| 连着刷抖音 / B 站 40 分钟以上，**或**在 B 站、微信、桌面之间来回切 3–5 分钟 | 她用某种方式出现：底部卡片 / 桌宠从边上跳出 / 大墨滴盯着你 / 弹幕飘过 / 耳机里一句（戴耳机时） |
| 看她这时说的话 | **不提主线、不问“卡在哪”**，只抛个好玩的问题 + 2–3 个选项 |
| 点三下选项 | 第二下变成“两分钟的小事”（喝口水 / 再看一个就停…），第三下收尾 |
| 刷了 15 分钟以上，切到别的应用 | 可能收“过路费”：“刚才那一大段里，有一个你还记得的东西吗？” |
| 锁屏 30 分钟以上，再解锁 | 可能打个招呼：“回来啦…” |
| 闲着、好久没动脑（上午 9 点后） | 可能来邀你下三手棋 |
| **23 点后**躺着刷 15 分钟以上 | 可能整屏拦住你：点两个选项就放；**「急事」按钮一直在**，点了马上回去 |
| 拦人页出现后按 Home 再回抖音 | 一分钟内她又出来；5 分钟到了自动放行 |
| 戴耳机放音乐时她用“耳语”出现 | 音乐变小 → 耳机里一句 → 音乐恢复 → 边上亮 8 秒“回她” |
| 打开设置里「刷着刷着慢慢褪色」，再连刷 | 画面慢慢变灰，**手指照常能滑**；切走立刻恢复 |
| 从对话页“去聊”打开 ChatGPT | 屏幕角上一个小胶囊，时间在走；切回桌面就消失 |

**一定要确认的**：电话、微信、支付宝、地图、设置里，她**从不**拦人、不出桌宠、不褪色。

## 4. 和 GPT 贯通（可选，10 分钟）

| 做什么 | 应该看到 |
|---|---|
| 设置 → 贯通 → 「ChatGPT」 | ChatGPT 打开，输入框里预填了墨灵的材料和问题 |
| 在 ChatGPT 里发出去，长按它的回答 → 分享 → 墨灵 →「这是 AI 的回答」 | 提示“收到了 / 收进体系图 N 条”；通知“GPT 那边：…” |
| （更进一步）按贯通页的 8 步部署联络站 | 「保存并同步」显示“黑板推上去了” |

---

## 5. 第二天看（1 分钟）

| 看哪 | 应该看到 |
|---|---|
| 今天页 | 早上自动排了一份水道草稿（通知“今天的水道排好了”） |
| 通知 | 夜里的“今天的账” |
| 体系页顶部 | 可能有“她替你采的：…”简报，点「收下」或「不要」 |
| 设置 → 了解 · 周报 · 参谋 | 可能有她提的规律（“当……，就……”）等你点「对 / 不对」；“她推过的”列表；“她怎么出现”统计 |

---

## 6. 出问题怎么报

1. **截图**出问题的那一屏，记下**大概几点**。
2. 打开 设置 → **调试**，往下翻到**日志**，截一张（里面有“她看了一眼，没出声”“拦住了…”“他点了…”这类记录，能看出是没触发还是坏了）。
3. 一句话说：做了什么、期望看到什么、实际看到什么。
4. 闪退的话：说清楚点了哪里之后闪退的。

把这几样发回当前协作会话，或附在本批问题记录里。
