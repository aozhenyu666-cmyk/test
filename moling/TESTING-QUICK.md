这是首次体验的简版。更完整的日常触发、总控联调和第二天检查见 [完整测试流程](TESTING.md)。

## 下载和准备（约 3 分钟）

- [墨灵官方仓库发布页](https://github.com/aozhenyu666-cmyk/test/releases/tag/moling-latest) · [直接下载 moling.apk](https://github.com/aozhenyu666-cmyk/test/releases/download/moling-latest/moling.apk)
- [总控官方仓库发布页](https://github.com/aozhenyu666-cmyk/test/releases/tag/zongkong-latest) · [直接下载 zongkong.apk](https://github.com/aozhenyu666-cmyk/test/releases/download/zongkong-latest/zongkong.apk)

目前是项目的 Android 调试测试版。覆盖安装即可；先保留旧数据，不要为了测试卸载。
下载前记下发布页标题中的版本和提交；安装后记下 App 显示的版本，反馈时带上。
若直链临时不可用，打开发布页，从 Assets 点 APK。

先打开一次总控，再打开墨灵，点右上角小圆环看「她准备好了吗」。
先填好文字模型接口，检查总控连接；主动出现还需要前台应用使用权限、悬浮窗、通知和后台运行。
对讲时按系统提示允许麦克风。AI 密钥只填在自己手机上，反馈截图不要带出密钥。
vivo 如后台被杀，可到 i 管家的后台高耗电设置允许墨灵。

## 先试这些（约 7 分钟）

| 操作 | 观察什么 |
|---|---|
| 发一句“今天有点乱，先陪我理一下” | 有正常回复；未填模型或网络失败时有可理解的提示，不闪退 |
| 打开键盘、输入多行，再收起键盘 | 输入框和发送按钮可见；能看到最新回复；收起后布局恢复 |
| 进入设置子页，按系统返回；在其他主标签再返回 | 先退出子页，再回到对话；不会一步就意外退出 |
| 模式选“破雾”，说“有点懵” | 有简短回应和可点选项；不连续追问长计划 |
| 快速连点同一个选项两次 | 不重复发两条相同选择，不把进度推进两轮 |
| 点“对讲”，说两轮，再点“停对讲” | 回复后能够继续听；停止后不再继续听；权限 / 网络问题有提示 |
| 体系页放入几句自己的笔记，再从对话页点“来一局” | 能进行三手棋并正常收尾；没有材料时不崩溃 |

每项可以只记“通过 / 不通过 / 没测”。模型生成需要联网，不把等回复的时长当成固定标准。

## 正常用手机时顺便观察

设置里打开“她会主动找你”；测试时主动程度可临时设为“多”。
她会受间隔、精力和随机选择影响，不保证一打开娱乐应用就出现；没出现时先看设置 → 调试 → 日志。
观察是否过于频繁、是否真的有帮助、弹窗能否顺利关闭。
若出现拦人页，“急事”应能立即放行；电话、支付、地图等必要应用不应被拦。

先体验核心部分即可。Notion、联络站、额外语音模型可以之后再配。
