# v13 真机验收（墨灵 + 总控）

> 这份测的是 v13 新加的东西：案板、联网采蜜、她主动准备、电台、外脑、计划代驾、以思代锁、系统工具、画像。
> 老功能（对话、今天页、她主动出现）还按 [TESTING.md](TESTING.md) 测。
> 每一步写的是：**做什么 → 应该看到什么**。不对就截图、记下时间，到「调试」页点「复制全部」一起发过来。
> 全部做完大约 60 分钟。第 5、6、9 节要等时间过去，可以分几次做。

---

## 0. 准备（5 分钟）

1. 装最新的 **moling-latest** 和 **zongkong-latest**，两个都打开一次。
2. 墨灵 → 设置 → **AI 接口** 填好密钥（没有密钥的话，后面凡是写着“模型”的步骤，你会看到“离线骨架 / 模型没接上”，这是对的）。
3. 想测联网：设置 → **联网采蜜** → 填「Brave 搜索密钥」。没有就跳过第 2 节的联网部分。
4. 墨灵 → 设置 → **调试**：往下翻能看到【以思代锁】【计划 → 动作 → 回执】【外脑】三块，说明是新版。

---

## 1. 案板：贴材料 → 她先做一块 → 你改（10 分钟）

| 做什么 | 应该看到 |
|---|---|
| 「案板」标签 →「贴材料」，问题写“申论开头怎么写”，贴两三句自己的笔记 → 开案 | 进入这件事，上面是问题，下面有你的材料 |
| 点「替我先做一块」 | 一份三点纲要。有依据的块标了来源；没依据的标“待核”。没模型时标“离线骨架” |
| 在一块上点「挑刺」 | 出现一条“对手”批注，带 A / B 两条改法 |
| 选 A 或 B | 那一段变成选的那条；顶上版本号 +1 |
| 点「撤销」 | 回到选之前的样子 |
| 在一块上点「改」，手动改一句 → 存 | 改的内容留下来，不会被她回来的结果覆盖 |
| 点「四参谋」 | 四个声音各说一句（没模型会说连不上，不假装） |
| 「整份采用」→「导出」/「复制」 | 能复制出一份完整稿子 |
| 菜单 →「收起这件」 | 回到案板首页；这件事不在“可以续上的事”里（收起 = 不要了） |

## 2. 联网采蜜（5 分钟，需要 Brave 密钥）

| 做什么 | 应该看到 |
|---|---|
| 案板首页 →「去查一下」 | 查到网页后才出现一件新事；里面有“支持 / 反对 + 来源”，来源能点开原文 |
| 没填密钥时点「去查一下」 | 明确说没配搜索，**不出假结果**，也**不留一件空的事** |
| 设置 → 联网采蜜 → 打开「每天自动一份」 | 一天最多自动查一次；它只往**已有的那件事**里加，不自己新开一件 |
| 在浏览器里分享一篇公开文章给墨灵 | 墨灵能取正文，放到当前这件事的材料里，标着“网页来的、未核实” |

## 3. 她先替我做一块（W10 T7，默认关，15 分钟）

| 做什么 | 应该看到 |
|---|---|
| 设置 → 联网采蜜 → 打开「她先替我做一块」 | 开关打开 |
| 开一件新事，只贴材料，不点「替我先做一块」，离开墨灵 | 等 10 分钟左右（下一次心跳），收到通知“我先替你拆了一份纲要” |
| 点通知进案板 | 纲要在，**没有被采用**；你可以挑刺、改或者不要 |
| 什么都不改，再等 | **不会**再做第二份（同一版材料只做一次） |
| 补一条材料，再等 10 分钟 | 已经有稿子了，所以还是**不会**再做 |
| 晚上 23 点以后，或者你刚说过“先不聊了” | 不做 |

## 4. 焦点两小时到期、续上（W10 T8，可分两次）

| 做什么 | 应该看到 |
|---|---|
| 开一件事，然后两个多小时不碰它 | 回到案板首页：这件事出现在「可以续上的事」里，写着“两小时没动，先收起了 · 几小时前 · 材料 N 条 · 稿子 N 份” |
| 点它 | 回到**同一件事**：材料、稿子、撤销历史都在，不是新开的 |
| 开着一件事，再「开新的一件」 | 旧的那件在「可以续上的事」里，写“收起” |
| 每次打开墨灵 | **不会**自动另起一件新事 |

## 5. 她怎么找你（认知画像，W10 T8）

| 做什么 | 应该看到 |
|---|---|
| 设置 →「她怎么找你」 | 按方式、按时段列出：出现几次（显示 / 有机会看到 / 没被看到），回应、敷衍、跳过、明确拒绝、急事各几次 |
| 刚装好、记录少 | 写“样本不足（n/10），先不下结论”，**不给百分比** |
| “记录里没有的”那几行 | 他在哪、在用什么 App、戴没戴耳机都写“未知”；“有用”写“未记录” |
| 用了几天、某一种方式超过 10 次 | “她看出的规律”里可能出现一条，后面写“她这么觉得，你还没说” |
| 点「对」/「停用」/「撤回」 | 后面的状态跟着变；她的出现方式**不会**因此马上改（这一批只展示） |

## 6. 电台「陪我听一会」（W11，10 分钟）

| 做什么 | 应该看到 |
|---|---|
| 案板（有材料的一件事）→「陪我听一会」→「开始」 | 她把材料念成一段段，状态从“准备中”到“播放中”；下面写来源 |
| 播放时插拔耳机 | 拔掉耳机自动暂停（不外放吓人） |
| 来电话 / 别的 App 放音乐 | 电台让路（暂停或压低） |
| 点「跳过」/「停止」 | 跳到下一段 / 停下，通知栏的播放卡片消失 |
| 默认情况下锁屏 | 停播 |
| 设置 → 在你身边 → 打开「电台锁屏后继续播」，再锁屏 | 锁屏后继续，通知栏 / 锁屏有播放控件 |
| 一边播一边在对话页打字 | 电台**不会**被打字停掉 |
| 桌宠上点一下 → 轮盘 →「只听电台」 | 开始念；轮盘收起 |

## 7. 破雾 / 过路费用你的真材料（W11 R4）

| 做什么 | 应该看到 |
|---|---|
| 案板上有一件事在做，然后去刷娱乐 App，等她出现 | 她的话 / 题目来自你案板上的材料，或者你说过的话 |
| 任何时候 | 她**不会**说“你在看的 XX 视频……”——她看不到你屏幕 |
| 同一天被收过路费 | 一天最多 3 回 |
| 卡片上点「先不聊了」 | 进安静期，两小时不主动出声 |

## 8. 外脑：发出去 → 收线（W12）

| 做什么 | 应该看到 |
|---|---|
| 案板一件事 →「发到外脑」→ 选 ChatGPT / 别的 →「生成进场包」→「复制进场包」 | 剪贴板里是一段带 `[[外脑:ob-…]]` 标记的说明 + 材料 |
| 去 ChatGPT 粘贴、拿到回答，复制回答 | — |
| 回墨灵 →「收线」→ 粘贴 →「接回案板」 | 结论作为材料 / 稿子放上案板，**未采用**；不自动交给总控 |
| 收线弹窗里点「说一段」，口述一句结论 | 系统识别；文字出现在框里，可以改；**不点就不听** |
| 点「停」，或者直接关弹窗 | 识别停掉（麦克风不再被占用） |
| 两个会话同时在等时收线 | 默认不选；不选就点不了「接回案板」 |

## 9. 计划代驾：采用 → 交给总控（W13 G1/G2/G5）

| 做什么 | 应该看到 |
|---|---|
| 今天页生成今天的水道 | 「计划代驾」里有一份草稿，写着“本地：草稿，你还没采用” |
| 等 20 分钟不管它 | 一条通知“到点了，点一下用今天的计划（不会自动执行）”；**不会**自动采用 |
| 点「采纳」 | “本地：你已采用”；下一行“总控：还没交给总控” |
| 点「交给总控（按授权书）」 | 授权书范围内的：总控那边 60 秒倒计时，可以取消；范围外的：总控弹出问你 |
| 等倒计时走完 | 今天页下一行变成“总控：已确认 N …”；调试页【计划 → 动作 → 回执】能看到 计划 → 每条动作 → 回执编号 |
| 倒计时里在总控点取消 | 那条写“总控拒绝”，**不会**重发 |
| 交给总控时把总控强行停止 | 那条写“结果未知（不重发）” |

## 10. 以思代锁：训练换玩的时间（总控 + 墨灵，10 分钟）

| 做什么 | 应该看到 |
|---|---|
| 总控 → 设置 →「以思代锁」→ 打开，选一个被管的 App | 写着要等 24 小时才生效（放松都要冷静期）；收紧马上生效 |
| 24 小时后，把赚来的玩时间用完，再打开那个 App | 拦截页写“赚来的玩已用完”，下面有「做一局训练」 |
| 做 4 道题，答对 3 道 | 拿到 N 分钟，回到那个 App 能用；答错太多就没有，回到原规则 |
| 墨灵今天页 | 有一行训练入口（总控开了、今天还有次数才出现），点开同样能做 |
| 总控「以思代锁」页最下面 | 最近 10 局：状态、有没有通过、回执；**看不到答案** |
| 不是因为“玩的时间用完”被拦（比如严管时段） | **没有**训练入口 |

## 11. 系统工具（第十五批 B5，各自默认关）

| 做什么 | 应该看到 |
|---|---|
| 设置 → 系统工具 → 打开「日历忙闲」，系统弹权限 → 允许 | 今天的水道会避开日历里忙的时间；不读日程内容，只读忙 / 闲 |
| 打开「主河道勿扰」，系统让你去给勿扰权限 | 主河道开始时手机进勿扰，结束时恢复成原来的档位（只恢复它自己改的） |
| 打开「歌单提醒」，填一个歌单链接 | 主河道开始时一条通知，点了才打开歌单；不会自己放 |
| 拒绝日历权限 | 「日历忙闲」开关回到关，不反复弹；勿扰没给权限时写清楚“没权限”，不假装开了 |

## 12. 备份（W13 G5）

| 做什么 | 应该看到 |
|---|---|
| 设置 → 记忆与备份 →「导出」 | 存出一个 json |
| 清掉一件案板的事，再「导入」刚才的文件 | App 重启后：对话、体系图、案板、来源都回来了 |
| 导入之后 | 计划账本、外脑会话、训练通行证**不会**恢复，也**不会**重复执行任何动作 |

## 红线（每一轮都要看一眼）

- 电话、短信、支付、地图、设置、总控、墨灵、微信**从来不被拦**。
- 任何拦截页上「急事」都在，都能用。
- 放松规则只在总控里、只有 24 小时冷静期这一条路；墨灵里没有“马上放松”的按钮。
- 她不替你花钱、不替你发消息、不读聊天和别的 App 的屏幕内容。
- 麦克风只在你点了「说一段」/「对讲」之后才开；关掉弹窗 / 停止就释放。
- 关于你的重要结论（规律、画像）都要你点了才算；没有“默认生效”。
