# 同桌

> 项目正式名称：**同桌**（手机桌面上显示的应用名）。取自需求文档里的角色定位——“像一个聪明、敏锐、有点毒舌但懂你的熟人同桌”。代码目录 `companion-pet/` 和包名 `cn.companion.pet` 保持不变，否则已安装的版本无法覆盖升级。之前文档里的“伴生桌宠 V1.5”“桌宠”都指这个项目。

手机上的 AI 伙伴：悬浮气泡负责开场，完整聊天页接着聊；默认用 DeepSeek，可按当前文字、明确允许上传的画面、没聊完的话题和目标主动交流。

当前版本：**0.8.3-partner-v1-preview（versionCode 43）**，主线为 `claude/r21-strict-takeover`。伙伴核心与接线均已实现；自动化通过情况、实际构建与真机待测项见 [验收表](handoff/claude-r21-strict/ACCEPTANCE.md) 和 [伙伴交接](handoff/partner-v1/IMPLEMENTATION.md)。这是个人测试用预览包，尚未完成真机验收。

- 点气泡“展开聊天”，或首页“和同桌聊”，进入同一份会话。普通聊天没有两轮上限；收起、切走后 30 分钟内可以接着聊，闲置超过 30 分钟结束。
- 设置 → 陪伴：每小时主动次数 5–40，默认 20。实际频率受睡眠时段、打字、通话、录音、受约束回合、未回应退避和每日模型额度影响。可以直接安静 30 分钟。
- 骑行 / 走路语音模式：戴好耳机，通过通知停止；依赖设备的系统语音识别和 TTS。关屏、耳机路由及国产 ROM 的后台表现仍需真机测试。
- 看图单独配置视觉模型并明确开启上传，DeepSeek 文字模型不会因此自动获得视觉能力。看图可以带问题、显示具体细节、在当前会话追问；完整画面观察只在内存保留。主动看图按视频 / 游戏类别和可编辑的应用名单选择时机。
- 记忆提议由你确认后才写入事实库；“我的 → 记忆”可核对来源原话、删除事实，以及暂停、关闭、删除话题线。新伙伴聊天不会通过夜间整理绕过记忆确认。
- 自主检索目前使用搜索摘要，会明确说明没有读取正文；不能据此声称已经读完链接中的文章。

需求依据：[原始 V1.5 需求](https://claude.ai/artifact/GBaCjrc1shZXy4v391C4zu)；本轮任务见 [伙伴实施计划](handoff/partner-v1/PLAN.md)。下面保留的外部 AI 会话、陪练和设备操作说明属于各自流程，不能据构建成功推断其真机可靠性。

基础记忆层的历史实现见 [0.3.1 交接](handoff/codex-foundation-v3/STATE.md)。设备覆盖升级的条件见 [升级验证](handoff/codex-foundation-v3/UPGRADE_VALIDATION.md)，不能把 APK 构建成功当成手机已验证。

## 安装

1. 手机浏览器打开当前主线预览包：**https://github.com/aozhenyu666-cmyk/test/releases/download/tongzhuo-preview-claude-r21-strict-takeover/tongzhuo.apk**，下载后覆盖安装。版本、源码提交和 SHA-256 以 Release 说明及本轮验收表为准。
   - 从 0.5.2 起使用同一把测试签名，可以覆盖安装并保留权限、记忆。若手机已有更高 versionCode，不要为降级卸载。
   - 也可以在 GitHub Actions 的 “Companion Pet Android” 运行记录下载 `companion-pet-debug-<commit>`。
2. 打开“同桌”，在“开始”页按顺序开权限：
   - **悬浮窗**（必需）
   - **无障碍服务**（必需）。开关是灰的：应用详情 → 右上角 ⋮ → 允许受限制的设置，再回来开
   - 麦克风和通知、不限制电池（推荐）
   - vivo / iQOO：i 管家里允许自启动和后台高耗电；应用权限里允许“后台弹出界面”；最近任务里把桌宠锁住
3. 到“设置”填 DeepSeek 的 API Key（地址默认 `https://api.deepseek.com`，模型默认 `deepseek-chat`，都能改），保存。
4. 回“开始”点“启动桌宠”。

## 怎么用

| 操作 | 效果 |
|---|---|
| 它主动开口 | 气泡里一两句话。可以按住说话、打字、去 Gemini；学习场景多一个“一起看”（Gemini Live） |
| 点一下角色 | 主动叫它，弹出入口；有信时先给你看信 |
| 按住角色说话 | 学习场景：直接带着屏幕内容进 Gemini；其他场景：它接你一句 |
| 拖动角色 | 换位置，松手吸附到最近的边 |
| 通知栏 | “安静一会”暂停主动开口；“停止”关掉桌宠（之后不会自动拉起） |

### AI 会话（Gemini / ChatGPT / 千问）

在“设置 → 深聊用哪个 AI”里选一个。包名会自动在手机上找（千问由通义改名而来，包名不固定），找不到可以手动填。

和它聊的时候，桌宠帮你守住这段对话，头上会出现蓝色的 **G**。

- **怎么开始**：在气泡里点“去 …”或“一起看”；或者自己打开 Gemini / ChatGPT / 千问 停留 20 秒。
- **切出去时**：文字深聊中切到别的 App，气泡倒计时 10 秒，到点把 Gemini 拉回来（回到原来的对话，不会新开）。倒计时里可以点“现在回去”、“给我 5 分钟”或“结束会话”。
- **调整**：
  - 下拉通知栏、弹出输入法、点开桌宠自己的设置页，都不算离开。
  - “会话中允许的 App”（加上学习 App）宽限 90 秒，适合去笔记里记一笔、去阅读器复制一段。从那里再切到别的 App，宽限缩回 10 秒。
  - 3 分钟内被拉回 3 次，就不再拉，改问你要不要结束。
  - Live 共看本来就要切出去，只记录、不拉回。
  - 熄屏 15 分钟、或者离开 30 分钟，会话自动结束。
- **怎么结束**：点桌宠 →“结束会话”。每次会话的时长、离开和拉回次数会记进当天的记录，统计页也有。

### 想一想（看东西时帮你思考）

点一下桌宠，气泡里有“想一想”和“记个念头”。

1. **划过留痕 → 划过了啥**：你快速往下滑的时候，它把经过屏幕的段落记在内存里（只留 10 分钟，熄屏清空，不存文件；信息流 App、排除 App 和 AI App 里不记）。点“划过了啥”，它列出 2–3 条要点，指出一处最值得慢下来重看的地方，再问你一个检验有没有看懂的问题。
2. **提问模式**：对刚才划过的内容（没有就用当前屏幕）选一种问法：
   - 追问我：苏格拉底式，由浅入深追问前提、证据、推论
   - 讲给我听：费曼法，先让你用大白话讲，再追问外行最可能问的
   - 挑刺：指出最站不住的论点，让你自己判断
   - 联系旧知：结合它对你的了解，问这和你以前学过、经历过的有什么关系
   你点“说一句”或“打字”回答，它回应一次：讲清楚了什么、哪里还含糊。随时可以点“带去 Gemini/ChatGPT/千问”，要点、问题和你的回答会一起带过去，请对方接着追问。
3. **记个念头**：看到一半冒出想法，点“记个念头”说一句，就和当时在看的那句原文一起存下来。“记忆”页能看到所有念头卡，点一下可以整理成按主题分组的笔记。

你的回答和念头也会记进当天的流水，每晚整理档案时能用上。

### 换模型

“设置 → 搭话用的模型”可以一键切到 DeepSeek、GPT（OpenAI）或千问（阿里云百炼），Key 要换成对应服务商的。

伙伴主动交流中，没回应会逐步放慢，间隔退避有上限；不会仅因沉默就永久停止。明确点“安静 30 分钟”则到期前不主动开口。

### 连续性（默认关，可在设置里打开）

打开后，它不再每次把整份档案塞给模型，而是：

- 从真实交流、你保存的念头、结构化事实和旧流水里，按当前话题做本地关键词/中文二元组召回；
- 默认最多 6 条相关记忆、合计 800 码点；最近交流最多 12 条、合计 2400 码点；整个动态上下文不超过 5000 码点；
- 每条记忆都带来源（“你说过 / 尚未确认 / 交流”）和日期；相关度不够就不补满；
- “记忆”页新增“它记住的事”：可以确认推测、更正事实、忘记；忘记会写删除清单，旧来源重放不会复活；
- 主动开口可以从“待分享话题队列”里取一条（来源只限真实交流、念头、日记摘要），仍走同一个开口节奏和安静时段；
- 关掉开关就回到旧的整份 profile 路径，已有设置、Key、人设、旧 Markdown 都不动。

底层记录改成事件日志：每条有稳定 id、发生时间和归属日；夜间整理使用固定批次（事件边界 + 档案版本），请求期间新增的交流留在待处理，不再被一起归档；提交有 journal，崩溃后可恢复，重复执行同一批不会重复归档。所有模型入口共用一本原子预算。

数据仍在应用私有目录 `filesDir/memory/`。升级前建议在系统里备份应用数据；旧 `today.md` 第一次启动会迁移成事件并保留备份，不删除旧文件。

## 代码结构

```
app/src/main/java/cn/companion/pet/
  core/      纯 Kotlin，全部有 JVM 单元测试
    scene/     场景判断、行为轨迹、卡壳探头
    rhythm/    开口节奏、被忽略升级
    probe/     人设、提示词拼装、回复解析、违禁词、原子预算
    companion/ 事件日志、结构化事实、相关召回、上下文组装、状态、话题队列
    memory/    Markdown 记忆、夜间批次、journal 提交与恢复、今日流水
    life/      生物钟、有分量的开口
    text/      屏幕文字清洗（WorkBuddy）
    bridge/    Gemini 桥接文本（WorkBuddy）
  net/       OpenAI 兼容客户端（不重定向、不重试、256 KiB 上限）
  data/      设置、统计、Keystore 存 API Key
  a11y/      无障碍感知、Gemini 自动发送实验
  overlay/   占位角色（Canvas 绘制）、漫画气泡、悬浮窗管理
  service/   常驻服务、大脑（PetBrain）、语音、震动、锁屏心跳、开机自启
  work/      每晚整理、看门狗
  ui/        设置页四个标签：开始、设置、记忆、统计
```

## 构建与测试

CI（`.github/workflows/companion-pet-android.yml`）每次推送都跑单元测试、lint、构建 debug APK 和设备测试 APK。0.5.4 本地实测：**365 个 JVM 测试通过、0 失败**（APK 和 lint 以 CI 为准）；设备测试 APK 只编译，未在真机执行。

本地需要 JDK 17、Android SDK 35：

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

## 已知限制

- 角色是占位形象，正式版换原创 Lottie 动画，状态接口不变。
- 从开机或后台被拉起时，系统不允许前台服务带麦克风类型，这时按住说话可能失败，会提示改用打字；打开一次 App 再启动桌宠即可恢复。
- Gemini Live 没有公开的直达入口，只能打开 Gemini 后提示你点 Live 和共享屏幕。
- 真机行为（常驻、保活、语音识别、Gemini 拉起、自动发送）需要在 iQOO 12 上验证，见 VALIDATION.md。
- 本轮没有可用真机或模拟器：`connectedDebugAndroidTest` 未运行，所有仪器测试只证明可编译。
- 角色仍是 Canvas 占位形象，未交付原创 Lottie；“减少动画”目前只影响新增界面，占位角色本身没有持续循环动画。
