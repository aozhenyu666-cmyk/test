# 伴生桌宠 V1.5

一只停在屏幕边上的小生物，会按节奏主动找你说一两句话：看书看卡住了它会针对那段内容挑刺，来回刷手机时它只问你脑子里在转什么。想深聊时一键把你送进 Gemini，上下文已经帮你拼好。

需求依据：[V1.5 需求文档](https://claude.ai/artifact/GBaCjrc1shZXy4v391C4zu)，开发计划见 [PLAN.md](PLAN.md)。

当前基础完善版本为 **0.3.1（versionCode 4）**：记忆更正同步档案、来源失效、当前问题召回与夜间过期结果保护。实现与自动化结果见 [本轮交接](handoff/codex-foundation-v3/STATE.md)；后续开发见 [DeepSeek 命令](handoff/codex-foundation-v3/DEEPSEEK_NEXT.md)。设备覆盖升级的条件与待测项见 [升级验证](handoff/codex-foundation-v3/UPGRADE_VALIDATION.md)，不能把 APK 构建成功当成手机已验证。

## 第一次用

装好之后走完下面五步，就能看到它停在屏幕边上。每一步“应该看到什么、没看到怎么办”另有逐项核对表：[FIRST_RUN_CHECKLIST.md](handoff/codex-foundation-v3/FIRST_RUN_CHECKLIST.md)。

### 1. 装上去

在 GitHub Actions 的“Companion Pet Android”运行记录里下载 `companion-pet-debug-<commit>`，解压得到 `app-debug.apk`，传到手机安装。包名是 `cn.companion.pet`，应用名“桌宠”。

覆盖升级前先读[升级验证](handoff/codex-foundation-v3/UPGRADE_VALIDATION.md)：**能覆盖安装的前提是两份 APK 签名一致**。签名不一致时装不上，此时应在原构建环境用原签名重新出包，**不要为了装测试包卸载旧应用或清数据**——那会把已有记忆一起丢掉。

### 2. 开权限（“开始”页）

打开“桌宠”，停在“开始”页，按分组从上往下开。每一行右边写着“已开启 / 未开启”，点未开启的那一行会跳到系统里对应的设置页。

| 分组 | 项目 | 不开启会怎样 |
|---|---|---|
| 必需 | **悬浮窗** | 角色根本出不来，“启动桌宠”是灰的 |
| 必需 | **无障碍服务**（系统里显示“桌宠 · 感知”） | 它不知道你在用什么 App，只能按普通场景搭话 |
| 推荐 | 麦克风和通知 | 按住说话用不了；少掉常驻通知和快速暂停 |
| 推荐 | 不限制电池 | 后台容易被系统杀掉 |
| vivo / iQOO | 允许自启动 / 后台高耗电 | 一键清理或息屏后容易失联 |
| vivo / iQOO | 后台弹出界面 | 点“去 Gemini”时可能拉不起来 |
| vivo / iQOO | 在最近任务里锁定 | 同上，锁住卡片后一键清理不会杀掉它 |

两个容易卡住的地方：

- **无障碍开关是灰的**：应用详情 → 右上角 ⋮ → 允许受限制的设置，再回来开。
- 无障碍行如果已经显示“已开启”，但描述后面多了一句“（已打开，但服务还没连上，可以关掉再打开一次）”，说明开关开着、服务没跑起来，按那句话操作。

非 vivo 机型，“vivo / iQOO 还需要”这一组会显示成“国产系统还需要”，内容一致。

### 3. 配模型（“设置”页）

“设置”页最上面是“搭话用的模型”。桌宠主动开口、想一想、整理记忆都用这里配的模型。

1. 点一下 **DeepSeek / GPT / 千问** 任一按钮，接口地址和模型名会自动填好（`https://api.deepseek.com` + `deepseek-chat`，或 OpenAI、阿里云百炼的对应值），填完仍可手动改。
2. 填 **API Key**。Key 存在系统 Keystore 里；已经存过时标签会变成“API Key（已保存，留空不改）”，留空直接保存不会清掉旧 Key。
3. **每日调用上限**默认 150，可填 1–2000。
4. 点“保存”。保存成功提示“已保存”，Key 写入失败提示“Key 保存失败”。旁边的“清除 Key”会把已存的 Key 删掉。

接口地址只接受 `https`，带 `?`、`#` 或账号密码的地址不合法（输入框会标红），保存时提示“接口地址要是 https 开头”。路径不以 `/chat/completions` 结尾时会自动补上。

**有 API Key 不等于模型已经连通。** 这一版没有“测试连接”按钮，保存只证明 Key 写进了设备，不证明地址可达、模型名正确、额度还有钱。第一次真实验证只能等它开口，或者点“设置”页最底下“调试 → 现在整理一次记忆”，看是否真的产出内容。

### 4. 启动

回“开始”页，点“启动桌宠”。成功的话角色出现在屏幕边上，状态标签变成“正在陪伴”。已经在跑时按钮会变成“重新唤出”，点它只是把角色叫出来。

启动失败会提示“启动失败，检查悬浮窗权限”。

页面顶部那行提示按优先级只显示一条，可以作为就绪检查：

| 顶部提示 | 含义 |
|---|---|
| 先开悬浮窗权限，它才能出现。 | 悬浮窗没开 |
| 还没填模型的 API Key：它会出现，但不会开口。 | Key 没配 |
| 今天的调用额度用完了。它会继续陪着你，明天恢复开口。 | 额度用完 |
| 没开无障碍：它不知道你在用什么 App，只能按普通场景搭话。 | 无障碍没开 |
| 一切就绪。 | 可以了 |

### 5. 暂停和停止不是一回事

| 操作 | 位置 | 效果 |
|---|---|---|
| **暂停** | “开始”页“暂停”，或通知栏“安静一会” | 角色留在屏幕上，只是不主动开口。“开始”页按钮变“继续”，通知标题变“桌宠在安静待着”、动作变“让它说话” |
| **停止** | “开始”页“停止”，或通知栏“停止” | 服务真的关掉。之后开机、应用更新都不会自动拉起，必须回“开始”页手动点“启动桌宠” |

除了这两者，**安静时段**（“设置 → 开口节奏”，默认 0 点到 7 点）也会让它不开口，但那是节奏设置，状态标签仍然显示“正在陪伴”。

### 6. 记忆：确认、更正、遗忘（“记忆”页）

“记忆”页分两块，来源都写在界面上，能核对。

**它对你的了解**（整份档案）

- 行首 `[他说过]` 是你亲口说的，`[我推测]` 是它猜的。
- 推测的那行有“对”（确认为事实）和“删”；亲口说的那行只有“删”。
- “整段编辑”可以一次性改全文，改完点“保存”。

**它记住的事**（结构化事实）

- 每条带来源标签“你说过”或“尚未确认”，以及日期。
- 推测的可以点“对”确认；写错了点“更正”，改完点“保存”；不想留就点“忘记”。

三点要注意：

1. **这里的“删”“忘记”都没有二次确认**，点下去立即生效。想撤回只能重新告诉它。
2. 写入失败会提示“没有保存成功，请重试。”，看到这句说明这次改动没落盘。
3. **“清空今天的记录”不是“忘记一件事”**。

| | 清空今天的记录 | 忘记一件事 |
|---|---|---|
| 位置 | “今天的交流”下方 | “它记住的事”每条右边的“忘记” |
| 作用范围 | 只清掉今天的交流列表 | 针对那一条事实写删除清单 |
| 档案 / 日记 / 信 | **保留** | 保留 |
| 旧内容会不会回来 | 今天这一天的列表清掉后不再显示 | 删除后旧来源重放不会让它复活 |

清空前会弹“清空今天的记录？”，正文写明“会清除今天的交流列表；已生成的档案、日记和信会保留。要忘记某件事，请在‘它记住的事’里操作。”——界面和你看到的一致，以它为准。

**不要把这理解成“所有历史字节已经抹除”。** 遗忘的效果是让这段内容退出使用路径（召回、动态上下文、最近交流、话题、夜间输入都不再用它）；原始事件和事实历史仍留在应用私有存储里，供本机追溯。没有来源关系的自由文本，也只能按文本保守过滤。

### 7. 看今天的调用余量

“开始”页状态框里有一行 **“今天已调用 X / Y 次”**，`Y` 就是“设置 → 每日调用上限”，默认 150。上限大于 0 才显示这一行。

口径要说清楚：**每次真实的模型请求发出前，先占掉一格预算，请求失败那一格也已经用掉。** 所以这个数字是“尝试次数”，不是“成功开口次数”，也不是 token 用量，更不是费用——统计页自己也写明“没有可靠 token/定价信息，所以不算精确费用”。

“统计”页的“调用”列和这个数字同口径，可以互相对照；同一天内两边应当一致。额度按本地日期每天重置。

用完额度后，顶部提示变成“今天的调用额度用完了”。它不会消失——动画、震动这些本地动作还在，只是不再请求模型。

### 它不开口时，先查这几项

“不说话”有很多种原因，**不要一律当成权限没开**。按这个顺序排：

1. **已暂停 / 已停止**：看状态标签是“已暂停”还是“已停止”。
2. **安静时段**：默认 0 点到 7 点不开口。不想等到早上，把“设置 → 开口节奏”的安静时段改掉。
3. **排除 App**：前台是“设置 → App 名单 → 排除 App”里的应用时不开口、也不读屏。信息流 App 只聊状态、不聊内容。
4. **额度用完**：见上一节。
5. **Key 没填，或模型不可用**：Key 没填时它只做个动作、不出声；地址错、Key 失效、模型名下架这类请求失败也会静默，按正常节奏等下一轮，界面上不会有报错。
6. **间隔没到**：“开口节奏”最短间隔默认 6 分钟、最长 12 分钟，刚点完“停止”再“启动”不会立刻说话。

排查时先看“统计”页：如果“开口”和“调用”都是 0，说明它根本没在尝试；如果“调用”在涨而“开口”不涨，那问题在模型侧，不在权限。

## 怎么用

| 操作 | 效果 |
|---|---|
| 它主动开口 | 气泡里一两句话。可以按住说话、打字、去 Gemini；学习场景多一个“一起看”（Gemini Live） |
| 点一下角色 | 主动叫它，弹出入口；有信时先给你看信 |
| 按住角色说话 | 学习场景：直接带着屏幕内容进 Gemini；其他场景：它接你一句 |
| 拖动角色 | 换位置，松手吸附到最近的边 |
| 通知栏 | “安静一会”暂停主动开口；“停止”关掉桌宠（之后不会自动拉起） |

### AI 会话（Gemini / ChatGPT / 千问）

在“设置 → 深聊用哪个 AI”里选一个。包名会自动在手机上找（千问由通义改名而来，包名不固定），找不到可以手动填。

和它聊的时候，桌宠帮你守住这段对话，头上会出现蓝色的 **G**。

- **怎么开始**：在气泡里点“去 …”或“一起看”；或者自己打开 Gemini / ChatGPT / 千问 停留 20 秒。
- **切出去时**：文字深聊中切到别的 App，气泡倒计时 10 秒，到点把 Gemini 拉回来（回到原来的对话，不会新开）。倒计时里可以点“现在回去”、“给我 5 分钟”或“结束会话”。
- **调整**：
  - 下拉通知栏、弹出输入法、点开桌宠自己的设置页，都不算离开。
  - “会话中允许的 App”（加上学习 App）宽限 90 秒，适合去笔记里记一笔、去阅读器复制一段。从那里再切到别的 App，宽限缩回 10 秒。
  - 3 分钟内被拉回 3 次，就不再拉，改问你要不要结束。
  - Live 共看本来就要切出去，只记录、不拉回。
  - 熄屏 15 分钟、或者离开 30 分钟，会话自动结束。
- **怎么结束**：点桌宠 →“结束会话”。每次会话的时长、离开和拉回次数会记进当天的记录，统计页也有。

### 想一想（看东西时帮你思考）

点一下桌宠，气泡里有“想一想”和“记个念头”。

1. **划过留痕 → 划过了啥**：你快速往下滑的时候，它把经过屏幕的段落记在内存里（只留 10 分钟，熄屏清空，不存文件；信息流 App、排除 App 和 AI App 里不记）。点“划过了啥”，它列出 2–3 条要点，指出一处最值得慢下来重看的地方，再问你一个检验有没有看懂的问题。
2. **提问模式**：对刚才划过的内容（没有就用当前屏幕）选一种问法：
   - 追问我：苏格拉底式，由浅入深追问前提、证据、推论
   - 讲给我听：费曼法，先让你用大白话讲，再追问外行最可能问的
   - 挑刺：指出最站不住的论点，让你自己判断
   - 联系旧知：结合它对你的了解，问这和你以前学过、经历过的有什么关系
   你点“说一句”或“打字”回答，它回应一次：讲清楚了什么、哪里还含糊。随时可以点“带去 Gemini/ChatGPT/千问”，要点、问题和你的回答会一起带过去，请对方接着追问。
3. **记个念头**：看到一半冒出想法，点“记个念头”说一句，就和当时在看的那句原文一起存下来。“记忆”页能看到所有念头卡，点一下可以整理成按主题分组的笔记。

你的回答和念头也会记进当天的流水，每晚整理档案时能用上。

### 换模型

“设置 → 搭话用的模型”可以一键切到 DeepSeek、GPT（OpenAI）或千问（阿里云百炼），Key 要换成对应服务商的。

不理它：60 秒后它做个动作 → 再 60 秒轻震一下、往中间挪一点 → 再 60 秒回到边上，下次早一点、换个说法再来。

### 连续性（默认关，可在设置里打开）

打开后，它不再每次把整份档案塞给模型，而是：

- 从真实交流、你保存的念头、结构化事实和旧流水里，按当前话题做本地关键词/中文二元组召回；
- 默认最多 6 条相关记忆、合计 800 码点；最近交流最多 12 条、合计 2400 码点；整个动态上下文不超过 5000 码点；
- 每条记忆都带来源（“你说过 / 尚未确认 / 交流”）和日期；相关度不够就不补满；
- “记忆”页新增“它记住的事”：可以确认推测、更正事实、忘记；忘记会写删除清单，旧来源重放不会复活；
- 主动开口可以从“待分享话题队列”里取一条（来源只限真实交流、念头、日记摘要），仍走同一个开口节奏和安静时段；
- 关掉开关就回到旧的整份 profile 路径，已有设置、Key、人设、旧 Markdown 都不动。

底层记录改成事件日志：每条有稳定 id、发生时间和归属日；夜间整理使用固定批次（事件边界 + 档案版本），请求期间新增的交流留在待处理，不再被一起归档；提交有 journal，崩溃后可恢复，重复执行同一批不会重复归档。所有模型入口共用一本原子预算。

数据仍在应用私有目录 `filesDir/memory/`。升级前建议在系统里备份应用数据；旧 `today.md` 第一次启动会迁移成事件并保留备份，不删除旧文件。

## 代码结构

```
app/src/main/java/cn/companion/pet/
  core/      纯 Kotlin，全部有 JVM 单元测试
    scene/     场景判断、行为轨迹、卡壳探头
    rhythm/    开口节奏、被忽略升级
    probe/     人设、提示词拼装、回复解析、违禁词、原子预算
    companion/ 事件日志、结构化事实、相关召回、上下文组装、状态、话题队列
    memory/    Markdown 记忆、夜间批次、journal 提交与恢复、今日流水
    life/      生物钟、有分量的开口
    text/      屏幕文字清洗（WorkBuddy）
    bridge/    Gemini 桥接文本（WorkBuddy）
  net/       OpenAI 兼容客户端（不重定向、不重试、256 KiB 上限）
  data/      设置、统计、Keystore 存 API Key
  a11y/      无障碍感知、Gemini 自动发送实验
  overlay/   占位角色（Canvas 绘制）、漫画气泡、悬浮窗管理
  service/   常驻服务、大脑（PetBrain）、语音、震动、锁屏心跳、开机自启
  work/      每晚整理、看门狗
  ui/        设置页四个标签：开始、设置、记忆、统计
```

## 已知限制

- 角色是占位形象，正式版换原创 Lottie 动画，状态接口不变。
- 从开机或后台被拉起时，系统不允许前台服务带麦克风类型，这时按住说话可能失败，会提示改用打字；打开一次 App 再启动桌宠即可恢复。
- Gemini Live 没有公开的直达入口，只能打开 Gemini 后提示你点 Live 和共享屏幕。
- 真机行为（常驻、保活、语音识别、Gemini 拉起、自动发送）需要在 iQOO 12 上验证，见 VALIDATION.md。
- 本轮没有可用真机或模拟器：`connectedDebugAndroidTest` 未运行，所有仪器测试只证明可编译。
- 角色仍是 Canvas 占位形象，未交付原创 Lottie；“减少动画”目前只影响新增界面，占位角色本身没有持续循环动画。
