# 同桌 · 设计系统（DESIGN.md）

本文件是可持续维护的设计约定。修改 UI 前先读这里；新组件必须引用 token，不写死颜色。

## 1. 产品定位与视觉原则

同桌是手机桌面上长期陪伴的伙伴，不是企业后台、不是自律仪表盘、也不是通用 AI 聊天页。

四条原则：
1. **安静但不冷漠**：留白和细线承担结构，颜色只用于表达状态与主操作。
2. **一屏一个焦点**：每页只有一个“现在最该做的事”，其余降级。
3. **角色是品牌资产**：悬浮角色负责个性，界面负责清晰，两者用同一套颜色。
4. **不装饰**：不用渐变、玻璃拟态、发光描边、卡片套卡片来制造“高级感”。

## 2. 命名规范（重要）

| 名称 | 指什么 | 用在哪 |
|---|---|---|
| **同桌** | 应用名 / 产品名 | 应用标题、Launcher 名称、文档 |
| **桌宠** | 桌面上的悬浮角色本体 | “点桌宠 → 看一眼”“启动桌宠”等操作指引 |

不要把两者混用。应用标题写“同桌”，指向角色时写“桌宠”。

## 3. 颜色 token

定义在 `ui/theme/Tokens.kt` 的 `CompanionColors`。语义用途：

| token | 用途 | 禁止用途 |
|---|---|---|
| `paper` | 页面底色 | — |
| `panel` | 卡片 / 面板底 | 不要用于整页背景 |
| `ink` | 主文字、深色 Hero 底色 | — |
| `ink2` | 次级说明文字 | 不要用于主操作文字 |
| `rule` | 1px 分隔线、卡片描边 | 不要用作强调 |
| `chip` | 分组底、未选中态 | — |
| `accent` | **单一**主操作、当前选中、品牌强调 | 不要同时用于徽标和标签 |
| `signal` | 柔和高亮（米色），次级标记 | 不要当主按钮底色 |
| `success/warning/info/danger` | 语义状态 | 不要混用别的色代替 |

约束：
- 强调色全页只允许出现一次主操作。
- 状态不能只靠颜色区分，必须配文字。
- 悬浮层（`PetView` / `BubbleView`）必须与 token 同源，改色时两边一起改。

## 4. 排版

- 标题：Serif（`headlineMedium` 27sp / `titleLarge` 21sp）。
- 正文：Sans，16sp / 25sp 行高。
- 说明：13sp / 20sp 行高。
- 标签：12sp，字距 0.6sp。
- 层级靠字号 + 字重，不靠降低透明度制造层级。

## 5. 间距与圆角

| token | 值 |
|---|---|
| `page` | 20dp 页面左右边距 |
| `group` | 22dp 分组间 |
| `card` | 16dp 卡片内边距 |
| `minTouch` | 48dp 最小触摸目标 |
| `small` | 12dp 卡片圆角 |
| `button` | 16dp 按钮圆角 |
| `hero` | 24dp 主视觉圆角 |
| `pill` | 50% 胶囊（标签） |

## 6. 图标规范

- Launcher：`mipmap-anydpi/ic_launcher.xml`（adaptive）+ `ic_launcher_round.xml`。
  - 前景 `drawable/ic_launcher_foreground.xml`（108dp，安全区 72dp）。
  - 背景 `drawable/ic_launcher_background.xml`（暖纸 #F7F3EA）。
  - monochrome `drawable/ic_launcher_monochrome.xml`（主题图标）。
- 通知小图标：`drawable/ic_notification.xml`，必须单色剪影，24dp。
- 不要在 Launcher 图标里放文字；轮廓要在 48dp 下可辨认。
- 文件放 `mipmap-anydpi`（minSdk 30，不需要 `-v26`）。

## 7. 角色规范

- 身体暖橘 `rgb(255,214,165)`，描边墨 `rgb(70,48,38)`（与 `ink` 同族）。
- 强调色统一为珊瑚 `rgb(201,81,46)`（与 `accent` 一致）。**不再使用蓝色**。
- 气泡：底 `rgb(255,253,248)`，1.5dp 墨色描边，圆角 14dp。
- 状态：待机 / 思考 / 说话 / 好奇 / 困，靠眼睛与嘴角变化，不靠换色。
- 动效 120–240ms，不抢注意力；低性能设备只用位移与透明度。

## 8. 组件规范

| 组件 | 用途 | 注意 |
|---|---|---|
| `PageHeader` | 页面标题 + 一句说明 | 说明不超过两行 |
| `Panel` | 内容分组 | 1dp 描边，不用阴影 |
| `HeroPanel` | 唯一主视觉 | 墨底，深色页面上文字用 `paper` |
| `SettingRow` | 设置项 | 必须有可见的点击反馈 |
| `ToggleRow` | 开关 | 带 `contentDescription` |
| `CutAction` | 主/次按钮 | `highlighted` = 珊瑚主操作 |
| `QuietAction` | 次要操作 | 描边按钮 |
| `SourceTag` | 来源标记 | 胶囊，`highlighted` 用珊瑚 |
| `EmptyState` | 空状态 | 必须有下一步动作或明确说明 |

## 9. 深色模式

- `DarkCompanionColors` 已定义；`values-night/themes.xml` 设 `#16140F` 底色，避免启动闪白。
- 深色下强调色提升为 `#E8794F`，保证在深底上的对比。
- 深色模式下 HeroPanel（墨底）会与页面底接近，需要用 `rule` 描边区分。

## 10. 无障碍

- 最小触摸目标 48dp。
- 所有开关带 `contentDescription`。
- 文字对比度：正文对 `paper` ≥ 7:1，`ink2` ≥ 4.5:1。
- 关键按钮带 `testTag`，供 uiautomator 按资源 ID 定位，不依赖坐标。
- 字体放大 1.3× 时不得出现截断；长说明允许换行，不设固定高度。

## 11. 反模式

- ❌ 照搬旧黑黄原型（黑底 + 高饱和黄块）。
- ❌ 黑底 + 紫蓝渐变 + 霓虹光效。
- ❌ 每个区块都套圆角卡片，卡片里再套卡片。
- ❌ 每个标题前加彩色底块图标。
- ❌ 用大面积渐变 / 玻璃拟态 / 厚阴影制造层次。
- ❌ 为“高级”把正文降到 12sp 以下或降低对比度。
- ❌ 为“极简”删掉真实功能入口或必要说明。
- ❌ 用表情符号或随机插画代替正式图标。
- ❌ 应用标题写“桌宠”（应为“同桌”）。

## 12. 页面规则

- **今天**：只回答“它现在什么状态、我下一步能做什么”。权限缺口只显示一张小卡。
- **我的**：记忆 / 目标 / 技能 / 人设 / 统计，用胶囊分段而非嵌套卡片。
- **设置**：按 权限 / 模型与看图 / 陪伴 / 设备 / 诊断 五组，组内允许长滚动，但必须有用 `GroupTitle` 分隔。
- **统计**：只展示真实存在的数字；空数据用 `EmptyState` 解释而不是空白。
