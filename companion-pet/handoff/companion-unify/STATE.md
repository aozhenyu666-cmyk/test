- 分支：`claude/companion-unify-v1`（基于 DeepSeek `feature/companion-dual-mode-training` @ c5438a2）
- 版本：0.7.1-preview / versionCode 31
- 预览链接（CI 绿后）：`tongzhuo-preview-claude-companion-unify-v1`；不写 `tongzhuo-latest` / `tongzhuo-stable`，不合并主线
- 真机：**全部 NOT_RUN**。JVM 测试和 CI 构建不等于真机通过。

## 统一后的规则（一句话版）

1. **同一时间只有一个受约束回合**：陪练、严格陪伴互斥；进行中点桌宠给“当前回合菜单”，不会收起/作废。
2. **只有一个“拉回”拥有者、一个全屏拦截层**：守护在跑时守护管；守护不在时，陪练切到别的应用才由陪练用同一个拦截层拦（按钮换成“回去接着练 / 歇 5 分钟 / 结束训练”）。开守护会先撤下陪练的拦截层。
3. **受约束回合期间桌宠不插嘴**：主动陪伴（C3）忙碌状态新增“陪练 / 严格陪伴 / 休息”；陪练期间也不自动开深聊会话。
4. **锁屏不作废**：严格回合和陪练跨锁屏保留，锁屏停计时，亮屏接着问。
5. **模型用不了不卡死、不冒充**：没 Key / 次数用完 / 超时 / 解析失败 / 请求被取消，一律退回“等你回答”，不算过也不算错。

## 修掉的问题

### 严格陪伴（DeepSeek continuity）
| # | 问题 | 处理 |
|---|---|---|
| S1 P0 | 回答进不来：开始气泡只有“我不会/结束”，没打开 awaitingAnswer；按住说话也走闲聊 | 所有严格气泡带“说一句/打字/我不会/结束”，按住说话也路由到回答 |
| S2 | 验收标准和“我不会”写死成“作者转折” | `StrictCriteria.forQuestion` 按当前问题生成；支架按本步缺口说 |
| S3 | 一步通过就结束，且结束后回合对象一直挂着（3 分钟清理永不触发） | 有下一问且没到期 → 进入下一步（持续闭环）；最后一步/到期 → 结算并收起 |
| S4 | “提示后通过”按整回合 attempts>1 计，第二步一次过也算提示后 | 改为按步：本步多次尝试或用过“我不会”才算提示后 |
| S5 | 没 Key/超时停在 EVALUATING | `evaluationUnavailable` 退回等待；协程被取消也在 finally 里复位 |
| S6 | 点桌宠、锁屏都会作废回合 | 点桌宠重显当前问题；锁屏只收界面 |
| S7 | 恢复后问题在状态机里但 answerThink 读 result，恢复后答不了 | 严格回合一律读状态机里的问题 |
| S8 | 恢复时 EVALUATING 卡死、空窗被夸大、坏文件直接丢 | 恢复回等待并作废在途结果；30 秒心跳落盘；坏文件改名留底 |
| S9 | 恢复后素材为空却照常要求“原文依据” | 屏幕原文按隐私约束不落盘；恢复后标准改为“说出依据或理由”，提示里如实说明 |

### 双形态训练（DeepSeek dual-mode）
| # | 问题 | 处理 |
|---|---|---|
| T1 | 计时器混用墙上时间和开机时长：开题用 now()、tick 用 elapsedRealtime，沉默计时永远不触发 | TrainingTimer 只用单调时钟；存盘/空窗只用墙上时间 |
| T2 | 恢复空窗用开机时长减墙上时间，永远是 0，还把单调时间写进存档 | 恢复用墙上时间；30 秒心跳落盘 |
| T3 | 先进 EVALUATING 再发现没 Key → 卡在核对中，“我不会”失灵 | 先检查模型可用；新增 `evaluationFailed`；取消/异常在 finally 复位 |
| T4 | 解析时用“当前会话”盖章，迟到结果校验形同虚设 | 用发请求那一刻的快照解析；核对中禁止重复提交 |
| T5 | 跨应用拦截 `onTrainingForeground` 从没接到前台回调；接上也会把“开始训练时所在的应用”当成离开 | 接到唯一的前台确认入口；记录起点应用，桌面不算离开；守护在跑时让位 |
| T6 | “回到训练”打开主界面，但训练在悬浮气泡里 | 回到起点应用（没有就回桌面），再重显这一步 |
| T7 | 休息许可 `maybeGrantRest` 从没调用 | 完成时按“练习换休息”策略发放；休息期间桌宠不打扰，到点叫一声 |
| T8 | 完成后又被 endTraining 记成“中止” | 完成只记一次“完成” |
| T9 | “继续”按钮对恢复态无效（resume 只认 INTERRUPTED） | RECOVERY 也能继续 |
| T10 | 支架选项写死 20 人样本题 | 题目自带 `scaffolds`，没有就用通用选项 |
| T11 | 违规/恢复气泡没有回答入口；采纳建议后不落盘、不重置计时 | 气泡统一带回答入口；每次状态变化落盘并重置计时 |
| T12 | 训练中点桌宠只是收起气泡、按住说话走闲聊、主动陪伴照常插嘴 | 训练菜单；语音路由到训练；忙碌状态“陪练” |

## 真机清单（全部 NOT_RUN）
1. 想一想 → 严格陪我想：气泡出现“说一句/打字/我不会/结束”，打字回答能进入核对。
2. 严格回合按住桌宠说话 → 进入核对，不开闲聊。
3. 严格回合一步通过且有下一问 → 显示“下一步”，第 N 步递增；最后一步/到期 → 结算并收起。
4. 没填 Key 时回答 → 提示没法核对，仍可继续回答，不卡“核对中”。
5. 严格回合中锁屏再解锁 → 回合还在，提示“回来了，接着刚才的”。
6. 严格回合中杀进程重启 → 提示断开约 N 分钟（误差 ≤30 秒），问题还在，能答。
7. 开始陪练 → 25 秒（长题更久）不答出现缩小选项；再不答出现提示；再不答进入“先歇一会儿”，点“继续”能接着。
8. 陪练中切到起点应用以外的应用 → 全屏拦截层，按钮为“回去接着练 / 歇 5 分钟 / 结束训练”；回桌面不拦。
9. 拦截层“回去接着练” → 回到起点应用并重显这一步；“歇 5 分钟” → 5 分钟内不拦，到点叫回；“结束训练” → 训练结束、拦截层消失。
10. 没有无障碍/悬浮窗权限时切走 → 退到气泡并写明拦截层没显示的原因。
11. 守护进行中开陪练再切走 → 只出现守护的拦截层，不出现第二层。
12. 陪练中点桌宠 → 训练菜单；主动陪伴不插嘴；不自动开深聊。
13. 设置为“练习换休息”完成一题 → 显示休息分钟数；休息期间桌宠不打扰，到点提示“再练一题？”。
14. 陪练中杀进程重启 → 回到同一题同一步，空窗分钟数合理。
15. 完成一题后事件流水只有一条“训练完成”，没有“中止”。
