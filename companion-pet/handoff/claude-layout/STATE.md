# 0.5.8：整理界面布局

日期：2026-10-25。分支：`ccr-2899d69f-xlzjh6`。版本 **0.5.8 / versionCode 26**。在 0.5.7（DeepSeek 新视觉 + 我的功能）基础上调整信息结构，样式沿用 DeepSeek 的主题。

## 新结构

- 主导航只有两个：**今天 / 我的**。
- **设置**放到右上角“⚙ 设置”，打开是单独一页，返回键或“‹ 返回”回来。
  - 分区：权限 · 模型与看图 · 陪伴 · 设备 · 诊断。
  - 权限（原来铺在今天页的悬浮窗/无障碍/麦克风/电池/国产系统设置）搬到这里。
  - 诊断：复制崩溃报告（原在今天页）、决策轨迹、脱敏诊断、立即整理记忆。
- **今天**：状态卡 + 启动/暂停/停止、还差的设置（一张小卡，点哪项就打开设置对应分区）、四个快捷入口（看一眼 / 记念头 / 技能 / 去 AI）、最近交流。
- **我的**：记忆 · 目标（自主开关 + 目标 + 待确认）· 技能 · 人设 · 统计。

## 自动化标识

`tab_0`/`tab_1`、`open_settings`、`settings_back`、`settings_group_0..4`、`mine_group_0..4` 都能在 uiautomator dump 里按 resource-id 找到。冒烟脚本的 B1 改为先点“我的”（默认就是记忆）。
