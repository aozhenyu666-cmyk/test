## 已完成

1. **编辑记忆的统一入口**：新增 `core/memory/MemoryEdits.kt`，记忆页的确认、更正、遗忘和整段编辑都通过它更新事实库及 profile。共享夜间事务锁；用户显式编辑标为 `USER_EDIT`。只改来源标签不再把同一事实加入删除清单。
2. **更正不会制造另一条事实**：档案同步按现有存活文本复用原事实键；夜间结果保留显式编辑，不能用旧档案替换用户更正。过期的事实行不能再分叉出新版本。
3. **来源失效贯穿消费链路**：新增 `EventVisibility.kt`。CORRECTION/FORGET 携带旧来源 ID，并使派生事件逐层失效；召回、动态检索线索、最近交流、话题及夜间输入共同使用。生产话题队列核对来源仍存在且可见；念头生成的交流行补充 sourceIds。
4. **当前问题参与召回**：用户回复时重新组装上下文，以这次问题检索记忆，避免只沿着上次主动话题找。请求期间人设、档案、事实或删除清单变化时，不展示基于旧记忆生成的回答。
5. **夜间过期结果拒绝提交**：批次身份包含档案、人设、删除清单及事实版本。提交时逐项核对；恢复先检查全部目标文件，再开始写入，避免日记冲突时先污染 profile。
6. **遗忘文本继续过滤旧日记与新输出**：旧日记输入、写出的日记/信和回退路径增加过滤；Worker 从实际落盘日记生成话题，而非未经处理的模型原文。
7. **日志尾部恢复**：正常追加只检查文件尾字节，不再每次读整个月文件。完整 JSON 仅缺换行时补换行保留；真正损坏的尾行才隔离。按日读取只打开对应月份。
8. **基础界面**：开始页异步刷新最近交流、Key 是否已配置及当日调用数，额度用完有明确提示；设置页和事实操作按钮支持换行；记忆写入失败会给出反馈。清空当天交流的文案明确区分“清空列表”与“忘记事实”。
9. **升级准备**：旧格式数据回归、APK 对检查及干净模拟器升级脚本 `tools/verify_upgrade.py`。脚本拒绝物理设备和已有安装，不清除已有应用数据。

## 结果边界

- 没有声称真机或 iQOO 通过。FlowRow、开始页刷新、键盘和气泡等表现仍需要设备截图/录屏。
- APK 签名一致仅指本次同环境构建的一对样本，不能据此认定用户手机上由另一台机器构建的 debug APK 可以覆盖升级。
- 遗忘使内容退出使用路径；原始事件及事实历史保留在应用私有存储供本机追溯。这不是“所有历史字节物理抹除”。无来源关系的自由文本仍只能保守地按文本过滤。
- “不喜欢猫”等明确更正可以被召回；并不宣称已实现通用语义事实键或同义句推理。
- 这轮没有接入 B站账号、QQ、网页朗读桥，也没有安装 DSH 插件；研究结论及后续任务另列。
