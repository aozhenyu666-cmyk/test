# 给 WorkBuddy 的简单任务

只做这一份小任务。复杂的记忆、夜间整理、来源失效和工具执行不分配给你。

## 起点

从 `pet-v15/codex-foundation-v3` 创建独立分支 `pet-v15/workbuddy-ui-copy-v3`。保留既有工作区，优先用新 worktree。先读同目录 `STATE.md` 和 `DEEPSEEK_NEXT.md`，避免与 DeepSeek 修改相同文件。

## 范围

1. 整理 `companion-pet/README.md` 的首次使用说明，覆盖安装、权限、配置模型、启动、暂停/停止、记忆确认/更正/遗忘、查看调用余量。
2. 增加一份简短的 `companion-pet/handoff/codex-foundation-v3/FIRST_RUN_CHECKLIST.md`：每一步写“用户做什么 / 应该看到什么 / 看不到时怎么办”。
3. 根据现有实际文案写设备截图清单：开始、设置、记忆、统计四页，360dp/430dp、浅/深色、字体 1.0/1.3，重点核对换行按钮、输入框和调用余量。
4. 明确“清空今天的交流”和“忘记一件事”不同；清空列表不会自动删除档案、日记、信。不要承诺全部历史字节已经抹除。
5. 说明有 API Key 不等于模型已经连通；静默可能来自安静时段、暂停、排除 App、预算用完或模型不可用，不能把所有情况写成权限没开。

## 限制与交付

- 本任务只改 Markdown 文档，**不改 Kotlin、Manifest、Gradle、测试或模型提示词**。
- 不从文档猜出“已完成”截图；没有实际打开设备就写“截图待补”。不重装 App、不清数据、不接触 API Key、Cookie、私人聊天。
- 保留 Endfield 风格现有术语和界面名称，不另设计一套尚未实现的功能。
- 校对文档里的路径和相对链接。只提交两份文档，并在交付中列出改了哪一段、依据哪个现有界面。

这份任务无需调用模型接口、安装插件、运行真机升级，也不需要新增测试。
