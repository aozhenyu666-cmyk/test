# C1：能力面板

版本：0.3.5 / versionCode 8。基线：b1e47e9。

入口：设置 → 打开能力面板。保留四页导航和现有 CompanionTheme。
五项能力均经 PetApp.actions 在后台执行：读取记忆、查看素材、保存念头、打开 AI 应用、朗读文字。

- 念头先预览实际文字再确认；应用展示目标；朗读遵守开关与引擎状态，成功仅表示接受请求。
- ActionSession 冻结参数、拒绝忙碌时重复提交；新的显式执行使用新 ID。
- 查看上次操作只查原 ID，不再次执行。未确认结果先要求核对，不用新 ID 自动重试。
- 面板拥有自己的执行作用域；取消/离开仅取消自身 ID，并停止自身朗读。旋转由 ViewModel 保留执行状态；进程重建只恢复 ID 和类型用于核对。
- 素材结果使用中文证据等级，默认界面不展示内部来源 ID 和枚举。

验证：新增 4 个 JVM 行为测试（冻结/双击、取消排队任务与新参数、作用域关闭与晚到结果、恢复只查及不可用）；新增 2 个 Compose instrumentation 测试（确认与忙碌、状态重建不自动执行）。后者仅编译，未设备执行，不能作为真机证据。

C1 的写入去重仍限当前进程；C2 补持久化记录。没有开启自动循环或无人值守写入。
