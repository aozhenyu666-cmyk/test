# 设备待测清单

本轮 adb devices 为空；以下项目全部未执行，没有 iQOO 或其它真机通过结论。

## 安装与升级

1. 用户现有安装必须由原签名环境生成同签名更新包；本云环境 debug 签名不保证与原 Windows APK 一致。遇到签名不符，回原构建环境生成更新，保留应用数据。
2. 用原环境构建的 0.3.6 / versionCode 9 覆盖安装，核对旧设置、旧 Markdown 念头和合成测试记忆仍在。不要卸载或清数据来得到通过结果。
3. 本轮 0.3.5 → 0.3.6 的 APK 离线检查只核对包名、递增版本和同一构建环境签名；不证明手机已覆盖升级。
4. tools/verify_upgrade.py 的 --serial 只接受未安装本应用的干净模拟器，并写入该次运行创建的合成夹具；它拒绝物理设备和已有应用数据，勿改掉保护条件。

## 能力面板

1. 设置 → 打开能力面板；小屏、横竖屏、系统字号较大时仍可滚动到操作/结果；默认界面没有执行 ID 和内部枚举。
2. 用合成念头：预览后返回不保存；确认后只出现一条；快速双击不会写两次；执行中旋转不会重新提交。
3. 保存成功后退出并重启应用，从最近操作核对；仍只有一条。记忆页删除后重启/核对不恢复正文。
4. 先录入合成事实和合成素材，查到后纠正/遗忘/删除，再执行读取；旧内容不应回来，猜测仍有“我推测”标记。
5. 未安装目标 AI 应用时显示暂不可用；已安装时显示实际选定目标，接受请求不代表已打开到某个特定界面。
6. 关闭朗读开关：不可用且不提交语音；开启后检查中文引擎缺失、初始化失败、接受播报、取消和锁屏。成功只表示引擎接受，不表示已听到/播完。
7. 播报中离开面板或按取消，只停止面板自己的播报；不会停止另一作用域的无关任务。锁屏按既有全局策略取消全部在途工具。
8. 最近记录需要核对时，只查已有回执；不自动打开应用或重新朗读。核对期间离开面板不得取消原操作所属的其它作用域。
