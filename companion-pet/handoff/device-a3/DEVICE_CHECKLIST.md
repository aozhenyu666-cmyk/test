# A3 设备待测清单

全部当前 NOT_RUN。

1. 安装/启动 Shizuku：未安装、未运行、未授权、已授权、Binder 断线、重启后各状态；应用内刷新/请求权限显示准确。
2. 设置 → 允许操作的应用：空名单时所有设备动作拒绝；加入一个测试 App 后只允许该 App。
3. 打开测试 App → 能力面板“查找控件” → 选择节点 → 点击/滚动/输入；每次后重新观察确认页面变化，记录 observation/action ID。
4. 节点过期/切换 App/坐标变化：旧节点 ID 应 FAILED，不误点；不凭模型编造坐标。
5. 锁屏、无障碍断开、权限撤销、用户停止：不产生新动作；已发生的操作如实记录 UNVERIFIED，不重放。
6. 同一执行 ID 重复点击/输入：只发生一次；结果不明时先核对，不自动重试。
7. 密码框/银行/系统设置/商店默认拒绝；输入普通测试文字，不发送给第三方。
8. 没有 Shizuku 时原生 Intent/无障碍仍可用；检查日志不包含 Key/密码/屏幕原文。
