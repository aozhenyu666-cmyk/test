1. `TrainingController.bind` 在恢复时只绑定同题材料，不再重置 `currentSlot`；不匹配的题号/版本/槽位定义拒绝绑定。
2. `TrainingStore.restore` 保留恢复态、题目、作答及帮助等级，并递增 revision、清掉旧请求号。完成/退出保存终态，不清库假装没有任务。
3. 训练快照时间统一为日历时间，秒级提示只用 `elapsedRealtime`。默认首等及后续间隔均为 60 秒；两个提示后恢复等待。提示预算随任务保存，重启不能再领一轮提醒。
4. 所有作答（含无 Key/无额度/断网）、提示、核验、换槽、完成和退出均调用保存。模型失败退出 EVALUATING，保留原答案并能重试。
5. 模型请求绑定发出时的不可变快照；迟到回调先核对同一 controller、revision、requestId，再按原快照解析。重复提交/重复回调不重复推进。
6. 模型 JSON 缺字段/字段类型不正确时拒绝。PASS 需有存在于本题材料的引用，且无 uncertainty；已得到的帮助等级不能被模型降低。
7. 增加 `OfflineTraining`：只覆盖第一道固定示例 `sample-scope-01` v1 的两个槽位。接受列明的短答与固定选项；其他表达明确要求澄清。改变材料/版本后不套旧量表。不调用模型、不发休息券、不宣称通用中文评分能力。
8. 初始不展示答案选项；“我不会”后才展示，并记帮助等级。收起气泡只暂停认知计时，点击桌宠继续原题。训练占用期间普通主动话题与新 Agent 扫描让位。
9. 文字输入改为每次打开 `InputActivity` 重新绑定一次性 `InputBridge`，解决第二轮输入失效；输入取消恢复计时。语音结果也回到训练入口。
10. 训练进度本身不能产生设备授权；前台训练提示需已有未到期且未暂停的 Focus 契约。设备动作仍由原 `FocusController` 承担，本轮不宣称设备监管通过。
