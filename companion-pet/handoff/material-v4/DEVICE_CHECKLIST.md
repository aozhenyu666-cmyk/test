# 下一轮设备检查

当前没有真机或模拟器执行结果。这里是可复跑的清单，不是通过记录。每项填写：构建 commit、APK SHA-256、设备/系统、通过/失败/未执行及证据路径；不回传 Key、Cookie 或私人聊天。

## A：分享与材料

1. 从浏览器、B站分享链接/文字到桌宠；再用 CharSequence/带样式文字的合成 Intent 验证。应进入预览，不自动保存或请求模型。
2. 修改标题、摘录和证据等级，旋转屏幕后核对草稿；保存过程中按钮/输入状态正确。返回“记忆”后列表应刷新。
3. 离线保存/查看/删除；记录保存前后调用余量，应不因本地保存扣模型额度。
4. 同链接先存长摘录，再换短字幕，确认展示和上下文里的正文/类型都对应最新实际输入。不同无链接摘录保留不同卡片。
5. 只有长链接时，证据提示仍明确不能假装知道内容；不接受“只有链接却带正文”。
6. 连续性开关开/关分别验证下一轮对话使用材料；材料只在 USER 数据段，不进入 SYSTEM。使用本地 fake client/合成材料记录结构，避免导出真实私人对话。
7. 模型请求中删除材料；旧响应不应重新显示被删内容。夜间整理也覆盖该时序；重启后不从旧 journal 恢复被撤回来源。
8. 过期测试用注入 Clock 或独立 cache fixture，不改用户手机系统时间。过期来源及派生话题不可用，显式清理计数准确。
9. 360dp/430dp、字体 1.0/1.3、浅/深色检查按钮换行、预览输入、列表与键盘。

## B：原生适配器

B 当前没有用户工具入口。这组需要 C1 入口或可控 instrumentation harness，不能因 API 存在就填通过。

- 记忆工具不返回已忘记/过期来源，保留猜测标签；同 ID 再读能看到更新后的可见状态。
- 保存念头、同 ID 重试/并发只写一次；同 ID 改文字应拒绝；取消和返回不显示迟到成功。
- 打开已安装与未安装的 AI App；错误目标被拒绝，不能默默打开 Gemini。系统接受 Intent 与真的显示目标页分别记录。
- TTS 关闭、中文语音数据缺失、初始化失败、正常提交、等待中取消、锁屏、关闭开关；区分系统接受与真实播放。
- 验证未启动 PetService 时，锁屏仍能结束在途动作/待播报；关闭 TTS 不应误取消无关念头操作。
- 取消已开始的本地原子写入，不要求系统回滚文件；应给出明确状态，不能用“取消”宣称一定没有保存。

## 覆盖升级

先跑 `tools/verify_upgrade.py --check-apks` 核对两包包名、versionCode 和签名。脚本的 `--serial` 模式只接受没有既有安装的干净模拟器，自动写入合成资料并验证 install -r；没有设备时保持 not_executed。

用户手机上的旧包不一定与本容器构建包同签名。需要沿用原签名构建更新，不卸载旧包、不清数据、不导出凭证。基础操作详见 `../codex-foundation-v3/UPGRADE_VALIDATION.md`。
