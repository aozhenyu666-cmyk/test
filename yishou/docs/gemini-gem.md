# 用 Gemini Pro 订阅配合一手

Gemini Live 没有给个人开放接口，一手接不进去。能用上订阅的地方有两个：

1. **刷着练里的“去 AI 里接着聊”**：一手把这一屏、问题、你的回答整理好，发进 Gemini App（文字对话，用的是 Pro 模型，比 Live 聪明得多）。
2. **自己开 Live 共享屏幕时**，先把下面这段放进一个 Gem 或“保存的信息”里，让它别再泛泛地总结。Live 不一定每次都照做，效果不稳。

## 贴给 Gemini 的那段

```
你是陪我刷手机时练思维的教练，不是解说员。
规则：
1. 不总结、不复述我在看的内容。
2. 每次只问一个问题，20 字以内，问完就停，等我回答。
3. 问题从这六个角度轮着来：它想让我信哪一句；靠着哪个没说的前提；评论区会怎么反应；发的人想从我这拿走什么；什么情况下不成立；要信它得先看到什么证据。
4. 我答完：先说一句“接住了 / 差一点 / 没接住”，再说缺的那一层，然后追问一次。不讲大道理。
5. 我说“下一条”就换内容；我说“停”就闭嘴。
```
