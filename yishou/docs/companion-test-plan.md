# 视频陪练：真机验收方案

对着手机一步步做。每一步都写了「该看到什么」和「什么算没过」，过了再往下走——
前面一步没过，后面的结果就没意义，别硬测。

装的是 `yishou-companion-mainline-debug.apk`（主线）。覆盖安装即可，数据保留。
**第一次启动会跑数据库 14 → 15 迁移，这一步本身就是一个验收点**（第 0 步）。

---

## 0. 三分钟冒烟：装得上、开得起来

| 步 | 做 | 该看到 | 算没过 |
|---|---|---|---|
| 0.1 | 直接覆盖安装 | 安装成功，桌面图标还在，原有数据（题卡、一本账）都在 | 提示签名冲突 / 数据被清 |
| 0.2 | 打开 App | 正常进首页，没有闪退 | 一闪就退 |
| 0.3 | 设置 → 权限与运行状态 | 通知、无障碍等状态和之前一致 | 权限全没了 |

> 迁移失败的表现是**打开就崩**或者首页数据空。真出现就停下告诉我，这比后面的功能问题严重。

---

## 1. 能力闸门（探针）：先看能不能拿到东西

设置 → **陪练探针（调试）**。这一页不调模型、不花钱，只验证能不能拿到声音和画面。

### 1.1 内录声音

**前提**：目标视频 App 真的在出声、没静音、没戴耳机（先别用蓝牙，变量太多）。

1. 点「开始观察」→ 系统弹窗点「立即开始」/「同意」
2. 立刻切到视频 App，放一段有说话的讲解，**让它响着别停**
3. 20 秒后回探针页看「结论」栏

| 该看到 | 含义 |
|---|---|
| 内录声音 = **可用**，证据写着「读到 N 秒声音，峰值 X」 | 通了 |
| 内录声音 = **没有有效声音**，峰值接近 0 | 采集通了但没声音：先确认真的在响、没静音；再试另一个 App |
| 内录声音 = **不支持 / 失败** | 这台机器或这个 App 挡住了 |

「音量条」会跟着声音跳——**条不动但结论说可用**，说明两种状态没对齐，也是问题。

### 1.2 关键帧

同一次观察里一起验。看「关键帧」那行：

| 该看到 | 含义 |
|---|---|
| 可用：「观察 20 秒：看到 N 帧，留下 K 帧」 | 通了（K 可能很小，正常） |
| 可用：「看到 N 帧，画面一直没变，按重复丢掉」 | 也通了——你放的是静态画面 |
| 未验证：「一帧都没送过来」 | 没过 |

顺手验一次旋转：观察中把手机横过来，结论不该崩，回来再观察一次仍然可用。

### 1.3 暂停

1. 点「去开通知使用权」，在系统设置里给「一手」打开
2. 回探针页点「刷新会话」，看有没有列出你正在放的那个 App
3. 点「开」（自控播放器），再点「测暂停」→ 应显示**「已暂停（核实过状态）」**
4. 点「直接测你正在放的那个 App」→ 三种结果都可能：
   - 「已暂停（核实过状态）」= 最好的情况
   - 「发了指令但还在放」/「看不到播放状态」= 这个 App 停不了，后面走手动暂停那条路
   - 「没有可控制的播放会话」= 读不到它的会话

### 1.4 互斥

观察期间去开「刷着练」或「看屏」，应当被拒绝并写明「陪练探针正占着投屏」；反过来也一样。

**闸门结果决定后面怎么测**：

| 探针结果 | 后面怎么测 |
|---|---|
| 三项都可用 | 全流程都测 |
| 内录不可用 | 视频陪练会听不到内容 → 只测「开得起来、停得干净」，提问功能测不了，先告诉我 |
| 画面不可用 | 提问只依赖声音，仍可测；但「图表类材料」那一条跳过 |
| 暂停不可用 | 走手动暂停分支（第 2.4 条），这是设计好的降级路径，不算失败 |

## 2. 单轮闭环：一场只测「一问」

**这一步只关心一件事：它能不能完整地问出一问、听懂你的回答、说出差值。**

准备一条 **8–12 分钟的知识讲解**，要求：有"因为…所以…"、有举例、讲解中间有停顿。
纯音乐、纯娱乐、快节奏剪辑的都不合适（不是它该问的那种材料）。

1. 设置 → 视频陪练 → 目标填一句具体的（例：`抽样为什么能代表整体`）→ 时长 10 分 → 强度「陪」
2. 点「开始」→ 同意看屏 → 立刻切到视频 App 开播
3. **看通知栏**：应有「一手 · 视频陪练」，菜单里有「停」
4. 让它放，中场别切走。等第一问

| 观察点 | 该看到 | 算没过 |
|---|---|---|
| 胶囊 | `声音有 · 画面有 · 有效 N 分钟 · 在听`（声音/画面缺失会写明） | 一直「未验证」但材料确实在放 |
| 第一问时间 | **至少 2 分钟后**才可能问（策略规定，短测看不到是正常的） | 30 秒就冒出一问（说明计时错了） |
| 问题内容 | 提的内容能在刚才那几分钟里找到出处，是开放问法 | 问的是材料里没有的东西 / 是二选一 |
| 暂停 | 视频自己停住，且页面显示已暂停；停不了就提示「你先手动暂停一下」 | 宣称已暂停但视频还在放 |
| 朗读 | 念一遍问题，不超过两句 | 把内部判据念出来了 / 念了列表或标签 |
| 计时 | 念完才开始等（15 秒），念的时候不算你没接 | 还没念完就记「没接」 |

5. 问题出来、朗读结束以后，**直接对着手机说**一句不完整的（故意留个坑，比如只说现象不说条件）；说完停一两秒应当自己结束，页面显示「在把你说的转成文字…」，然后出现差值
   - 想手动结束就点「我说完了」；说错了点「不说了」再重说
   - 听不清时页面应当写「没听清…打字也行」，并出现输入框；打字作答会先关麦
   - 如果开麦失败，会直接写出原因；这条不算你的错，记下来告诉我
6. 看结果：应当指出**具体**差在哪一处，不是「回答得不错」

| 该看到 | 算没过 |
|---|---|
| 「差一点：你说了 X，但没说 Y」这种具体差值 | 只夸不指 / 泛泛而谈 / 说「答对了」但其实没答到 |

7. 再等它问第二问（或直接停）

---

## 3. 节奏与策略：打扰得值不值

同一场继续，或另开一场 20–25 分钟。这一轮看**打扰的密度和时机**。

| 观察点 | 期望 | 说明 |
|---|---|---|
| 一场提问次数 | ≤ 6 次 | 超过说明预算没起作用 |
| 两次提问间隔 | ≥ 2.5 分钟 | 连着问就是节奏错了 |
| 材料很平淡时的表现 | 不硬问，或者只做复述/预测 | **不硬说「这段有错」**——这条最重要 |
| 「跳过」之后 | 该问不算答错，账上记「记了一笔」 | 记成「没接住」就是错的 |
| 说「停」 | 一秒内停声 | 停不下来就是资源没释放 |

**主观记录（这一栏比数字重要）**：

- 哪一问让你真的多想了一步？把原话抄下来。
- 哪一问打断得不值当？当时材料在讲什么？
- 有没有出现「它说的破绽其实不是破绽」？

## 4. 失败与边界

每条 1–2 分钟，逐条过：

| 场景 | 做 | 该看到 |
|---|---|---|
| 目标 App 静音 | 把视频静音 30 秒 | 胶囊变「声音缺失」，之后恢复声音能自己恢复成「声音有」 |
| 中途切 App | 切到微信待 1 分钟再回来 | 服务不断，胶囊继续走；不该重新开局 |
| 跳播 | 往回拖 3 分钟 | 开新的一段，不在旧内容上继续问；旧问题作废 |
| 系统收回投屏 | 下拉通知点系统的「停止投屏」 | 立刻收摊，页面提示投屏被收回，通知消失 |
| 手动停 | 通知栏点「停」或页面点「停」 | 一秒内停声；投屏、录音释放；账本有一条本场记录 |
| 锁屏 5 分钟 | 直接锁屏 | 记录是否还在采集、耗电多少（这一条只记现象，不下结论） |
| 来电 | 让手机响一下 | 本轮暂停；挂掉后能继续（不行就记下来） |
| 内录被禁的 App | 换一个明确禁止被采集的 App（如某些音乐/网盘） | 报「没有有效声音」，**不报「不支持」** |
| 模型没配 | 设置里清空文字模型再开一场 | 安静地听，不乱出声；页面有明确提示 |

---

## 5. 落库与账本

1. 停掉一场 → 首页时之轮 / 一本账里应当出现「视频陪练 N」
2. 陪练页下方「最近记下的」能看到刚才的问、你的回答和差值（这就是同一条记录，不是另存一份）
3. 回答里区分得清：**材料原文**（记录里的 `sourceText`）、**它问的**、**你答的**、**它给的差值**
4. 跳过的那一问：记「记了一笔」，不是「没接住」
5. 同一场重复操作（比如连点两次「答」）不应产生两条记录

---

## 6. 稳定性与开销（30 分钟）

放满 30 分钟，中途不操作，记录：

| 指标 | 怎么取 |
|---|---|
| 耗电 | 开始/结束时的电量百分比 + 系统电池页里「一手」的耗电排行 |
| 发热 | 手感：温热 / 烫手 |
| 流量 | 系统流量统计里本场增量（内录转写全走网络） |
| 内存 | 开发者选项 → 正在运行的服务里看「一手」 |
| 中途是否卡顿 | 一边放视频一边操作手机 |

已知这版没有优化过能耗，**这项只用来建立基线**，不是判失败。

---

## 7. 效果评价（隔一天再填）

第二天回想这场：

- 你还说得出它问你的那个规则吗？（说得出 / 说不出 / 只有一个模糊印象）
- 有没有哪一个问题，让你在别的地方也用上了？

这两条才是「有没有用」的证据，比问了几次、生成几张卡重要。

## 需要回传给我的东西

按重要性排：

1. **探针三栏的截图**（内录 / 关键帧 / 暂停各一张，要带证据文字）
2. **手机型号 + 系统版本 + 视频 App 名字**（不知道型号就看设置→关于手机里的型号）
3. 第 2 步里**第一问的原话 + 当时材料在讲什么**
4. 第 3 步的主观三条（哪一问值得、哪一问不值、有没有误判破绽）
5. 任何一条「算没过」的现象，附上当时的页面截图

只有 10 分钟的话，就走 **0 → 1 → 2**，其余先不测。
