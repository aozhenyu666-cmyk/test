# 0.25.1 日常入口与联通验收

基础是已审过的 `claude/yishou-c1-judge`，基点 `832673d4e04fc6ff22e62e52631e1f512a9a4ffe`。工作分支 `codex/yishou-everyday-tools`，只开草稿 PR，不合并、不更新正式下载。

## 这次做了什么

- 内置 AI 助手：用现有文字接口，多轮流式聊天、停止、重试、语音输入、本机历史、新对话和删除。普通聊天不签发娱乐通行。
- 娱乐收费站：代码原本还在。补明显入口、真实连接状态、试题按钮；系统通知栏/输入法不再覆盖前台应用记录；每秒复查已识别的前台应用，避免只靠新窗口事件错过到期；异步查询结束后再核对前台，避免把用户从新应用拉走。正常仍按既有判卷和触发器流程换 15 分钟。
- 陪练小窗：用户手动允许悬浮窗后，陪练、看屏、刷着练、语音伙伴共用一个可拖动的小窗。点“一手 ●”展开，直接看问题、回复、看屏、打断和停止。服务结束撤掉入口；截图前临时藏起面板，不把自己截进题里。通知继续保留。
- 回复小窗：在原来的学习应用上方打字或按麦克风说话；独立透明任务，不先把整个一手主页翻到前台。语音伙伴运行时小窗打字，不再启动第二个录音器；打字或打断后，之前那次听写晚返回也不会再塞回对话。
- 分类标签页：默认行测、申论、海龟汤、文章、其他；能新建、改名、移动、搜正文。全部页导入自动分；选某一页导入就指定该页。批量题包逐题归类，旧内容补分类，手动移动不被自动归档覆盖。文件、图片、分享、题包继续复用现有导入，没换判题逻辑。
- 数据库 15→16：新增聊天、分类和归档表，旧题目、素材、线程原表不动。版本 0.25.1。

## 必须说清的边界

- 已加入 Android 10、14 模拟器上的真实无障碍服务与独立外部应用检查，覆盖拦截和到期重锁。厂商手机的后台弹窗策略仍需在对应设备确认。
- 无障碍开关“启用”不等于服务“已连接”。首页能区分两者；断连时需用户在系统设置关一次再打开，后台弹窗仍需厂商允许。
- 小窗需要用户手动授予悬浮窗权限；没有权限仍可进页面和通知。小窗不额外开服务，跟现有正在运行的会话走。
- 内置语音伙伴支持连续轮流说；普通题卡陪练的麦克风在可见的回复小窗里由用户点按，不宣称全双工。
- 分类为本机规则，包含自建分类名称匹配；不花额外模型请求。用户可手动移动。海龟汤正文能分类存储，未新增把任意汤面自动变成主持题的编译器。
- 严格模式的强制干预、拒绝交流后的处理按用户要求留到最后，这次没有扩展它。
- 没有合并或发布，正式下载页也可能仍是旧包；安装应使用本 PR 的新构建产物。

## 自动化联通与保留的设备检查

联通由 Codex 完成，运行范围和结果见 [运行验收记录](RUNTIME-VALIDATION.md)。以下列表用于实体手机补充检查；其中对话、真实服务、看屏、语音播放、分类和迁移已有模拟器覆盖，不再交给 Claude 执行联通。

1. 安装 0.25，旧线程/题库还在；助手能发消息、边生成边显示、停、重试、切换历史，重启能恢复。
2. 选择 B 站为关注应用，连接无障碍；打开 B 站出现收费站，正常答过后能回去，15 分钟后仍在原应用会重新拦；打开通知栏和输入法后到期照样检查。
3. 无障碍系统开关开着但服务断连时，首页显示未连接；手动重连后状态改变。厂商后台弹出界面权限要实测。
4. 允许悬浮窗，开陪练/看屏后切到学习应用。小窗能拖、展开、回一句、语音输入、停止；原应用仍能看见。截图没有截到小窗。
5. 语音伙伴在外部应用中讲话，点小窗打断立刻停声并转去听；打字能进入同一段对话；结束后麦克风/通知/浮窗都关闭。
6. 刷着练的小窗能出题、回一句、追问、显示判语。旧回复弹窗遇到已换题不能提交到新题。
7. 新建“英语”页，在该页导入文件/图片/题包；全部页导入混合题包会分类；手工移动后重启不被改回；几百条以上可以搜索和滚动，不只显示前 60 条。
8. 悬浮窗撤权、横竖屏、小屏/大字、切应用、系统回收后逐一检查。两种 APK 都启动一次。

## 构建

本地没有 Android SDK 或 KVM。GitHub Actions 运行 JVM 单元测试、主线/岔路打包，并在 API 29、34 的 KVM 模拟器上安装真实 APK 执行仪器测试。测试报告、逐项日志、截图和界面层级作为构件保留。APK 与运行链接见 PR #42。

此次运行修复了：冷启动带路由时导航图尚未就绪的崩溃；错误会话重新打开后缺少重试状态；模型普通响应、HTTP 错误和非流式回退在主线程读取响应体的异常；陪练结束后看屏服务延迟退出。题目通过门槛和发币条件没有降低。
