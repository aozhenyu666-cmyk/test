## 限制和待确认

- 没改 thread/、reflex/ 和 judge/ 的既有核心，只有任务卡允许的 ProbeRecorder 修复；按卡新增了 StrandStore。
- 真判卷入口已由基础分支提供，语义判断仍取决于配置接口；构建通过不证明判卷准确或训练有效。
- 对比卡沿用已有 DiffCards，里面有“太快，多半没想”的文字；按“不改核心目录”的约束保留，建议审阅时确认这句话是否该改。
- 线程每交一手都会 apply；两手不推进后下一问按既有引擎拉回。题库题保留同一锁题最多三次的流程。线程失败后点“接着来”，重新按 GatePlan 挑路。
- 外部总结不在收费站展示；回到主动线程页贴。独立页和入口可能同时面对同一线程，多页面并发是联通重点。
- 触发器 source 仍存锁题 id；默写题面从题卡或线程历史查，原素材删掉时只显示信号。
- 今天默写 id 与线程复盘落库；输入轨迹只在当前轮内存保存，通过后的复盘副本随线程存库，题库尚未完成的输入在进程被杀后重做。
- “早上”单独作为入口组，正常放行记这个组，不扩展到所有娱乐组。
- 新测试的迁移检查会在真实 SQLite 中运行 14→15 SQL，检查旧表不丢和新表能读写；没有替代手机上 Room 打开和升级验收。
- 无本地 Android SDK：测试与双变体打包交 GitHub Actions。正式下载地址不由此分支更新。

## 交给接手者的真机 / 联通项（均未测）
