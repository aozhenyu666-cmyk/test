### 0.20：Gemini Live 盯场

- 语音伙伴 →“用 Gemini Live 开始”：一手不接 Gemini、也听不到你们说什么，只看两件事：前台是哪个应用，以及此刻有没有应用在用麦克风（系统只告诉“有”）。Live 开着时麦克风一直开着，所以麦克风停了、人也不在 Gemini，就是 Live 断了。
- Live 断了：先提醒；开了“走了拉回 Gemini”就过一会儿把 Gemini 拉回前台（一场最多 3 次，严档更快）。输入法、通知栏、相机、拨号不算离开。
- 让 Live 看屏、自己在别的应用里刷：把那个应用登记成材料 App，Live 开着就算在场；去了没登记的应用只提醒，不拉。
- 规定词：Live 里没法粘贴。点“复制长规则”存进 Gemini 的「保存的信息」一次，以后开 Live 只说一句「一手开练。目标……」（一手显示在通知和页面上）。说「收工」结束。Live 认不认「保存的信息」，要在你手机上试一次。

### 0.19：刷着练

- **刷着练**（首页卡片、思考页放行后的“边刷边练”、快捷开关“考我一下”）：刷抖音、贴吧时也练。开始时系统会弹一次看屏授权。
- 刷到想练的，下拉通知点“考我一下”：一手收起通知栏，连拍三帧（隔 1 秒，看清字幕），交给识图模型，按“主张 / 缺口 / 预判 / 动机 / 反例 / 证据”轮着问一句跟这条有关的。
- 在通知里直接回一句，文字模型判“接住了 / 差一点 / 没接住”，说缺的那一层；没接住给参考。不用离开抖音。
- 也可以设“在关注的应用里每刷 3 / 5 / 10 分钟自动问一句”（只在入口思考页关注的那些应用里计时；上一问没回不追问，连着两问没理间隔翻倍）。
- 认真答过的那一屏，屏幕上的字收进素材池，以后“来一手”也能拿来练。想深聊点“去 AI 里接着聊”，把这一问发进 Gemini / ChatGPT。
- 不读整段视频：拿不到，也太贵。画面 + 标题 + 字幕 + 露出来的评论，够问一个好问题。截图不保存；一次最长 60 分钟，通知栏一直有“停”。

### 0.18：一个素材池，一个“来一手”

- **素材池**（首页）：粘贴、拍照 / 截图、导入文件、在别的 App 里“分享 → 一手”，都进这一个地方。进来自动分：像题的（有 A–D 选项或【要点】）进题库；像文章的切成一段一段（每段 1200 字以内，不丢字）进素材。文件是文章时不再被硬拆成题。
- 所有练法都从池子里拿：海龟汤、残局、练思维、刷题，语音伙伴也能选一段“一起聊”。不用每个练法各交一遍素材。
- **来一手**（首页最上面）：不用挑练法。按“上次没做好的先回来 → 能逼你自己生假设的（海龟汤）→ 你收进来还没练的 → 到期的 → 刷题”挑一件，说一句为什么；同一种练法不连着来，不想做点“换一个”。
- 首页精简：来一手、素材池、语音伙伴三个大入口，其余练法收成一排小按钮。

### 0.17：语音伙伴（第一版）

- 首页“语音伙伴”。两条路：**用 Gemini 开始**（外部伴读：一手准备开场白、计时、离开提醒和收线）；**用一手自己的语音开始**（你说 → 设置里的文字模型想 → 朗读念给你听）。
- 一手自己的语音：边出字边念，第一句一出来就开口；一问一答轮流说，它说话时不开麦，想打断点“停”（通知里也有）。
- 问了你 20 秒没回：缩短重问 → 换成二选一 → 记一笔“没接”，回去陪着，不纠缠；收线时告诉你没接几次。陪 / 诱 / 严三档决定它多久主动问一次。
- 导演（同一个文字模型）每 3 轮或 90 秒写一张卡，决定下一步推什么、用六面里的哪种问法；卡只给模型看，不念。
- 到点自己收线：“一句话，今天聊出了什么？”“下一步做什么？”。没收线就关掉的，入口页下次先问。
- 口令：“今天到这”收线，“逼紧一点 / 放松点”换强度，“安静”先别主动问，说完一段加一句“好了”立刻轮到它。
- 设置里听写和朗读可以填不同的服务，各自能测试连接。
- 还没接上的：语音海龟汤（T6）、“看一下”屏幕（T7）。

### 0.16：海龟汤

- **海龟汤**（首页）：拿题库里的真题当汤——材料和题干给你看，选项先藏着；正确答案和解析是汤底，只有主持人（你配的大模型）知道。你只能问是非问题，主持人只回“是 / 不是 / 部分是 / 无关 / 这不是是非题”，多一个字都不显示，没法替你想。至少问 3 问、或者说中了汤底，才能亮 ABCD——这一下拿锁死的答案核对，蒙不过去。最多 15 问。问过一样的不算。
- 去 ChatGPT 用语音玩：把汤面和规则（不含选项和答案）发进 ChatGPT，用它的语音模式问，回来亮选项核对。
- 煮完压一句“这锅的机关”收进棋谱，以后入口开局会推回来。
- **入口换回刷题**（一张题卡），升级上来的会自动换回一次；残局、主线、只打卡在设置里选。
- 0.15 的急刹去掉了（冲动时不会打开 App 去写经过）。
- **残局**还在首页：点出破绽那一句再翻底牌；只从你导入的题库和素材里加工。

### 岔路（探索版本）

主线之外，会陆续出一些“岔路”：同一份代码、换一种练法试一条路，和主线并排装在手机上（包名后缀 `.chalu`，图标青绿色，名字“一手·岔路”，数据各自分开）。

https://github.com/aozhenyu666-cmyk/test/releases/download/yishou-latest/yishou-chalu.apk

现在是 **岔路 1**（版本号后缀 `-chalu1`），只围着两件事：**精简**（把输入压成条件）和 **回响**（拿旧规则撞新变化）。

- 教练改成“捉虫 / 变条件”两拍：先甩一句故意埋了错条件的判断让你叫停、改一个条件；你答对后，强行反转一个条件追问你。不给 ABCD。
- 先喷后砍：第一步不限字数地倒出来（语音最快），第二步 20 秒内压成 40 字以内的一句“只有当……，才……”。规则不放水（主线里退回两次会放行，岔路不会）。
- 回响队列：收口、做事里“没做成 / 卡住”说的那句、入口答错后写的差值、回到主干时锁定的结论，都进回响队列；下次打开同一个 App，入口第一屏先推这一句，念一遍或点“记得”才往下。
- 入口不放水：主线“先放着”不放行；题卡答错要先写一句差值（本来想……，漏看了……，下次见到……先……）才放行。
- 不可逆的那一下（押答案、放行）先停 2 秒，期间点一下就收回。
- 读材料时逻辑词（转折、限定、否定、条件、因果）发亮；点一句钉到顶上的“已锁定条件”（最多 3 格），材料收起后还在。
- 出口改问“回来第一步点哪儿？”，放行后挂在通知栏，下次过入口答了“做了没有”就收掉。

编译：`./gradlew assembleChaluDebug`（主线是 `assembleMainlineDebug`）。代码里用 `system/Variant.kt` 判断走哪条路；纯逻辑不读它，靠参数传进去（`LineSession(style = CoachStyle.TRAP, lenient = false, …)`）。

APK 用仓库里固定的调试签名（`app/debug.keystore`），以后的新版本可以直接覆盖安装，本机数据保留。

## 代码在哪

| 目录 | 内容 |
|---|---|
| `data/` | Room 数据表与唯一的 DAO |
| `llm/Prompts.kt` | 所有提示词和返回格式，改陪练行为只改这里 |
| `llm/ChatClient.kt` | OpenAI 兼容接口请求，30 秒超时 |
| `llm/Coach.kt` | 开局 / 判定请求、JSON 解析、解析失败重试一次 |
| `round/RoundEngine.kt` | “一轮”的完整流程，主页、思考页、陪练窗口共用；放行与离线保存 |
| `gate/` | 无障碍服务（只读包名）和入口思考页 |
| `window/` | 陪练窗口：时间计算、闹钟、朗读、窗口页 |
| `summary/` | 每晚总结、WorkManager 定时、Markdown 导出 |
| `settings/` | 加密保存的设置 |
| `system/` | 通知、防掉线提醒、图片转写 |
| `look/` | 陪练看屏（屏幕授权、按需截一帧） |
| `stats/` | 盘点：每天的请求用量和计数 |
| `llm/Faces.kt` | 六骰子：六种思考动作、最小动作和检查标准 |
| `wallpaper/` | 局面壁纸（也用作壁纸守护） |
| `widget/` | 桌面小组件 |
| `training/` | 分组训练：每天的目标组数按达标情况加减 |
| `line/` | 主线（核心）：一局一手往下想；本机的说话规则（口水、先说结论、长度和结构）、不想答的降阶阶梯、回主线、断点；语音对练用同一套。岔路的捉虫 / 变条件两拍、先喷后砍的条件句规则、回响队列怎么挑（`Echoes.kt`）也在这里 |
| `bank/` | 题库：题包在本机解析（【题目】A–D【答案】【要点】…，也认“1. … 答案：B”、文末答案表、共用材料）、Word 读字、去 AI 出题的要求模板、导入去重 |
| `outside/` | 刷题 App（粉笔）的练习报告解析和统计；出题用 AI App 的列表 |
| `job/` | 做事：一件事拆成步（按份数、自己列、走一步看一步），每步用时和结果统计 |
| `endgame/` | 残局：切句、点没点中、缩包围圈、排期、题卡本机变残局、核对模型加工的残局是不是原文 |
| `scroll/` | 刷着练：连拍出题、通知里回答和判定、自动出题节奏、快捷开关 |
| `pool/` | 素材池：统一入口分流（题 / 文章切段）、“来一手”挑下一件、池子快照 |
| `partner/` | 语音伙伴：计划和开场白、外部伴读计时与收线、导演卡、会话控制器（轮次、没接阶梯、到点收线、口令）、麦克风前台服务 |
| `voice/` | 语音伙伴的四类接口适配、流式回复切句、说完检测、轮次号 |
| `soup/` | 海龟汤：汤面 / 汤底、只许是非问题、问够几问才亮选项、主持人回话只认固定几个字 |
| `think/Logic.kt` | 逻辑词（转折、限定、否定、条件、因果）的位置、点哪取哪一小句、是不是条件句 |
| `think/` | 练思维：六面下的练法（抓主干、背下来、押后果、估个数、找相似、挖前提、站立场、搭关系、回想）、背诵的逐字对照和间隔复习、作答前锁住的答案、本机核对原话和口水、估算区间计分、一次练习的流程 |
| `deed/` | 小工具：先估再做的偏差统计、比价（规格折算单价） |
| `share/` | “分享 → 收进一手”：别的应用里分享的文字或截图 |
| `card/` | 题卡（练思维的一种练法）：答案和依据在出题时定死；四步回合（下注、依据、多查、揭晓）、语音答案拆解、掌握度与难度、关屏阶梯、错题重做、出题后自验 |
| `coach/` | 热身接龙 |
| `speech/` | 语音：录音与说完检测、听写 / 朗读接口、语音口令 |
| `bet/` | 预判本的校准计算（说的把握和实际命中率） |
| `log/` | 运行日志：请求失败、服务出错、崩溃 |
| `ui/` | 主页、设置、权限、关注的应用、总结等页面 |
