# 伴随 · Android 语音助手原型

[下载 Android 安装包](releases/companion-0.1.0-debug.apk?raw=true) · [下载独立源码包](releases/companion-0.1.0-source.zip?raw=true) · [验证记录](VALIDATION.md) · [扩展路线](docs/ROADMAP.md)

本项目完整放在 `companion-voice-assistant/`，构建请先进入这个目录。安装包和源码压缩包放在本目录的 `releases/` 中。

一个可安装的原生 Android 原型：把语音会话留在浮窗里，同时提供明确指令驱动的手机操作和主动触发的屏幕理解。最低 Android 11，无须 Root。中文界面，Java 实现，不依赖第三方界面或语音 SDK。

## 安装与第一次使用

1. 在 Android 手机上安装 `companion-0.1.0-debug.apk`。这是调试签名原型；系统可能要求允许当前浏览器/文件管理器安装未知来源应用。
2. 打开「伴随」，点「开始说话」并允许麦克风权限。Android 13 以上建议允许通知，以便随时关闭会话。
3. 要跨 App 使用，点「悬浮窗权限」并开启；返回后点「开启浮窗」。点圆形入口展开，拖动入口移动位置。
4. 要使用返回、桌面、最近任务或截图，点「屏幕与导航权限」，在系统中打开「伴随 · 屏幕与导航」。部分侧载手机会要求先到应用信息菜单允许受限设置；这是系统控制，应用不能替你开启。
5. 要自由聊天，在「模型与隐私设置」填写兼容 Chat Completions 的 HTTPS 基础地址、模型 ID、API Key。基础地址会自动补上 `/chat/completions`，完整接口路径也可直接填写。无鉴权的 HTTPS 网关可不填 Key。
6. 要理解截图，选择支持 `image_url` 图片输入的模型，并开启「按指令发送截图」。在其他 App 中展开浮窗，说「看一下屏幕」，或点浮窗里的同名按钮。

不配置模型也可以尝试「打开微信」「返回桌面」「声音小一点」。手机必须安装相应应用。设备需要有可用的系统中文语音识别服务和中文 TTS 引擎；有些国产系统没有公开可调用的识别服务，届时可以打字。系统自身的语音助手可用，并不保证开放了第三方识别接口。

## 当前真实能力

| 能力 | 原型实现 | 条件/限制 |
|---|---|---|
| 浮窗 | 可拖动、展开、暂停、关闭 | 用户授予悬浮窗权限；系统可隐藏敏感页面上的浮窗 |
| 语音输入与播报 | 系统 SpeechRecognizer + 中文 TTS | 优先使用可用的设备端识别，否则使用系统识别服务；后者可能联网 |
| 连续对话 | 听一句 → 回复 → 继续听 | 通过点按打断；三次无结果后暂停；不是全双工，也没有唤醒词 |
| 打开 App | 按启动器应用名称查找并发出启动请求 | 应用需有启动入口；重名时要求完整名称；受后台启动规则影响 |
| 手机导航 | 返回、桌面、最近任务 | 用户启用无障碍服务 |
| 音量/设置 | 媒体音量加减、打开系统设置 | 不修改系统保护的设置 |
| 自由对话 | 可配置的 HTTPS 模型服务，最近 8 轮上下文 | 用户自行配置服务商；可能计费；当前等待整条回复后播报 |
| 看屏幕 | 主动触发单次截图，缩放至最长边 1280 后发送 | Android 11+ 无障碍截图接口；另外需要用户在模型设置授权；受保护页面不可保证可见 |
| 记忆 | 当前进程的聊天上下文 | 没有跨重启记忆，不会从截图自动建立永久画像 |

支持的直接指令：

- `打开微信`、`切换到支付宝`、`启动计算器`（以实际应用名称为准）
- `返回`、`返回上一页`、`返回桌面`、`最近任务`
- `声音大一点`、`声音小一点`、`打开设置`
- `看一下屏幕`、`看一下屏幕，帮我总结这一页`
- `暂停聆听`、`结束对话`

说「不要打开微信」或「你能打开微信吗」会进入普通聊天，不会执行打开指令。模型只负责回复和看图，尚未被授予任意操作手机的工具，不能自动点击、付款、发送消息或更改权限。

## 数据与权限

- 截图只由明确的看屏幕指令触发，暂存在内存，不写入相册或磁盘，不后台巡视。截图隐藏伴随浮窗后拍摄，但会包含目标屏幕上其他可见信息。
- 截图和对话会发送给你填写的模型服务商；服务端留存由服务商决定。关闭「按指令发送截图」会阻止后续截图，不会撤回已经发出的请求。
- API Key 使用 Android Keystore 中的 AES-GCM 密钥加密存储。应用禁用系统备份，不把 Key 写进源码或日志，不跟随 HTTP 重定向发送鉴权头。
- 聊天记录仅保留进程内最近 80 条，模型上下文为最近 8 轮。清空对话、修改/清除模型设置会取消当前请求并清理模型上下文。停止助手会释放语音资源；界面中的对话在当前进程仍然存在，重启进程后清空。
- 麦克风会话由你从应用或已开启的浮窗中启动，使用前台服务通知。没有开机自启。系统仍可能因省电策略终止服务。
- 无障碍授权具有较高系统能力；当前服务只声明导航与截图所需能力，不读取界面节点、不接收文本变化，不声明模拟手势能力。权限不能让普通应用访问其他 App 的私有数据库或绕过锁屏。

## 构建

需要 JDK 17/21、Android SDK 35、Build Tools 35.0.0。首次构建需要联网下载依赖。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

生成文件：`app/build/outputs/apk/debug/app-debug.apk`。在项目根目录的 `local.properties` 中配置本机 `sdk.dir`，或设置 `ANDROID_HOME`。不要把本地 SDK 路径、代理或 API Key 提交到版本库。

## 测试范围

自动测试覆盖指令解析中的操作、问句、否定句和截图指令边界；Android Lint 检查权限/API 使用。具体运行结果与模拟器检查记录见 `VALIDATION.md`。

真实模型服务、麦克风识别质量、中文 TTS 可用性，以及不同厂商的后台保活效果需要在目标真机验证。原型不附带 API Key，也不承诺全天候监听或任意跨 App 自动化。

## 向更强的助手演进

第一阶段以稳定的语音交互和少量手机动作建立闭环。下一阶段优先接入流式模型输出/流式语音、回声消除、耳机音频路由和可取消的实时会话，解决高频交流的延迟与打断体验。

操作能力建议逐个注册：每个工具声明参数、所需权限、适用页面、执行结果及验证方式。优先调用 Android Intent、Deep Link 和目标 App 的官方 API；模型提出计划后，由本机执行层验证并检查结果。发消息、提交订单等有外部后果的动作，在提交前展示具体目标和内容。

产品形态可以继续拆成 `assistant-core`（会话/记忆/工具路由）、`assistant-android`（系统能力）和 `assistant-ui`（App 内组件/浮窗）。当前交付是独立可安装应用，尚未封装成可直接依赖的 AAR SDK。

### 系统与分发边界

“权限不断扩大”必须对应具体系统接口和用户授权，普通 APK 不能自行变成系统应用。成为默认助手也不会自动获得全部系统权限。更深的系统控制通常需要设备厂商合作或定制系统，属于另一条产品路线。

Google Play 对利用无障碍 API 自主发起、规划与执行操作有明确限制。因此，不能把“无障碍 + 任意 AI 自动点击”当作默认可上架方案；个人侧载原型和公开分发产品需要分别设计能力范围。
