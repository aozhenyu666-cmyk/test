# 一手 电脑版（Windows）

手机上的「一手」在等你应手时，电脑往往是最顺手的逃跑通道。电脑版只做一件事：守门。

## 拿到安装包

https://github.com/aozhenyu666-cmyk/test/releases/download/yishou-pc-latest/yishou-pc.msi

双击安装，装在当前用户下，不需要管理员。也可以用同一个发布页里免安装的 `yishou-pc-portable.zip`。

## 它做什么

- 每 0.7 秒看一眼前台窗口的程序名和标题，认出三类：
  - 网页娱乐：夸克等浏览器里标题含“哔哩哔哩、抖音、贴吧、红果……”的页面；
  - 游戏：WeGame，以及由 WeGame 启动的游戏；
  - 模拟器：雷电模拟器。
- 认出来时把那个窗口最小化，盖一个全屏的守门页：
  - 上次说好“看完回来做”的事，先答做了没有；
  - 写清这次去做什么、回来做什么，选时长，等冷静期过去才放行（今天每多放一次，冷静期长 10 秒）；
  - 每类每天有额度，用完就只剩“真有急事”（写满 30 个字，每天 2 次）和“不去了”。
- 放行到点前一分钟提醒；到点再打开，守门页先问“你说看完回来做的呢”。
- 专注时段（和手机陪练窗口设成同一时间）：这三类一律不开。
- 逃跑记录：每次想打开、放行、不去了、说到做到没有、退出、被强行结束，都按天记下来。

## 透明原则

- 图标、托盘、开始菜单都看得见，不隐藏，不防卸载。
- 只读前台窗口的程序名和标题，不读窗口内容，不截屏，不记键盘。
- 不联网。设置和记录都在 `%APPDATA%\Yishou` 里，记事本就能看。
- 随时可以关自启、退出、卸载。退出要写一句原因；被强行结束会在下次启动时记一笔。

## 代码

| 目录 | 内容 |
|---|---|
| `core/` | 纯逻辑：规则匹配、额度与放行、冷静期、专注时段、逃跑记录、心跳。有单元测试 |
| `app/.../win/` | Windows 接口（JNA）：前台窗口、上级进程、最小化、置顶、开机自启、系统朗读 |
| `app/.../ui/` | Compose Desktop 界面：守门页、今天、规则、设置 |
| `app/.../Controller.kt` | 把上面串起来的运行逻辑 |

CI（`.github/workflows/yishou-pc.yml`）在 Windows 上跑测试、把几个页面画成截图（`snapshots.zip`）、打 MSI 安装包。
