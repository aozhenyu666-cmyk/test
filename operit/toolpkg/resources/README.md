# 核心对话台 v0.2.0（主控中枢）

打开侧边栏的「核心对话台」：中间是和 AI 的对话，右侧（手机上点「面板」）是：

- **现在**：当前这件事和当前问题。写下你的回答，点「保存并继续」，AI 接着问。
- **专注时段**：09:30–11:30、14:30–16:30、20:00–22:00。时段内打开 B站、抖音、贴吧、小红书要先回答三个问题拿钥匙；每天 2 把，每把 10 分钟，最长 15 分钟；不答或敷衍会冷却 5→10→20→40 分钟。
- **伴读**：登记要看的东西，打开 Gemini；看完写一句收获。
- **收一句线**：和任何 AI 聊完、下完棋、做完题，写一句自己的收获。
- **今天**：重度 App 用时、日报开头；「找小满聊」「和小满语音」。

账本、AI 接着问、暂停都由 cognitive_continuity 后台负责。锁定执行接通之前，钥匙只记账，不改变手机限制。

宿主不支持嵌入对话时，用工具箱里的「主控台（面板版）」。
