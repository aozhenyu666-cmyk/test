# 主控中枢 v0.1.0

三件事：

- **对话门**：想打开重度 App 时，先回答三个问题（干什么、多久、回来做什么），答得具体就给一把限时钥匙，到点收回并提醒你回来做什么；不答或敷衍，冷却时间按 5→10→20→40 分钟延长。
- **伴读**：登记材料，打开 Gemini；你在 Gemini 里打开「伴读」Gem、点 Live、共享屏幕，它就边看边和你聊。
- **思考线**：伴读结束或和任何 AI 聊完、下完棋，写一句自己的收获，存进 cognitive_core 的思考线。

默认值对齐你现有的解锁政策：每天 2 把钥匙，每把 10 分钟，最长 15 分钟。放宽要你亲自在设置里改。

解锁和回锁只走已绑定的现有通道（S4 锁队列 / 解锁闸门）。没绑定时，钥匙只记账，不改变手机上的限制。

工具名前缀：`zhukong:`。详细设计见仓库 `operit/docs/`。
