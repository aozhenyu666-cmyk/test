# A｜A-030｜装主控台 0.9.0（司南），跑通一问一答

**这一轮只证明一件事**：用户在主控台写一句话，司南用模型接着问，语音也接得上。

**用户要做的**：约 10 分钟，第 3 步。
**不做**：
- 不冻结、不解冻任何 App；
- 不改时段、名单、规则；
- 不删除任何对话或工作流；
- 不对 `local.focus_hub` 这个容器调用 `use_package`。它不是包，上次报错就是这个原因。工具在子包 `focus_hub_nav` 里。

## 1. 安装（机器步骤）
1. 用包里的 `SHA256SUMS` 核对 `focus_hub-0.9.0.toolpkg`。
2. 以同一包 ID `local.focus_hub` 升级安装（0.8.0 → 0.9.0），保留子包的启用状态。
3. 读回版本号，应为 0.9.0。

## 2. 工作流（不用新建）
原来的「专注推进（每15分钟）」继续用：工具名没变，逻辑已经换成按司南的当前问题推进。
- 确认它仍是启用状态；
- 「陪伴打卡」不动。

## 3. 用户走一遍（请用户来做；你只记录，不代替用户写回答、不代替用户点）
1. 打开侧边栏「主控台」，应该落在「专注」页，底栏只有三栏：专注、陪伴、管理。
2. 在输入框写下这段时间要做的一件具体的事，点「开始」。司南会提第一个问题。
3. 用自己的话回答，点「发送」。这样来回 3 次。
4. 点顶部胶囊「复盘」，回答它的一个问题。
5. 点 🎙。
   - 第一次会自动建「司南」角色卡和「司南」对话。
   - 如果系统弹出权限确认，请用户自己决定。
   - 语音球打开后，用语音回答一句。
6. 回到主控台，看是否出现带"语音"标记的气泡。

如果气泡下写着"模型没接上，这句是本地备用问题"，把那一行上方状态条里的原因原文抄下来。

## 4. 主动推进（机器步骤）
- 手动运行一次 `focus_hub_nav:focus_nudge`，参数 `force=true`。
  - 返回值应为 `NUDGED`；
  - 返回的 line 应该是"回来接着想：<司南刚才的问题>"。
- 下一个专注时段过后，读「专注推进」的执行日志，记下返回的 status。
