# 总控 电脑版（Windows）

手机上的总控管手机；这台电脑一天能耗掉 6 小时，因为它什么都不管。电脑版就是把总控搬到电脑上：
**用电脑先说做什么，娱乐有额度，夜里锁机，想多用就向总控申请**——申请交给 AI 判断，它对着你今天的电脑记录和手机上的计划说话。

## 拿到安装包

https://github.com/aozhenyu666-cmyk/test/releases/download/zongkong-pc-latest/zongkong-pc.msi

双击安装，装在当前用户下，不需要管理员；开机自动启动（托盘里一个赭石色的“控”）。
同一个发布页还有免安装的 `zongkong-pc-portable.zip` 和界面截图 `snapshots.zip`。

## 第一次

1. 打开后先到 **连接与设置**：
   - 有手机：手机上 我 → 电脑 → 建立连接 → 复制配对码，发到电脑上粘贴。AI 接口可以一起带过来。
   - 没手机：直接填 AI 接口（DeepSeek、Kimi、通义、OpenAI 都行）。不填 AI 也能管，只是没法申请。
2. 到 **规则** 看一眼额度：默认娱乐 60 分钟、社交 30 分钟、游戏 0（一律要申请）、电脑总时长 5 小时、夜里 23:30–7:00 锁机。

## 它怎么管

| | 怎么回事 |
|---|---|
| 会话制 | 每次碰电脑先写“这次做什么、用多久”（自己最多 90 分钟），到点锁屏对账：做完了吗？ |
| 额度 | 娱乐 / 社交 / 游戏每天有分钟数。用完：程序窗口收起来、盖拦截页；网站在**网络层**打不开（换浏览器也一样） |
| 总时长 | 今天电脑用够 5 小时，再开要总控批 |
| 夜里 | 23:30–7:00 锁机，只有总控能批 |
| 锁机 | 总控可以锁、手机可以锁；手机进**总控时间**，电脑自动锁到结束 |
| 申请 | 锁屏和拦截页右边就是总控：说清楚做什么、多久、用完回去做什么。它看记录、看手机上的主线，批一小段（态度越严批得越少），到点回访你回去了没有 |
| 主动问 | 连续用 45 分钟，右下角问一句“在做什么”。2 小时不回扣信用 |
| 放宽要审 | 额度调大、删网站、关开关要写理由，交给总控（AI）审：批了 24 小时后生效，驳回作废、6 小时内不能再申请，没接 AI 等 72 小时。收紧马上生效。AI 自己只能收紧 |
| 紧急 | 一天一次、十分钟、写满 30 字，什么锁都打开——手机会知道 |
| 失联 | 被任务管理器结束、手动退出，都会记下来报给手机 |

## AI 能做什么（“许愿式”）

在 **总控** 页直接说话，它会调工具：

- 看记录：今天 / 昨天几点到几点用了什么、窗口标题；开了“看屏幕”还能截一张看你在干什么（发给你自己填的 AI）
- 放行一个网站 / 程序 / 一整类几分钟，批一次会话，结束会话，锁机
- 新拦一个网站或程序、调小额度（马上生效）
- 关掉某个程序
- **在电脑上执行命令（PowerShell）**：只读的（看进程、文件、网络）直接执行；会改东西的弹给你点“执行 / 不执行”；破坏性的（格式化、删一大片、动系统启动、关掉总控自己）代码直接拒绝
- 记陈述、判定、记约定、排回访（信用和手机一样算）
- 给手机发话、用电脑的声音念一句

## 网站怎么在网络层拦

总控在本机起一个小服务，把“自动代理脚本（PAC）”设成它（当前用户的系统代理设置，不用管理员）：
要拦的域名交给本机的拦截口（https 直接拒绝，http 回一页“关着”），其他照常直连；原来开着代理软件的，照常走原来的代理。
总控退出时还原设置；被强行结束时脚本地址打不开，浏览器自动直连——**不会把网弄断**。
设置被手动改掉，半分钟内会改回来。

## 透明原则

- 图标、托盘、开始菜单都看得见，不隐藏，不防卸载。
- 只读前台窗口的程序名和标题；开了“看屏幕”才截屏，截图只存在这台电脑上，看的时候发给你自己的 AI。
- 联网只为两件事：你自己填的 AI 接口；和手机互通用的你自己的 Notion。
- 数据在 `%APPDATA%\ZongKong`，都是 JSON，记事本能看。
- 锁屏时会吃掉 Win 键、Alt+Tab、Alt+F4；Ctrl+Alt+Del 不拦（也不该拦），从那里结束总控会记成失联。

## 代码

| 目录 | 内容 |
|---|---|
| `core/` | 纯逻辑，可以在任何系统上测：规则和分类、每天的使用记录、锁不锁 / 拦不拦、放宽冷静期、PAC 脚本、命令分级、AI 工具、和手机互通。**手机版总控的核心代码直接编译进来**（AI 对话、信用档案、Notion），两边是同一份 |
| `app/.../win/` | Windows 接口（JNA）：前台窗口、空闲、收起 / 关窗口、键盘守卫、开机自启、系统代理、截屏、PowerShell、朗读 |
| `app/.../ui/` | Compose Desktop 界面：今天、总控（对话）、规则、连接与设置、锁屏、拦截页、问候 |
| `app/.../Controller.kt` | 把上面串起来：每秒看一眼前台，每半分钟存盘 / 更新拦截 / 回访，每分钟和手机同步 |

CI（`.github/workflows/zongkong-pc.yml`）在 Windows 上跑测试、画界面截图、打 MSI。
