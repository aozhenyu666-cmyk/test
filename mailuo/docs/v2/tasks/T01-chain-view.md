# T01 结构页：「问 → 论 → 规」链条视图

**依赖**：T00（已完成）　**改动范围**：`www/js/app.js`、`www/js/model.js`、`www/js/pack.js`、`www/css/app.css`、`dev/e2e.mjs`、`dev/unit/`

## 目标

结构页（`#/tree`，函数 `viewTree` / `buildTree`）不再按「层级」文件夹显示，改成以「问」为根的缩进链条。手机上一眼能看清「问 → 论 → 规」的因果和落地关系。

## 要做的

1. **链条树**（替换 `buildTree`）
   - 顶部保留体系切换（`sys-chips`）和搜索框。
   - 根节点用 `store.chainRoots(体系)`，每个节点下面递归渲染 `store.children(id)`，每层缩进 14px，左侧细竖线沿用 `.lv-body` 的视觉。
   - 节点行用现有 `nodeRow()`：
     - 论 / 规 右侧显示把握表盘；
     - 暂停的规加 `.paused` 样式（降低不透明度，标题后加「暂停」小标签）。
   - 每个有下级的节点可以折叠，折叠状态存进 `localStorage` 的 `mailuo.closed`（沿用 `closedSet` / `toggleClosed`）。
   - 最下面一个「未挂载」分区，放 `store.unmounted(体系)`，标题后显示数量。没有就不显示。
2. **拖动改挂载**（改 `startDrag`）
   - 按住节点左侧 ⋮⋮ 拖到另一个节点行上，就挂到那个节点下面；拖到「未挂载」标题上，就取消挂载。
   - 落点用 `data-drop="node:<id>"` 或 `data-drop="unmount"`。
   - 松手时调用 `store.canMount()`：返回原因就 `toast(原因)` 并不改；否则调用 `store.mount()`。
   - 拖动时落点高亮沿用 `.drop-on`。
3. **新建**
   - 结构页右上角 ＋：新建一个「问」（根）。
   - 每个节点行增加一个 ＋ 小按钮（在 `.lv-tools` 的位置），按节点类型提供可挂的子类型：
     - 问 下可新建 问 / 论 / 规；
     - 论 下可新建 论 / 规；
     - 规 下没有 ＋。
   - 打开 `newNodeSheet`，并预填 `type` 和 `under`。
4. **去掉层级**
   - 删除 `newLevelSheet`、`levelOptions` 和层级相关按钮。
   - `nodeForm` 里的「上级层级」下拉先改成只读显示「挂在：xxx」。完整的挂载选择器在 T02 做。
5. **文件扁平化**
   - `model.js` 的 `Store.filePath()` 改为 `体系/标题.md`，不再按 `parent` 建子文件夹。
   - 旧文件在下次保存时会自动移到新位置（`saveNode` 已处理路径变化，删旧写新）。
   - `saveSystem()` 写出的体系目录改成按链条缩进（问 → 论 → 规），未挂载的列在最后。`levels` 字段保留但写空数组。
6. **复制体系大纲**（`pack.js` 的 `systemOutline`）改成按链条输出，每行带类型：
   ```
   - **[问] 标题**：结论
     - **[论 60%] 标题**：结论 〔激活词〕
   ```
7. **样式**：类型印章已是 问 / 论 / 规。规的行左侧加 2px 朱砂色竖线，和论区分开。

## 不要做

- 不改节点详情页（T02），不改录入 / 候选（T03 / T04）。
- 不删除 YAML 里的 `parent` 字段，只是不再使用。

## 验收

- `npm run test:unit`：新增单元测试，覆盖 `filePath` 扁平化和 `systemOutline` 链条输出。
- `npm run test:e2e`：
  - 把现有的「拖动改父级：文件移到新层级文件夹」那段改成新流程：载入示例体系后，把规 n-0101 从 n-0006 下拖到 n-0007 下。
    - `check`：`n-0101` 的文件内容里出现 `under: n-0007`。
    - `check`：把规拖到另一个规上，会出现提示且挂载不变。
  - 截图 `03-tree` 显示链条视图。
  - 「复制体系大纲」那条检查改成验证 `[问]`、`[论 ` 前缀。
  - 其余检查保持通过。依赖层级路径的断言，比如 `思维问题/根因/下一问没有产生.md`，改成扁平路径。
- 390px 宽度下没有横向滚动。深色模式下可读。
