# T02 节点详情页：推演槽位、按类型编辑、挂载选择

**依赖**：T01　**改动范围**：`www/js/app.js`（`viewNode`、`nodeForm`、`validate`、`newNodeSheet`、`editNodeSheet`）、`www/css/app.css`、`dev/e2e.mjs`

## 目标

点开一张卡片，先看到极简的三行：类型、标题、一句结论（规就是唯一动作）。推演槽位折叠在下面，点开才看全。所有槽位都能编辑。

## 要做的

1. **详情页头部**（`viewNode`）
   - 路径改成挂载链面包屑：`store.ancestors(id)` 反序，每段带类型字，可点击跳转。
   - 标题下的标签：类型、把握（论 / 规）、状态（论）、「暂停」（规）。
2. **推演槽位面板**
   - 新增一个 `<details class="card slots">`，默认展开，标题「推演槽位」。
   - 按 `SLOTS[n.type]` 渲染（定义在 `model.js`）：
     - `list`：渲染为 `.kw` 标签组；
     - `text`：渲染为一段文字；
     - `sentinels`：每条一行，左边是 `+10` / `−15` 的彩色徽标（加分绿、扣分红、0 灰显示「待定」），右边是 `when`。
   - 空槽位显示灰字「待补：〈hint〉」，点击直接打开编辑弹层。
   - 原来的「激活词 / 把握 / 验证方式 / 来源 / 更新」卡片保留但精简：
     - 去掉「验证方式」行，已由验证哨代替；
     - v1 迁移来的 delta=0 哨显示「待定」。
3. **下级列表**：在「关系」分区上方加「下级」分区，列出 `store.children(id)`，每行是 `nodeRow`，末尾一个「＋ 挂一个论/规」按钮，打开预填 `under` 的新建弹层。
4. **按类型编辑**（`nodeForm`）
   - 类型切换（问 / 论 / 规）用 `.seg`，切换时只显示该类型的字段：
     - 问：标题、结论、破局支柱（每行一条，最多 3 条）、激活词
     - 论：标题、结论、把握滑块、状态、反方盲区、验证哨编辑器、激活词
     - 规：标题、唯一动作（存在 `claim`）、把握滑块、触发场景（每行一条，最多 3 条）、破戒代价、「暂停」开关、激活词
   - **验证哨编辑器**：可增删的行，每行是「现象」输入框 + delta 步进（−30…+30，步长 5）。
   - **挂载选择器**：可搜索的节点列表，只列出 `store.canMount(当前id, 目标)` 返回空的节点。另有一项「不挂载」。新建时用 `blankNode` 的 id 为空，按类型过滤即可。
   - 说明、来源字段收进「更多」折叠区。
5. **校验**（`validate`）
   - 论：没有任何验证哨时提示「至少写一条验证哨」，可以「仍然保存」。
   - 规：没有触发场景时同样提示。
   - 原来「假设必须写验证方式」的硬性要求去掉。
6. **保存**：`read()` 返回 V2 字段（`pillars`、`blindspot`、`sentinels`、`triggers`、`cost`、`paused`、`under`），保存后详情页即时更新。挂载变化走 `store.mount()`。

## 不要做

- 不改结构页（T01 已做），不改录入 / 候选。
